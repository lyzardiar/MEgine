# 迫击炮照明弹

人族迫击炮小队的 `Afla` 接入点目标施法，原 `flare` 订单、`Rhfl` 科技前置、范围、冷却、魔法、施法事件及界面操作沿用现有技能流程。技能效果在源 `DataB` 延迟后创建所选位置的迷雾视野与 `DataA` 隐形侦测，持续 `Dur` 秒；效果对象和显形区域在结束时释放。已发射的效果不依赖施法单位继续存活。公共资源从原 MPQ／地图归档读取，支持地图自定义能力覆盖。

原 1.27 `War3Patch.mpq` 的 `Units/AbilityData.slk` 中 `Afla` 的范围为 1800、持续 15 秒、延迟 0.8 秒、侦测类型为 3、冷却 120 秒，效果 ID 为 `Xfla`；`Units/HumanAbilityFunc.txt` 指定 `flare` 订单、`Rhfl` 前置与原施法特效。字段在执行时由源资源及地图覆盖决定，以上是原始值而非硬编码。

信号枪 `fgun` 的 `AIfa` 接入点目标物品施法与现有显形区域，支持地图及小地图选点，复用物品次数、冷却、施法事件及延迟效果。原资源定义 3 次使用、范围 1800、持续 45 秒、延迟 0.8 秒和侦测类型 1；具体字段按资源及地图覆盖读取。实际操作、遮罩与时序仍待阶段验证。

实际窗口、遮罩边缘、多个照明弹叠加、施法单位死亡／技能取消、暂停、共享视野、持续时间、射程、自定义覆盖、双端同步及原版时序、源动画／声音与视觉效果均待集中验证。`DataC` 闪烁计算和飞行弹道细节尚未实现，不将本项视为完整原版验收。
