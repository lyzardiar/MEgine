# 战争践踏地形波纹

战争践踏 `AOws` 及其派生能力允许源表的负地形幅度字段，避免 `Awrs` 的 `DataB=-50` 被通用非负检查拒绝。原始字段按编辑器元数据校验：幅度为 -1000 至 1000，持续时间为 0 至 99999 毫秒的整数。

施法命中阶段使用现有地形形变系统创建一次以施法者为中心的波纹，半径为技能范围，深度 -50、时长 300 毫秒、空间波数 1、时间波数 2、起始半径比例 1，仅保留负位移。随后执行原有范围伤害和眩晕。波纹随会话时钟消退，使用现有的地形顶点和高度查询，无派生资产。地形形变达到现有 256 个并发上限时跳过新增波纹，伤害和眩晕继续执行。

证据来自固定版 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）：`CAbilityStomp` 的施法虚函数 `0x6f56e410` 使用常量 -50 和 300 调用 `0x6f770120`；JASS `TerrainDeformRipple` 的绑定 `0x6f1f8bc0` 调用同一入口。`Units/AbilityMetaData.slk` 与 `UI/WorldEditStrings.txt` 标识 `Wrs2` 为地形变形幅度，`Wrs3` 为地形变形持续时间（毫秒）；`Awrs` 的源值为 -50 和 300。静态路径显示该施法入口使用固定参数，地图覆盖字段是否影响其他路径仍需原版运行验证。

待集中验证：`NightElfX01` 中 `Awrs`、英雄 `AOws` 和自定义地图派生能力的加载、践踏伤害／眩晕／动画，以及波纹半径、位置、方向、时长、水面和高度查询；对照原版修改 `Wrs2`／`Wrs3` 的效果，并检查 256 个并发地形变形上限、多人同步和性能。现有波纹公式属于近似，尚未编译或运行。
