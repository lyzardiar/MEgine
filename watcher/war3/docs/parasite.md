# 寄生技能

`ANpa` 及地图派生技能接入目标订单，读取原能力等级、目标类别、毒伤、速度减幅、叠加标志、召唤单位、数量、召唤寿命及状态 ID。命中后状态加入单位 Buff 集合，脚本可通过 `GetUnitAbilityLevel` 查询；毒伤及减速由已有毒状态消费者处理。带状态的普通单位死亡后生成对应归属和数量的召唤单位并触发召唤事件；带正时限时设置定时生命。

DotA_v6.83d 的 `A0BH` 以 `ANpa` 为原型，使用 `B0E7` 和 `n019`；地图脚本会查询 `B0E7` 并监听召唤单位。资源从地图及公共归档读取，源对象数据来自本机 Warcraft III 1.27.0.52240 安装和地图覆盖。

本次仅做差异检查，尚未编译或运行该技能。状态叠加、英雄／幻象死亡、尸体占用、驱散、召唤生命周期及事件顺序需与原版对照。到期状态在该 tick 的伤害消费后清理；伤害回调重新施加的状态按标记轮次保留。此边界和原版一致性仍待验证。
