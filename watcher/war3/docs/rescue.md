# 战役与自定义地图救援

`SetUnitRescuable` 按玩家设置单位救援资格，`SetUnitRescueRange` 设置检测半径。模拟步进按位置检测进入范围的活单位，派发玩家单位救援事件 19 和单位救援事件 63，并通过 `GetRescuer` 提供实际救援单位。地图玩家类型 4 映射为 `MAP_CONTROL_RESCUABLE`；该类玩家的单位可由用户／电脑玩家触发救援，单独设置可覆盖指定玩家的资格。

原安装 `Scripts/Blizzard.j` 的 `TriggerActionUnitRescuedBJ` 从 `GetRescuer` 获取所有者，再调用 `RescueUnitBJ`；后者调用 `SetUnitOwner`、显示指示和小地图提示并播放救援声音。救援事件因此沿用脚本触发的实际所有权转移，复用已有易主、人口、研究和事件流程。自定义事件可以选择自己的转移行为。检测通过单位空间网格缩小候选范围，单位离开范围、死亡、隐藏、禁用资格或易主会刷新邻近状态，回调中重新检查句柄、生命和归属。

实现阶段采用 600 的默认半径、按中心距离和首次进入判定，并按单位句柄排序；玩家控制类型、资格覆盖、暂停／隐形／空中单位、碰撞、重复进入及回调时序尚待原版对照。无效或过大范围明确失败，尚未验证原版异常参数行为；地图源玩家类型、归属及默认救援 BJ 的完整组合、视觉／声音、多个救援者和局域网同步均待验证。

阶段集中验证：Rescuable 玩家和显式设置启停、每玩家独立资格／范围、已在范围内设置及离开后返回、原玩家和救援者的事件上下文、BJ 默认颜色／指示／声音／小地图、真实归属／人口／科技、死亡复活／隐藏显示／转移／回调重入、建筑与空中单位、多人争抢、暂停以及 Prologue 和其他战役。当前尚未进行实际运行或原版一致性验收。
