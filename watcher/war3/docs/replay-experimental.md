# 自研局域网回放

启用 `--experimental-local-lan` 的同构建对局在载入完成后记录成功应用的时间片。结算时可通过原保存面板输入文件名并保存已录制时间片；未通过面板保存而离开、连接中断、关闭窗口或异常退出时尝试自动保存至独立用户目录的 `Replays`，默认 `%LOCALAPPDATA%/MEgine/War3/Replays`，遵循 `MEGINE_WAR3_USER_DIR`。采用唯一文件名、临时文件和原子发布；录制或保存失败写入日志并显示提示，不中断运行中的对局。记录包含地图校验、槽位、玩家、种子及时间片内的自研聊天动作；不含离开原因、校验和结算记录；断线、窗口关闭或录制失败时保存已完成的前缀并在文件名标记 partial，操作系统强制终止或崩溃无法保证保存。

单人菜单的原版回放按钮打开回放列表。选择本客户端记录后，校验文件中的可执行文件 SHA-256 与当前构建，恢复录制端的玩家视角，校验本机 `Maps` 中同路径地图并在内存中准备会话，通过载入界面启动一次 main；回放以时间片驱动模拟，视图只读，空格暂停／继续、加减键调整 0.25／0.5／1／2／4／8 倍播放速度，Esc 返回列表；当前速度显示在画面顶部。调速只作用于回放时间片，不改变记录的模拟命令。局域网接收的地图在保存回放时保留与该回放关联的原始归档；播放优先核对安装目录中的同路径地图，未匹配时从关联文件读取并再次校验后直接挂载内存。结束后保持最后画面直到用户返回；未知非时间片记录或动作明确报错并返回列表。未执行本地双端及实际播放验证。

回放名称包含 `MEgine LAN v1 sha256=<64位摘要> | peer=<玩家编号> | ` 标记，用于识别自研时间片和同构建校验，不是防伪签名；可执行文件改变后拒绝播放。资源从原公共与地图归档直接读取，不写地图解包目录。视频或模型过场期间继续处理记录的时间片，最小化暂停并恢复本地播放时钟。该局域网路径通过自研标记识别录像，原版录像及原版客户端互通仍待支持。地图脚本中的本地分支、音频／输入、时间片动作缺失、观察者和播放界面一致性仍需实现或验证。

原版 1.27 Game.dll 的 REA 证据表明对象首字包含池及槽位，第二字校验对象代际，槽位以空闲链复用；池由多类游戏内部对象共享，存在指定编号的构造路径。证据 `ev_c17c365fa42314807f09adc1b8b24bc62536f15b3f616cef0a1e3447f647c271`、`ev_61f46c26c23622ea857e7fb8819386a7d086c146968a71e6bd3336102c3daa60`，原件与分析记录位于 `tmp/docs-artifacts/war3/object-id-research/initial-state-and-classes-1028.md`。当前对象分配次序尚不完整，不能用自研 ordinal 解释原版回放；1.26 样本的第一个选择对象即无法由自研映射解析。

进一步定向分析表明，`CUnit` 基类构造时将对象引用双字设为 `0xffffffff`。单位创建路径 `0x6f65a35e` 调用 `0x6f1012b0`，后者经虚函数初始化对象；`CAgentBaseAbs` 的关联路径 `0x6f0f3470` 发出类型 2 回调。初始化代码将该回调设置为 `0x6f0307e0`；其类型 2 分支创建对象并关联池对象，`0x6f038110` 将池对象 `+0x14/+0x18` 两字写入目标对象 `+0x0c/+0x10`，选区构造 `0x6f69f85a` 读取后者。推定的 CUnit 虚表对应关联函数 `0x6f64e030` 还初始化多个组件。以上链路依赖系统初始化、虚表绑定和调用参数，静态指令不能证明完整对象创建次序；路径对象等其他类型共享池，仍不能按单位创建顺序推算原版回放 ID。下一步需追踪世界初始化、各类组件及释放的实际分配顺序，并以固定版本真实回放校验。复现命令与原始指令索引位于 `tmp/docs-artifacts/war3/object-id-research/link-chain-1030.md`；已有构造和池证据为 `ev_cc56c81306e82a53bf51595cc695317ab2fa0eb93cdad619de40c43eb0471af2`、`ev_09ce3878f33272b5fc35d2cd2d96c9c19314e97e2ceb3739445ee7c9b188f4d7`、`ev_21fc510af86c542f8eb30c4afa07641f29737ddcd65d51671c14f2b711568596` 和 `ev_c75f78c81722f824bfe57f295202d8dcbf9ad9c105a3aac0b7871367717b7b19`。

## 局域网接收地图的回放副本

仅为局域网接收、未与本机 `Maps` 匹配的地图记录原始归档 SHA-256；退出保存回放时先检查本机是否已有完全相同的原图，若没有则在 `%LOCALAPPDATA%/MEgine/War3/Replays`（或 `MEGINE_WAR3_USER_DIR/Replays`）与回放同目录保存 `<回放名>.w3g.<SHA-256>.map`。内容是原始 W3M/W3X 归档，不解包或转换资产。相同摘要且实际文件内容一致的已保存副本优先使用 NTFS 硬链接，硬链接不可用时写独立副本；不会修改或删除游戏安装目录中的文件。原地图副本写入失败时保留已保存的回放，并提示地图副本保存失败。

从回放界面删除已识别的回放时同时删除其同名副本链接；其他硬链接仍保留数据。副本或回放在系统外部被移动、删除或更名时需要成对处理；无法解析的回放不能在界面中删除，以免误删关联文件。系统中断、文件占用、权限或外部更改可能导致副本不完整或无法清理，播放会拒绝摘要不符的副本并显示错误；不会自动扫描或删除其他用户文件。若安装目录中的匹配原图后来被删除，而保存时未创建副本，则仍需恢复原图。地图副本写入和重复回放、并发保存／删除、硬链接回退、失败保留、切图释放、原版互通与实际播放均待功能阶段验证。

回放界面将删除和关联地图校验交给原有后台线程，界面保持刷新并显示处理状态；校验期间暂停其他回放选择和返回操作。回放选中时计算原文件摘要，删除前在受限句柄上复核，文件发生变化则保留；地图以禁止并发写入／删除的句柄分块计算 SHA-256，仅对一致、非重解析的文件通过同一文件句柄删除链接，不一致或无法读取时保留并提示。回放删除与地图清理失败分别报告。关闭客户端时，后台任务在删除提交前检查取消；提交回放删除后继续尝试清理已校验地图。磁盘读操作及回放解码本身不可即时取消，系统强制终止、权限和多进程边界仍待实际验证。

结算保存使用原 `ScoreScreenSaveReplayButton` 与 `SaveReplayPanel`，只在已有实验局域网录制时间片时启用；名称由用户输入并校验，不覆盖已有文件，录制不完整或主机离开的文件名带 `-partial`。保存成功后切换为原 `REPLAY_SAVED` 状态；保存失败可修改名称重试，未保存退出沿用自动保存。原版布局、文件选择／删除、同名处理、实际窗口、失败回退及关联地图副本留待阶段验证。

结算面板的原 FDF 根帧挂接可通过 `cmake --build --preset release --target war3_browser_tests --parallel 8` 编译后执行 `./build/windows-x86/bin/Release/war3_browser_tests.exe "E:/Program Files (x86)/dzclient/Game/Warcraft III Frozen Throne" "../../tmp/docs-artifacts/war3/score-replay" score_replay_fdf_attach`。该检查在本机原资源和 D3D9 下通过（1 通过、0 失败；产物位于 tmp/docs-artifacts/war3/score-replay-fdf/），仅覆盖控件构造和绘制，不证明回放数据、窗口输入或原版兼容。

播放画面显示已播放与记录总时长。总时长累加完整时间片，已播放时长仅计成功执行的时间片；暂停、倍速和分片不会凭墙钟提前改变计数。原版回放、长回放和更多实际窗口条件仍待阶段验证。

地图脚本 `DoNotSaveReplay` 在当前会话禁止保存回放：main 期间调用会跳过实验局域网录制器创建，之后调用则在保存前丢弃录制数据，结算界面不启用保存入口；此状态仅作用于本地保存，不改变同步命令或已有文件。原版该 native 的自动／手动保存边界和实际地图行为待对照。

对照 1.27 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）的只读反汇编显示，`DoNotSaveReplay` 注册入口为 `0x6f1dfee0`，沿调用链进入处理函数；该函数在取得文件对象后调用 `DeleteFileA` 并清除内部状态。原始指令记录位于 `tmp/docs-artifacts/war3/replay-native-1030/`。该静态片段不能确定用户手动保存及调用后的完整录制行为，仍需原版运行对照。

## 单人遭遇战录像

支持符合脚本检查的新开单人遭遇战。普通胜负结算和确认退局时，可以通过计分界面命名保存到用户目录的 `Replays`。同名保存保留旧文件，修改名称后可以再试。回放从单人菜单进入，沿用暂停、单步、调速和 Esc 返回，结束时停在最后一个战场画面。

单机 W3G 使用独立的产品编号。记录地图相对路径、地图和实际挂载基础归档的 SHA-256、可执行文件摘要、初始种子、游戏版本、本地席位和玩家配置。加载同一份已验证的地图字节，恢复设置后执行一次地图 main。按原顺序重放玩家命令、命令面板事件、主动退局和每次模拟推进的原始浮点参数。录制和播放在相同的模拟操作边界刷新本地视野。消费端核对命令执行结果、结算时间、胜负和部分模拟状态摘要。

录像覆盖通过检查的经典 JASS 地图和活跃电脑席。AI 与地图共用模拟调度器，玩家设置和随机流由已有初态恢复。`StartMeleeAI` 加载的实际 AI 模块在初始化前检查。录制和播放在同一操作边界更新本地视野和共享侦测缓存。地图边界、边距和本地化查询使用已校验归档中的数据。

预加载模块在执行前检查。录制采用普通对局的文件解析规则。遇到用户目录预加载脚本或检查不通过的模块，正常对局继续，录像不能保存。播放遇到这些情况会中断并显示原因。2SAJ／Lua、磁盘缓存、实时音频查询、本地镜头查询、动态 ExecuteFunc 和其他未接入输入仍受脚本检查限制。战役、已恢复存档、重开对局和已经执行手动存档或快速存档的当前对局也不提供录像保存。脚本调用 `DoNotSaveReplay` 后，本局的保存入口保持禁用。
