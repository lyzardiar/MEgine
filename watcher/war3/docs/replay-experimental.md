# 自研局域网回放

启用 `--experimental-local-lan` 的同构建对局在载入完成后记录成功应用的时间片。正常离开或连接中断时将已有时间片保存至独立用户目录的 `Replays`，默认 `%LOCALAPPDATA%/MEgine/War3/Replays`，遵循 `MEGINE_WAR3_USER_DIR`。采用唯一文件名、临时文件和原子发布；录制或保存失败写入日志并显示提示，不中断运行中的对局。记录包含地图校验、槽位、玩家、种子及时间片；不含聊天、离开原因、校验和结算记录，断线保存是截至断线的截断内容。进程异常退出或未走离场路径不会自动保存。

单人菜单的原版回放按钮打开回放列表。选择本客户端记录后，校验文件中的可执行文件 SHA-256 与当前构建，校验本机 `Maps` 中同路径地图并在内存中准备会话，通过载入界面启动一次 main；回放以时间片驱动模拟，视图只读，空格暂停／继续、Esc 返回列表。网络下载的地图若未在本机安装目录 `Maps` 的同路径存在，当前不能播放。结束后保持最后画面直到用户返回；未知非时间片记录或动作明确报错并返回列表。未执行本地双端及实际播放验证。

回放名称包含 `MEgine LAN v1 sha256=<64位摘要> | ` 标记，用于识别自研时间片和同构建校验，不是防伪签名；可执行文件改变后拒绝播放。资源从原公共与地图归档直接读取，不写地图解包目录。该入口只接受自研标记，不支持原版回放或与原版客户端互通；地图脚本中的本地分支、音频／输入、时间片动作缺失、观察者和播放界面一致性仍需实现或验证。

原版 1.27 Game.dll 的 REA 证据表明对象首字包含池及槽位，第二字校验对象代际，槽位以空闲链复用；池由多类游戏内部对象共享，存在指定编号的构造路径。证据 `ev_c17c365fa42314807f09adc1b8b24bc62536f15b3f616cef0a1e3447f647c271`、`ev_61f46c26c23622ea857e7fb8819386a7d086c146968a71e6bd3336102c3daa60`，原件与分析记录位于 `tmp/docs-artifacts/war3/object-id-research/initial-state-and-classes-1028.md`。当前对象分配次序尚不完整，不能用自研 ordinal 解释原版回放；1.26 样本的第一个选择对象即无法由自研映射解析。
