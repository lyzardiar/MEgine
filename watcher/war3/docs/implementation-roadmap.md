# 客户端集中实现清单

目标为独立还原Warcraft III 1.27.0.52240完整客户端。2026-10-26起按可运行流程组织实现，持续覆盖功能清单，再集中测试修正。完整范围及最终证据要求仍以 `acceptance.md` 为准。

## 阶段A：选图到可操作地图

- [x] 源单位/物品定义与w3u/w3t覆盖，基础创建/属性/分组，普通数字声音与天气实例状态。
- [x] 1/32秒模拟基础步进、计时器/触发器/事件与BootyBay原main初始化。
- [x] 原W3E地形/水面、DOO装饰物、脚本单位/物品模型及空间裁剪。
- [x] 原版载入FDF/MDX与进度、开始游戏、退出并返回选图。
- [x] 源相机六档有界缩放、平移、选择反馈、WPM基础寻路与移动/停止/保持命令。
- [x] 运行中单位外观/动画、模型/图标后台读取和分帧GPU交付代码。
- [x] 区域/接近/聊天事件、基础物品栏、视野状态/GPU投影、typed hashtable和会话缓存。
- [x] 显式静音的容器时长/声音状态，不依赖声音输出设备。
- [ ] 补齐代表地图初始化仍缺少的native及对象消费者，接续DotA商店库存/购买。
- [ ] 集中验证三图、完整输入、取消/失败恢复、持续运行与切图释放，修正失败项。

以上勾选表示对应实现已接入实际流程，未表示完整客户端或原版一致性验收通过。BootyBay已运行真实地图画面；完整范围和本阶段待测项见[场景流程](world-rendering.md)及W028–W030测试队列。

## 阶段B：完整对战与自定义地图

- [ ] 路径、碰撞、寻路、编队、命令与确定性随机数。
- [ ] 四族经济、建造、生产、战斗、英雄、技能、物品、科技和胜负。
- [ ] 完整JASS/AI native、句柄、事件/调度、DotA与自定义对象消费。
- [ ] 完整音频、昼夜/天气、动画/灯光/粒子与游戏HUD。
- [ ] 完成实现后集中进行对战及自定义地图回归并修正。

## 阶段C：完整客户端与最终验收

- [ ] ROC/TFT战役、任务、过场、配音与进度。
- [ ] 原版存档/回放与局域网同步。
- [ ] OpenGL、完整界面和原版画面/操作一致性。
- [ ] 集中进行冷/热载入、帧耗时、内存、持续切图和无解包增长检查。
- [ ] 在直接加载完整验收后核对边界并清理旧转换缓存。

实现期间只做开发必需编译、静态差异检查及阻塞问题的最小复现。原件数值/时序的精确核对、专项夹具和重复回归进入本阶段待测队列，避免打断主流程实现。对尚未具备真实消费的模块保持部分完成状态，不将接口数量当作玩法完成度。
