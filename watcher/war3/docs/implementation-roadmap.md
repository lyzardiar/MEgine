# 客户端集中实现清单

目标为独立还原Warcraft III 1.27.0.52240完整客户端。2026-10-26起按可运行流程组织实现，持续覆盖功能清单，再集中测试修正。完整范围及最终证据要求仍以 `acceptance.md` 为准。

## 阶段A：选图到可操作地图

- [ ] 原版对象定义、地图对象覆盖，单位/建筑/物品与放置数据。
- [ ] CreateUnit/CreateItem、基础属性和分组，普通声音与天气实例，地图main所需native。
- [ ] 模拟步进、计时器/触发器与事件，地图初始化生命周期。
- [ ] 地形/水面/装饰物和单位模型渲染，原版相机与选中/命令输入。
- [ ] 原版载入界面与进度，开始游戏、退出并返回菜单。
- [ ] 完成实现后集中检查代表地图、输入、切图释放及失败恢复，修正阻塞。

## 阶段B：完整对战与自定义地图

- [ ] 路径、碰撞、寻路、编队、命令与确定性随机数。
- [ ] 四族经济、建造、生产、战斗、英雄、技能、物品、科技和胜负。
- [ ] 完整JASS/AI native、句柄、事件/调度、DotA与自定义对象消费。
- [ ] 完整音频、昼夜/天气、动画/灯光/粒子与游戏HUD。
- [ ] 完成实现后集中进行对战及自定义地图回归并修正。

## 阶段C：完整客户端与最终验收

- [ ] ROC/TFT战役、任务、过场、配音与进度。
- [ ] 原版存档/回放与局域网同步。
- [ ] OpenGL、完整界面和原版画面/操作一致性。
- [ ] 集中进行冷/热载入、帧耗时、内存、持续切图和无解包增长检查。
- [ ] 在直接加载完整验收后核对边界并清理旧转换缓存。

实现期间只做开发必需编译、静态差异检查及阻塞问题的最小复现。原件数值/时序的精确核对、专项夹具和重复回归进入本阶段待测队列，避免打断主流程实现。对尚未具备真实消费的模块保持部分完成状态，不将接口数量当作玩法完成度。
