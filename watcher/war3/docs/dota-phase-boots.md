# 风步负淡入时间与相位鞋

`AOwk` 风步允许有界负淡入时间，负值的风步状态提供源移动加成与现有单位穿行，但不触发隐形或隐身攻击加成，也不因隐身而禁止自动索敌。正值风步沿用现有淡入、破隐与攻击流程。当前负值不隐形的语义依据相位鞋的地图配置及预期表现，仍需固定版原件对照。

DotA_v6.83d 原图 `I0GJ` 的能力 `A12W` 设置淡入时间 -1、移速加成 0.16；隔离会话直接创建英雄与物品后使用，观察 1.16 移速倍率、可见、物品冷却及到期恢复，记录 `tmp/docs-artifacts/war3/dota-phase/after.log`。Win32 Release 客户端及 mobility 测试程序编译通过；普通风步的移动、破隐与攻击载荷检查 1 通过、0 失败，不加载 Game.dll。

阶段核对不同负值、零淡入时间、其他隐身来源叠加、施法与攻击中断、单位穿行／地形阻挡、自动索敌与弹道、物品获取和替换、真实窗口及原版和联机。
