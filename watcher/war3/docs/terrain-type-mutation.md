# 地图地表类型修改

`SetTerrainType` 修改当前会话的 W3E 地表角点槽位和变体，`GetTerrainType`／`GetTerrainVariance` 随即查询同一数据；共享地图和原安装只读，切图时会话状态与显存释放。对已加载地图的地表类型，从对应 Terrain.slk 与 BLP 源图读取本地图已有材质，无需生成磁盘资产。

按地表角点记录受影响的 16×16 区块，覆盖相邻混合单元；实际可见区内以每帧最多四个区块及约 3 毫秒调度重建 CPU 合成 atlas、顶点和 GPU 资源，沿用现有多层 alpha 掩码、变体与原场景的高度。每块独立纹理按当前不同混合项合并，累计动态纹理限制为 256 MiB；无变化时不重建。荒芜区域同时标记脏，使用更新的变体。悬崖覆盖角点仍使用已有悬崖地表材质，悬崖纹理及几何不会因该接口重建。

当前实现支持地图加载时声明的地表类型；不在地图 tileset 内的类型明确失败。面积支持 1–256、形状 0 圆形／1 方形，-1 变体从会话随机数选取，0–31 使用给定值，其他参数明确失败。圆形/方形边界、面积对齐、随机序列、对不存在类型的原版行为及悬崖处理均为当前实现，尚未与原版确认；加载的多个地图不共享更改。

待功能阶段验证：DotA 中类型／变体切换、原图边界与半格位置、圆／方多尺寸、显隐与镜头移动、原始／混合／荒芜／水面／悬崖区域、连续脚本调用及区域预算、随机种子／双客户端、CPU/GPU 资源和设备恢复，逐项对照 1.27 的面积及变体规则。Win32 Release 客户端增量编译通过，尚未运行。
