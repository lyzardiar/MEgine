# 亡灵第四关失效单位无敌设置

`SetUnitInvulnerable` 对空或已移除单位不执行操作；有效单位仍按传入布尔值更新实际无敌状态。亡灵第四关原图尝试从战役 gamecache 恢复阿尔萨斯时，先对恢复结果调用该接口，再检查空值并创建默认英雄；缺少对应缓存时，此前空句柄异常阻止了默认分支。

未携带前关 gamecache 的 `Undead04.w3m` 静音隔离探针在修改前于 `war3map.j:1616` 报空句柄异常，修改后进入默认英雄路径，开场恢复玩家控制并空闲推进至 400 秒。独立 x86 探针编译了本次修改并链接既有核心快照；记录位于 `tmp/docs-artifacts/war3/undead-next-1031/undead04.log` 与 `undead04-after.log`。探针不覆盖真实操作、携带有效 gamecache 的跨关、战斗或原版行为对照。

待集中验证：空、已移除及有效单位设置无敌和取消无敌，缺失及存在跨关缓存时的开场、窗口和完整关卡，核对原版句柄与事件语义。
