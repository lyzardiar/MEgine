# 实验对局菜单动作录制

实验局域网对局中，玩家通过鼠标或热键打开英雄技能／建筑子菜单时，界面将对应的经典 0x66／0x67 动作经现有时间片发送路径提交；发送成功才打开本地子菜单，等待选区同步或发送失败时显示提示。收到的动作进入逐玩家展示状态，并由现有实验回放录制及播放消费；动作不改变游戏单位或命令模拟。

选区改变、子组改变或下达命令的已有记录可关闭回放菜单，已有回放中的 Esc 动作也可关闭菜单。取消按钮、右键及菜单内 Esc 关闭尚无单独记录，回放可能保持子菜单直到下一条关闭动作；这些交互及原版确切语义继续实现或对照。本次未编译或运行。

待集中验证：主机和客机分别用鼠标／热键打开两类菜单，动作的网络回显和保存回放，菜单关闭／选区／命令竞争、发送失败／同步等待、回放视角，双端模拟确定性及原版 1.27 动作序列。
