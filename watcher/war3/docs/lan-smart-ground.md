# 联机与回放的地面智能命令

时间片中的点目标 `smart`（订单 851971）可通过原有玩家命令消费者移动选中单位；0x11 点目标和 0x12 空对象目标都进入该路径。订单、坐标与排队标志在编码、解码、命令队列及实际移动事件中保留，建筑和具有集结能力的对象复用现有智能点目标分支。普通 `move` 继续使用 851986。非有限坐标与不匹配的发出订单仍由原有检查拒绝。

此实现消费已有经典动作结构，不改变对象编号映射或提供原版互通保证。固定参考 [w3g_actions.txt](https://github.com/nielsAD/gowarcraft3/blob/f13251b6caed199c3347214f4591e7ccaa96c7c7/file/w3g/w3g_actions.txt) 说明 0x11／0x12 动作结构；订单号与消费以项目现有 `order_ids.inc` 和 `ScriptSession::moveUnit` 为依据。1.27 原版实际报文、点目标智能命令对建筑及特殊单位的语义尚未对照。

待集中验证：编码／解码 0x11 与空对象 0x12、单选／多选、编队与阻挡、Shift 排队及中断、普通 move 回归、建筑集结、非法坐标／订单、删除与授权变化、脚本订单事件、实验双端及回放、真实 1.27 行为。`tests/order_queue_tests.cpp` 新增消费者断言，本次未编译或运行。
