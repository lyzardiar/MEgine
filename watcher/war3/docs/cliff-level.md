# 地形悬崖层查询

`GetTerrainCliffLevel(x, y)` 已连接地图 W3E 的悬崖层级：以地图原点为参考，将坐标除以 32 并向零取整，再转换到最近的 128 单位地形角点，读取角点悬崖字节的低四位。网格索引越界时返回 -1；原点负方向不足 32 单位的坐标向零取整后仍为第一个网格。查询只读取会话中的地形，不生成解包文件。

本机 1.27 `Game.dll` SHA-256 为 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`。REA/Rizin 观察入口 `0x6f1e5920` 调用 `0x6f76e560`，后者在 `0x6f726900` 查询地形网格；原版按 `0x6f7329d0` 的整数规则换算角点并读取低四位，越界返回 -1。证据为 `ev_9ee30e3d767787d42e6667dce3cfd8b47ebc956888579466d7c317fc3cb6cdc2`、`ev_066663ffb51e526508906433c9701139dfd6b95532678bf9f530637936ac9048`、`ev_5af1dc273d54a20b4c0bdac91ef35b5046aa7132759c241ee563e127d4f2eb83`、`ev_51defbf8d2d5fe7a8005002dd9139b13d255d404f5900ff62bc40ecf35c9f90f`。

可行走可破坏物的占地已接入稀疏覆盖网格：按对象定义的 `walkable`、`cliffHeight`、生死占地纹理和位置／角度构造，重叠时查询最高层；死亡／复活替换占地，移除对象时清除其覆盖。纹理像素中红蓝通道最低位或绿色非零的格子加附加层，其他格子保留覆盖区域中心的基础层。建立覆盖时，附加层按 `cliffHeight` 和中心已有模型表面相对地面的高度差计算，并排除当前对象。下方对象后续改变时，依赖它的覆盖尚未重新计算；原版地面采样模式、生死占地更新时机、旋转映射和精度仍待核验。此查询不改变单位寻路，动态桥面通行仍待实现。

会话从地图覆盖／公共归档按需读取经典 MDX，使用 CPU 骨骼动画和模型三角面作垂直射线求高；按可行走对象占地索引候选，死亡／复活更新索引，移除时清除。`GetLocationZ` 与画面的地面／两栖单位、选择圈、单位跟随特效及对应弹道共享模型表面；画面仍按移动类型合并现有地形／水面高度。模型几何按会话缓存，无需 GPU 上传或磁盘解包。当前包含所有 geoset，透明面、死亡动画、混合动画、模型碰撞筛选及其他地形／水面高度的原版语义仍待核验。

当前网格尺寸按 W3E 宽高推定，原版内部尺寸与此推定的关系、浮点减法的精确舍入、边界与异常坐标、坡道、地图覆盖和动态覆盖仍需对照；当前结果不能视为完整原版验收。阶段验证应覆盖不同层级地形角点、32／64／128 单位边界、四周越界、坡道、桥梁生死与重叠、纹理零格、动态场景、脚本调用和真实地图。

## 原版覆盖层依据

原版维护可破坏物的可行走覆盖项。`0x6f6a20d0` 根据对象类型数据检查资格，调用 `0x6f762750` 在全局管理器中按对象增删覆盖项；条目持有对象引用，并在新增时调用 `0x6f7670f0` 建立网格。该函数通过模型的 `pPathingFootprint` 获得占地数据，以覆盖矩形中心的地形层作为基础层，通过 `0x6f6a4370` 计算附加层，并按占地遍历回调 `0x6f770b30` 写入网格。查询 `0x6f7654c0` 对所有包含查询点的覆盖项取最大值。原版对象定义读取 `walkable` 与 `cliffHeight`，覆盖项类型有 `WalkableInfo` 标识。

占地遍历器读取 footprint 内部字节数组并逐格传给回调；字节非零时回调在基础层上增加附加层，零时写基础层。证据 `ev_d7e510f9a5579d5725f063fe27e886cfbfbaae81419b64b128f73ea6a060d673`、`ev_9018529bd4deac9d58af8e3645f21ed63f3e7799371611446a7d2dad8a76b410`。该字节与纹理通道及现有路径阻挡位的关系尚未证实。
