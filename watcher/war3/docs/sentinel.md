# 女猎手哨兵

原版女猎手的 `Aesn`／`Aesr` 接入树木目标、原订单与科技前置，复用现有施法、冷却和命令事件。施法后按源模型速度向目标树移动，飞行中使用源飞行视野半径；到达后使用源盘旋视野半径，并提供隐形侦测。猫头鹰模型使用源 Missileart，盘旋高度取源 DataC；目标树死亡、隐藏或移除时清理视野与模型，切图时随会话释放。

原版 `War3Patch.mpq` 的 `Units/AbilityData.slk` 将飞行视野、盘旋视野、高度分别定义为 DataA／DataB／DataC；`Aesn` 的原值为 100／900／275，`Units/NightElfAbilityFunc.txt` 指定 `sentinel` 订单、`Resc` 前置及猫头鹰模型。运行时使用地图覆盖及公共资源。

当前飞行轨迹、高度、侦测掩码、同树多个哨兵、销毁／复活行为为近似或尚未完整实现。实际模型动画、共享视野、目标树被攻击／采伐／移除、暂停、切图、网络和原版精度均待阶段对照；不能将本项视为完整原版验收。

照明弹点目标和哨兵树木目标接入自研局域网动作编码与时间片消费，原版对象 ID 互通和实际双端仍未验证。

`DataD` 读取源猫头鹰数量：正数作为每个单位、每个能力实例的有限释放次数，成功释放时扣除，耗尽时拒绝命令并禁用按钮；零为无限。取消施法、失效目标不扣次数，移除并重新获得能力会重置余量。原版 `CAbilitySentinel` 的 0x6f4fa3b0 初始化正数余量并以零设置无限标志，其虚表中的 0x6f4ee3d0 在释放阶段递减余量并于耗尽时刷新界面，静态指令记录在 `tmp/docs-artifacts/war3/sentinel-count-1030/original.txt`。自定义多等级切换、剩余数量显示、存档、复活、事件重入及原版行为尚待集中验证；新增 `war3_stealth_tests ... sentinel` 场景尚未执行。
