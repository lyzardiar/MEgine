# 女猎手哨兵

原版女猎手的 `Aesn`／`Aesr` 接入树木目标、原订单与科技前置，复用现有施法、冷却和命令事件。施法后按源模型速度向目标树移动，飞行中使用源飞行视野半径；到达后使用源盘旋视野半径，并提供隐形侦测。猫头鹰模型使用源 Missileart，盘旋高度取源 DataC；目标树死亡、隐藏或移除时清理视野与模型，切图时随会话释放。

原版 `War3Patch.mpq` 的 `Units/AbilityData.slk` 将飞行视野、盘旋视野、高度分别定义为 DataA／DataB／DataC；`Aesn` 的原值为 100／900／275，`Units/NightElfAbilityFunc.txt` 指定 `sentinel` 订单、`Resc` 前置及猫头鹰模型。运行时使用地图覆盖及公共资源。

当前飞行轨迹、高度、侦测掩码、同树多个哨兵、DataD 猫头鹰数量和销毁／复活行为为近似或尚未完整实现。实际模型动画、共享视野、目标树被攻击／采伐／移除、暂停、切图、网络和原版精度均待阶段对照；不能将本项视为完整原版验收。

照明弹点目标和哨兵树木目标接入自研局域网动作编码与时间片消费，原版对象 ID 互通和实际双端仍未验证。
