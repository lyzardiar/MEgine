# 选中单位头像

选中单位时，头像框优先使用该单位当前模型的 `_Portrait.mdx`，通过现有后台资源流送按需读取；使用模型首个原相机和 `Portrait` 动画，缺少该动画时使用 `Stand`。头像和场景模型共用单位的队伍颜色及颜色过滤，形态更换时按当前模型重新选择头像。头像资源或相机不可用时，在同一头像框内显示单位图标，游戏对局与单位选择继续运行。

头像在底部控制台纹理之前绘制，由控制台纹理覆盖边缘；渲染只清除头像矩形内的深度，并使用状态块恢复设备状态及原视口。当前头像矩形依据现有界面和窗口截图定位，等待与原版逐族对照；完整人脸说话动作、头像音效、相机选择、多选切换时序及动态皮肤仍待实现或核验。

Win32 x86 MSVC 隔离编译通过。对原人族控制台 BLP 的头像区域做 10,000 点采样，8,190 点透明、1,810 点不透明；该结果仅说明存在透出区域，不证明其他种族或画面完整一致。待验证真实窗口选择／多选、头像资源加载及缺失、不同窗口和 DPI、队伍颜色、动画与静态图标回退、相机／深度与主视口、切图资源释放、状态块开销及原版画面对照。
