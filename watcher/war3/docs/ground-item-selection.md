# 地面物品选择

游戏场景支持普通左键选择可见的地面物品，清除当前单位选择，显示物品图标、名称、生命及场景选择圈；选择单位或空地会清除本地物品选择。物品被拾取、隐藏、销毁或进入不可见区域时不再显示为选中。当前颜色、大小与 HUD 位置沿用客户端已有绘制参数，原版视觉与操作细节待对照。

经典动作 `0x1c` 的 flag 和两段 32 位对象 ID 在编解码中原样保留；网络／回放消费者通过对象解析器确认物品类型，将已知 `0x04` 选择关联到对应玩家，并要求同一动作序列先完成单位取消选择。其他 flag 的含义尚未证实，消费时明确拒绝。实验性局域网左键选择会先排队取消单位选择，再发送 `0x1c` 并等待网络确认；不把本地句柄冒充原版对象 ID。回放能否解析原版对象仍依赖对象 ID 映射，当前不能据此声称原版回放完整兼容。

格式依据 [blue 与 nagger 的 w3g_actions.txt v1.00](https://github.com/nielsAD/gowarcraft3/blob/f13251b6caed199c3347214f4591e7ccaa96c7c7/file/w3g/w3g_actions.txt)，固定提交 `f13251b6caed199c3347214f4591e7ccaa96c7c7`；该资料对 flag 仅记载“已观察到 0x04”，并非原版 1.27 协议实证。真实原版报文、其他 flag、拖选／Shift 以及游戏 HUD、视觉、音效和多端时序留待阶段验证。
