# 电脑单位的吞噬、寄生和死亡之指

电脑单位在已有可见战斗目标时，可对施法范围内的合法敌人使用吞噬 `Adev`／`ACdv`、寄生 `ANpa` 和死亡之指 `ANfd` 及其地图派生。选择依据已实现的源目标、施法者魔法、冷却、科技和禁用状态；候选按等级、最大生命、距离和句柄排序。寄生跳过已有相同 Buff 的目标，吞噬通过真实货舱、消化目标和源目标掩码排除不合条件对象，死亡之指复用真实伤害与事件。选中后沿现有施法入口执行，费用、事件、死亡／召唤和战斗命令恢复由相应消费者处理。

排序和交战条件是当前策略，尚未核对原版 AI；AI 只会在已有可见战斗目标时选择这些技能。尚未编译或运行。集中验证空／满货舱、目标类型和单位等级、不可见／魔免／无敌、已寄生与多个技能来源、对象覆盖、施法中目标失效、消化／毒伤致死、回调重入、AI 长局及双端确定性，并对照 1.27 决策与时序。
