# 昼夜模型光照的计算复用

没有骨骼变换轨道的模型，在没有 Billboard、目标朝向或动作混合变化时复用已有姿态与蒙皮；骨骼轨道、全局动画、朝向和混合仍按原有时钟更新。只更新粒子／附件而不绘制模型几何时保留骨骼姿态更新，跳过几何顶点蒙皮。世界光或启用的模型内光源需要实际受光网格时才生成骨骼法线。

仅有 DNC 世界方向光的模型可复用最后一次顶点照明；命中要求骨骼姿态代次、法线变换的 3×3 部分和 DNC 方向／颜色完全一致。平移不会改变方向光法线结果，因此不作为缓存条件；旋转、非等比缩放、动画、光源变化以及模型内光源都会按当前状态重新计算。方向光和环境光无需世界顶点位置，只有存在点光源时才计算位置。缓存只保留当前模型的最近一项，不增长场景对象缓存。

绘制层仅在本次存在有效世界或模型光源时消费光照结果，避免关闭光照或切换到没有活动光源时沿用上次计算的颜色。

Win32 x86 Release 产品编译通过；未执行 GPU 画面或性能测试，也未量化帧耗时。阶段验证需覆盖静态与骨骼动画、不同朝向／缩放／平移、Billboard、目标朝向和混合、几何隐藏再显示、光源开关及变化、点光源、多个材质层、场景切换与 Amazonia 密集地图；对照缓存前后的画面和 CPU／帧耗时。
