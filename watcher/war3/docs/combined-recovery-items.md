# 复合即时物品

自定义物品可以组合多个即时生命恢复 `AIhe`、魔法恢复 `AIma` 及同时恢复生命和魔法的 `AIre` 派生能力，即时金币 `AIgo` 和木材 `AIlu`，永久属性、生命、攻击、经验和等级能力，`AIgl` 科技符文，以及 `AIil` 幻象。使用时按能力列表顺序读取地图覆盖后的数值，检查库存权限、共享冷却、次数和魔法，在存在资源收益、永久效果、科技效果、有效幻象目标或至少一项恢复有缺口时一次支付与消耗、依次应用科技、永久效果、幻象、恢复与资源收益并派发一次物品使用事件。符文沿用拾取消费流程；生命事件回调移除或转移物品时仍对存活的原单位应用魔法效果，单位死亡／销毁后不再作用于已失效对象。

当前费用按各项求和、共享冷却取最大值，受益者仅限使用者；这属于实现选择，必须与原版对照。其他主动能力的组合仍明确报错，不忽略未知能力。物品动画、音效、耗尽／转交与事件时序及多人同步尚待阶段验证。

原版 `dtsb` 的 `AItp,AImv,AIsr` 分别是一个主动传送、75 魔法上限和法术减伤两个被动，现有单主动加被动流程可识别；该事实不代表原版地图和原件行为已验收。自定义组合夹具 `tests/generate-combined-item-fixture.py` 写入 `tmp/docs-artifacts/war3/combined-item/`，包含继承原能力的地图数值覆盖及使用事件回调，`war3_control_tests ... item-combined` 覆盖单次费用／冷却／事件、满生命或满魔法、使用回调删除、生命变化回调删除物品并易主，以及未知组合拒绝；最小检查 1 通过、0 失败，未加载 Game.dll。Win32 Release 客户端与 control 目标编译通过。


本次扩展新增三项恢复和 `AIre` 混合能力夹具，Win32 Release `war3_control_tests` 编译通过，功能测试待批次执行。多项即时效果的应用顺序、逐项生命／资源事件及费用／冷却计算尚需原版对照。


金币和木材进入实际玩家状态及状态变化事件，按能力次序与恢复效果执行；每项回调后检查使用者生命周期。金币／木材组合及回调重入待功能批次和原版对照。


永久效果使用已有 `AIam`／`AIim`／`AIsm`／`AIxm`、`AImi`、`AIaa`、`AIem` 和 `AIlm` 消费者；英雄属性及经验／等级要求英雄，英雄要求及源数值范围在扣费前检查。组合中的生命及玩家资源回调可能改变后续效果的执行环境，死亡或移除后不再处理余项。原版多能力派发与事件顺序仍待核对。


科技符文按源能力各级的科技类型和数量更新玩家研究，保留既有科技上限和单位刷新；扣费前检查科技定义与支持的效果。混合物品和符文的目标规则、回调、费用及原版行为待功能批次验证。


复合即时物品隔离会话批次 `item-combined` 1 通过、0 失败，覆盖新增三项恢复、`AIre`、资源、永久属性、非英雄拒绝及科技组合，并复核旧双恢复与回调。首轮夹具 JASS 声明顺序失败，修正后重跑通过；具体日志和未覆盖场景见[测试队列](testing-batches.md)。


`AIil` 可选择自身或可见友方单位；使用前核对目标、范围及落点，实际创建沿用现有幻象与限时生命流程。混合物品的其他即时效果作用于使用者及其玩家，执行幻象前重新核对目标状态；目标失效时跳过幻象。原版混合目标规则、失败处理和事件次序待验证。


复合即时物品支持 `AIvi` 隐身，使用者复用隐身状态、淡入及持续时间处理，可与资源等即时效果混合；目标规则、淡入与失效、攻击打破隐身及原版事件顺序待功能批次验证。
