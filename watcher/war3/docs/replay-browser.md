# 回放选择界面

`ReplayBrowser` 使用原版 `UI/FrameDef/Glue/ViewReplayScreen.fdf` 的标题、文件列表区域、地图信息区域与确认／返回按钮。用户回放从独立用户目录 `Replays` 读取，默认位于 `%LOCALAPPDATA%/MEgine/War3/Replays`，也遵循 `MEGINE_WAR3_USER_DIR`。首次进入创建目录，并核对其不处于原版游戏安装目录。目录列表只包含子目录和 `.w3g`，跳过重解析点，支持滚轮、方向键、翻页、返回上层和刷新；选中文件在后台读取 W3G 并显示名称、地图、玩家数和时长。选中回放可通过确认按钮或双击交接；双击时若后台仍在读取，读取成功后自动继续播放，切换文件、进入目录、返回、删除或读取失败会取消该请求。

删除通过 Delete 键打开确认，确认后仅删除所选用户回放文件；不递归删除目录，删除前重新检查用户目录边界、文件类型和重解析点。切换选择时后台请求按代数丢弃旧结果；读取受现有 W3G 文件和解压预算限制。后台单次文件读取／解压不能中途取消，关闭界面可能等待其结束，网络路径与高密度目录的性能待验证。

界面 `draw` 在确认播放时返回 `PlayReplay`，随后由调用方的 `takeSelection` 取得路径和已解析的只读 `Replay` 快照；返回时返回 `CancelButton`。主菜单已接入本界面，自研同构建局域网记录可进入地图准备与时间片播放，详见[自研局域网回放](replay-experimental.md)。原版对象编号和原版回放播放尚未接入，因此当前界面不能视为完整回放功能。删除确认使用现有标准界面模板，原版删除位置、布局、快捷键、地图预览和交互还原度待对照。

本机 1.27 的 `ViewReplayScreen.fdf` 来自 `War3Patch.mpq`，SHA-256 `6bec0f4958f3788f86655ae0e58aa8f069a7ad95bad633c232cdcc07c5f04a00`；运行时从原公共归档读取，不拷贝游戏资源。原版界面中的 `FileListFrame`、`MapInfoPaneContainer`、`NumPlayersValue`、`OKButton` 和 `CancelButton` 用作布局和交互入口。实际窗口、非法文件／目录替换、确认取消、资源释放和用户目录保护均待阶段验证。

Win32 Release 产品增量编译通过；实际窗口及运行行为尚未验收。

回放列表的异步双击交接需集中验证：冷读取、已读取、切换选中、删除、返回、损坏文件及连续双击；播放兼容性仍以同构建局域网录制为限。
