# 回放选择界面

`ReplayBrowser` 使用原版 `UI/FrameDef/Glue/ViewReplayScreen.fdf` 的标题、文件列表区域、地图信息区域与确认／返回按钮。用户回放从独立用户目录 `Replays` 读取，默认位于 `%LOCALAPPDATA%/MEgine/War3/Replays`，也遵循 `MEGINE_WAR3_USER_DIR`。首次进入创建目录，并核对其不处于原版游戏安装目录。目录列表只包含子目录和 `.w3g`，跳过重解析点，支持滚轮、方向键、翻页、返回上层和刷新。选中文件后在后台读取 W3G，并在界面显示名称、地图、玩家数和时长。

确认按钮、键盘和双击都通过后台复核所选回放的 SHA-256。摘要一致时交接已解析的快照，摘要变化时从同一个防并发写入和删除的句柄读取新预览，请用户重新确认。文件移走时刷新目录并停留在列表。双击时若预览仍在读取，会在读取成功后发起复核。换选、进入目录、刷新、返回和打开删除确认会取消待播放操作。

鼠标或键盘显式选择回放文件后，确认按钮获得焦点，预览完成后可用 Enter 启动复核。用 Tab 选中取消时，Enter 返回上一级菜单。

Delete 键打开删除确认并固定当前选中项。确认框出现后，重新点击「删除」或按 Enter／Y 提交，Esc／N 或「取消」关闭。鼠标确认要求在确认框出现后重新按下并释放。后台在受限句柄上复核回放摘要，再删除所选回放及摘要匹配的同名关联地图链接。删除失败后刷新原路径，提示显示在列表下方。切换选择时后台请求按代数丢弃旧结果。读取受现有 W3G 文件和解压预算限制，在分块读取和解码过程中检查取消。网络路径与高密度目录的性能待验证。

界面 `draw` 在确认播放时返回 `PlayReplay`，随后由调用方的 `takeSelection` 取得路径和已解析的只读 `Replay` 快照；返回时返回 `CancelButton`。主菜单已接入本界面，自研同构建局域网记录可进入地图准备与时间片播放，详见[自研局域网回放](replay-experimental.md)。原版对象编号和原版回放播放尚未接入，因此当前界面不能视为完整回放功能。删除确认使用现有标准界面模板，原版删除位置、布局、快捷键、地图预览和交互还原度待对照。

本机 1.27 的 `ViewReplayScreen.fdf` 来自 `War3Patch.mpq`，SHA-256 `6bec0f4958f3788f86655ae0e58aa8f069a7ad95bad633c232cdcc07c5f04a00`；运行时从原公共归档读取，不拷贝游戏资源。原版界面中的 `FileListFrame`、`MapInfoPaneContainer`、`NumPlayersValue`、`OKButton` 和 `CancelButton` 用作布局和交互入口。实际窗口、非法文件／目录替换、确认取消、资源释放和用户目录保护均待阶段验证。

Win32 Release 产品增量编译通过；实际窗口及运行行为尚未验收。

回放列表的异步双击交接需集中验证：冷读取、已读取、切换选中、删除、返回、损坏文件及连续双击；播放兼容性仍以同构建局域网录制为限。
