# 人族农民与民兵

`Amil` 从能力数据读取农民／民兵单位类型和持续时间，命令将单位送往己方城镇大厅转换；民兵到期或收到返工命令时返回城镇大厅。转换复用单位变形流程，保留单位句柄，并刷新单位类型、能力及人口。新命令可中断返程，民兵计时状态保留。

`Amic` 根据源能力范围为附近己方单位发出征召或返工命令，包括矿内采集的农民。大厅拥有能力由对象数据及地图脚本决定。按钮使用源正反向图标、提示和快捷键。原版数据中的 `Amil` 持续时间为 45 秒，`Amic` 范围为 2000；地图覆盖数据可改变这些值。

此流程及实际对局尚未运行验证。计时起点、返程范围和阻路、采矿与携带资源、易主、脚本事件重入、技能限制、多人同步、AI 操作、界面和原版行为均待集中对照；警钟音效尚未接入。
