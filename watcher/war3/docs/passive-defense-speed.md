# 被动防御速度字段

`AIdd` 及其地图派生能力的 DataC／DataD 在装备与单位能力刷新时进入真实移动速度和攻击间隔聚合，受持有／移除、能力可用性与科技前置影响。DataC 为零时保持正常速度，正值作为速度因子；DataD 作为攻击速度减少量。多个来源与已有 Defend 状态沿用当前最强减速及增强聚合，变形时关闭该被动贡献。原版 `Aegr`／`AIdd` 对应字段均为零，其他值来自地图对象覆盖。DataI 仍未实现并明确拒绝。

固定版 AbilityMetaData 的 Def3／Def4 将字段命名为移动速度因素和攻击速度因素；源表与字段信息见 `tmp/docs-artifacts/war3/faerie-dragon/source.json`。非零语义、能力叠加、变形与幻象规则尚未得到原版运行证据，此处按已有 Defend 状态逻辑实现，不能作为原版一致性结论。

待集中验证：自定义单位和物品的零／小于一／大于一移动因子与攻击值、实际移动距离和攻击间隔、不同等级／能力移除或转让／科技与可用性变化、装备交换／幻象／变形／死亡及与 Defend／光环／Buff 叠加，双端与密集地图性能，并对照原版 1.27。未编译或运行。
