# 纷争面纱与点目标物品

物品的暴风雪类能力使用已有点目标、物品法力／冷却及引导施法流程。DotA 6.83d 的纷争面纱 `I0O3` 使用 `A28D`，由地图脚本将效果施加给范围内的有效敌人；客户端继续消费脚本授予的能力，并在伤害计算中使用源魔法伤害倍率。

Win32 Release 客户端编译通过。DotA 原图隔离会话中，英雄对目标施法，目标获得地图脚本效果；同一魔法伤害由 100 变为 125，脚本效果到期后恢复为 100。输出与临时探针位于 `tmp/docs-artifacts/war3/dota-i0gj/`，使用的地图及原始资产未纳入仓库。该检查直接调用会话入口，不代表真实窗口操作、完整物品玩法或原版一致性验收。

点目标输入、无效目标与施法范围、引导打断、物品次数和冷却、多个目标、免疫／驱散、伤害类型和效果叠加需在功能阶段验证，并与原版对照。
