# 受攻击提醒

本地玩家拥有的单位受到敌方实际攻击伤害时，客户端在小地图显示原资源配置的攻击提示颜色，并从 `UI/war3skins.txt` 按玩家种族选择单位或建筑受攻击的声音标签。提醒使用本地呈现队列，不向地图脚本输出额外事件或改变伤害。当前暂以八秒限制连续提醒，提示时长三秒；仅覆盖本地玩家自己的单位，盟友提醒、额外提示分类与原版时序待实现或对照。

`UnitIgnoreAlarm` 和 `UnitIgnoreAlarmToggled` 保存并查询单位的警报忽略状态；标记后不产生上述本地提醒。原 Game.dll 1.27 的接口观察 `ev_a5ac4a9afebb2ab302a762a3d15423ae0a3c1b9c99c935ab244a5e444de03ecf` 显示解析不到单位或组件时返回 0，并在标志为真时写入 0x80 位；本客户端为有效单位维护独立状态，组件资格与完整原版边界待核对。该显示状态不纳入实验联机同步摘要，以允许脚本针对本地玩家控制提示。

阶段需在实际窗口和声音设备验证敌我／单位／建筑、连续攻击间隔、静音、暂停、伤害与回调易主／删除、脚本屏蔽及恢复、地图覆盖、盟友和多人行为。
