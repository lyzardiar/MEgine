# 受攻击提醒

本地玩家拥有的单位受到敌方实际攻击伤害时，客户端在小地图显示原资源配置的攻击提示颜色，并从 `UI/war3skins.txt` 按玩家种族选择单位或建筑受攻击的声音标签。提醒使用本地呈现队列，不向地图脚本输出额外事件或改变伤害。当前暂以八秒限制连续提醒，提示时长三秒；盟友单位和建筑受到敌方实际攻击时，按本地玩家的联盟关系显示同一攻击小地图提示，并分别读取原皮肤 `AllyUnderAttackSound`／`AllyTownUnderAttackSound`。己方与盟友提醒各有独立的八秒间隔，互不抑制；联盟方向、提示颜色、触发类别与时序仍待原版对照。

`UnitIgnoreAlarm` 和 `UnitIgnoreAlarmToggled` 保存并查询单位的警报忽略状态；标记后不产生上述本地提醒。原 Game.dll 1.27 的接口观察 `ev_a5ac4a9afebb2ab302a762a3d15423ae0a3c1b9c99c935ab244a5e444de03ecf` 显示解析不到单位或组件时返回 0，并在标志为真时写入 0x80 位；本客户端为有效单位维护独立状态，组件资格与完整原版边界待核对。该显示状态不纳入实验联机同步摘要，以允许脚本针对本地玩家控制提示。

阶段需在实际窗口和声音设备验证敌我／单位／建筑、连续攻击间隔、静音、暂停、伤害与回调易主／删除、脚本屏蔽及恢复、地图覆盖、盟友和多人行为。

源皮肤字段来自安装资源 `UI/war3skins.txt`，SHA-256 `53cedda87d59c6d27ad2d30680d37faa410d37e9917c00b21d473cce9eed70c7`；保留地图 `war3mapSkin.txt` 覆盖。盟友关系当前使用本地玩家对目标所有者的 passive 联盟位，提醒与冷却仅用于本地呈现，不改变伤害、模拟随机流或联机状态校验。原版联盟方向、不同来源／位置的去重、静音与共享视野行为需阶段对照。
