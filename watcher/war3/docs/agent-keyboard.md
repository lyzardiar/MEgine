# 隔离对局键盘探针

显式使用 `--hidden --agent-dir <目录>` 启动本地对局后，可向该目录写入 `key.request`，内容为 `请求ID:虚拟键码:修饰位`。请求 ID 限字母、数字、下划线和连字符；修饰位分别为 Ctrl=1、Alt=2、Shift=4、重复键=8，可相加。程序在下一次视图帧将输入交给正常游戏输入路径，并写入 `key-<请求ID>.ready`，包含是否接收及帧号。重复 ID 不覆盖已有响应。

请求仅限隐藏、本地、可交互对局；联机、回放、覆盖面板、前台窗口或同时存在指针请求时拒绝。`capture.request` 的状态补充镜头中心、缩放预设与距离、活动子组、小地图提示及音频开关，图片和响应保持在调用方指定目录。此入口是合成视图输入，不经过 Windows 消息或原版客户端，不能证明实际窗口键盘行为。

在 `tmp/docs-artifacts/war3/keyboard-input-probe/`，`make-fixture.py` 基于隔离地图构建带己方单位和提示的测试地图；`run.cjs` 创建独立用户和 agent 目录并启动隐藏对局。8 项检查通过：Ctrl+C 定位单位、空格定位提示、Alt+C 返回单位、重复／Shift 保护、Ctrl+M／S 独立切换及恢复；结果和状态见 `checks.log`、`result.json`。首次夹具把语句放在局部声明之前导致解析失败，修正后通过；一次驱动复用旧日志导致选择请求早于初始化，改用独立日志后重跑通过。

指针请求的 `middle` 动作在隐藏对局模拟中键按下、移动和释放，用于检查视图镜头平移；它不经过 Windows 鼠标消息。

对局快照含聊天输入是否打开、频道及私聊目标，用于确认快捷键选择的目标；不提供真实键盘或多人投递证据。
