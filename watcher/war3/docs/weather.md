# 地图天气

W3I 25 的天气 FourCC 按源字节顺序读取，`0` 和 `0xffffffff` 不创建默认天气；非空天气使用整张地图边界及 `TerrainArt/Weather.slk`，脚本 `AddWeatherEffect`、`EnableWeatherEffect` 和 `RemoveWeatherEffect` 管理独立区域及生命周期。Amazonia 的 W3I 原始天气字节为 `RAlr`，会话加载该类型。

天气纹理直接从地图／公共 MPQ 在后台读取，缺失或损坏的可选纹理记录日志并跳过，不中断对局。粒子按固定世界网格生成，不消耗游戏同步随机数；数量受相机附近区域、视频粒子设置及全局预算约束。绘制消费源纹理、寿命、速度／加速度、颜色／透明度、大小、头／尾、图集及 `useFog` 等字段；单机在固定步之间插值展示。该路径使用近似的网格密度、方向和图集播放，尚不代表原版视觉一致。联机／回放展示时钟仍可能随时间片跳变。

Win32 Release 客户端及相关消费者已编译。Amazonia 的最小 main 检查通过、未加载 Game.dll；该检查不包含 GPU 画面或音频。阶段验证雨／雪／雾等不同类型、地图默认及多个脚本区域的启停／移除、小范围／边界、相机移动、暂停／速度、失效或损坏贴图、设备恢复、持续切图、帧耗时及原版对照。当前真实窗口、颜色混合、粒子尺寸与轨迹、环境音和性能均未验收。

天气音频按 Weather.slk 的 `AmbientSound` 解析原版声音标签，通过现有 Miles 声音和环境音音量设置循环播放。镜头监听点进入启用区域时开始，离开、区域关闭或移除时停止；重叠区域使用相同标签时复用一份播放，切图随会话释放。原表的雨和风声来自 `UI/SoundInfo/AmbienceSounds.slk`。区域边界、重叠与淡入淡出是当前实现规则，尚需对照原版；地图自定义空间声的定位待完善；无法加载的声音标签输出调试信息并跳过，离开该区域后重新进入时可重试。

Win32 Release 客户端已编译；实际音频及交互尚未验收。
