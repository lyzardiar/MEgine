# 火焰箭

`ANfb` 及使用相同源 code 的派生能力接入雷击的单位目标、弹道与伤害流程；订单使用源配置，未配置时使用 `firebolt`。伤害、射程、目标、魔法、冷却、投射物和持续时间读取能力数据，地图覆盖继续生效。单位 AI 可使用该能力。

固定版 1.27 的 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）的 RTTI 指出 `CAbilityFireBolt` 继承 `CAbilityThunderBolt`；对应虚表共享大部分方法。公共 `Units/AbilityData.slk` 的 `ANfb`、`Awfb`、`ACfb` 没有 `BuffID` 字段，而 `AHtb` 和 `ACtb` 的状态为 `BPSE`。

原版火焰箭缺省状态的来源尚未核实：当前仅在地图或源数据提供 `BuffID` 时应用眩晕。默认火焰箭尚不具备已验证的完整状态行为，不能视为完整还原。

待集中验证：编译并在原版与独立客户端对照火焰箭的施法订单、伤害、目标过滤、弹道、冷却、魔法、英雄及普通单位眩晕；确认缺省状态的来源和可驱散行为，验证地图覆盖与中立守卫施法。尚未编译或运行。
