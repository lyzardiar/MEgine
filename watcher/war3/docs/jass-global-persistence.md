# JASS 基础类型全局状态快照

`jass::Runtime::encodePrimitiveGlobals` 将整数、实数原始 32 位、布尔、字符串（区分 null 与空字符串）及相应稀疏数组编码为独立的版本化字节流。变量按声明顺序记录名称、类型和数组形态，数组下标排序；恢复先完整解析和校验，再统一替换目标运行时的对应全局槽。快照大小及数组下标有界，格式错误或声明不匹配时拒绝操作；采集要求初始化完成且当前没有正在执行的脚本，恢复要求运行时空闲。

结果和字节流都记录被排除的非基础类型全局数量与其中非默认值数量，恢复返回同一报告。句柄、代码、对象图、线程、执行栈和 native 回调都未编码；恢复只更改基础类型全局，不生成全局变量写入事件，调用方须在完整对象、事件及线程恢复设计中明确处理其余状态。模块声明一致不能证明地图和脚本版本一致，集成存档时必须校验地图与脚本完整身份。

这是一组可复用的内存编码／恢复接口，尚未接入存档文件、游戏菜单、战役切换或原版存档格式；不代表完整会话可以保存或恢复。已在独立 JASS 睡眠线程的恢复检查中采集挂起时的全局值；对象、多个线程及实际会话恢复仍待实现和验证。
