# JASS 基础类型全局状态快照

`encodeGlobals` 和 `restoreGlobals` 另提供完整全局槽的独立字节组件：基础类型、稀疏数组、同一运行时的函数引用和经调用方稳定编号映射的句柄均可恢复。组件校验源码名称及 SHA-256、调试选项、声明和内容摘要，并限制大小及值数量；恢复在全部解析和映射成功后替换槽。句柄映射对可互相赋值的类型保持别名并拒绝冲突，彼此不兼容的类型可独立映射相同数值；对象本身的存在性和生命周期由调用方负责。恢复前目标运行时须空闲，函数引用重新绑定到目标运行时。组件摘要用于发现损坏，不提供身份认证。

Win32 Release `war3_jass_runtime_tests` 17/17 通过，覆盖句柄别名、稀疏数组、函数、空字符串、错误映射及损坏／源码不匹配时的事务性拒绝。`war3_jass_thread_tests restore_reference_globals_and_sleeping_thread` 1/1 通过：分别编码全局和睡眠线程，在目标运行时以同一映射恢复后，线程局部变量和全局变量仍引用同一单位句柄，回调访问目标全局状态。该检查使用隔离脚本和模拟句柄，不包含世界对象、真实地图或完整存档事务。

`jass::Runtime::encodePrimitiveGlobals` 将整数、实数原始 32 位、布尔、字符串（区分 null 与空字符串）及相应稀疏数组编码为独立的版本化字节流。变量按声明顺序记录名称、类型和数组形态，数组下标排序；恢复先完整解析和校验，再统一替换目标运行时的对应全局槽。快照大小及数组下标有界，格式错误或声明不匹配时拒绝操作；采集要求初始化完成且当前没有正在执行的脚本，恢复要求运行时空闲。

结果和字节流都记录被排除的非基础类型全局数量与其中非默认值数量，恢复返回同一报告。句柄、代码、对象图、线程、执行栈和 native 回调都未编码；恢复只更改基础类型全局，不生成全局变量写入事件，调用方须在完整对象、事件及线程恢复设计中明确处理其余状态。模块声明一致不能证明地图和脚本版本一致，集成存档时必须校验地图与脚本完整身份。

这些接口尚未接入存档文件、游戏菜单、战役切换或原版存档格式；不代表完整会话可以保存或恢复。对象及实际会话恢复仍待实现和验证。
