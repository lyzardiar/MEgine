# 中立守卫火焰箭

战斗施法调度识别源能力 code `ANfb`，因此使用该原型的守卫火焰箭及其地图派生可以复用现有单位目标策略：目标仍需有效、可见、敌对、在射程内并符合能力目标条件，施法前检查魔法、冷却、科技和能力开关，已处于同一眩晕状态的目标不会被重复选择。中立玩家 12 的守卫在已有战斗目标时进入该策略；玩家 AI 也使用同一能力选择。伤害、状态来源与地图覆盖的边界见 [火焰箭](fire-bolt.md)。

待集中验证：用具备 `Awfb`／`ACfb` 的守卫及地图派生能力进入实战，核对选敌、施法、冷却、法力、眩晕重施、视野和目标死亡；验证 AI 脚本、多个技能竞争及多人确定性，并对照原版施法时机。当前调度周期和选择策略仍非原版行为证明，尚未编译或运行。
