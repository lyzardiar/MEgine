# 游戏内帮助

游戏内 Esc 菜单帮助页从资源视图读取原版 `UI\\HelpStrings.txt`，沿用源文件解码，显示原始颜色标记和换行。文本来自当前公共／地图归档视图，原安装只读，不写出文件。保留已有脚本败北条件显示。

帮助页按文本换行计算可见范围，支持滚轮、Page Up／Page Down、Home／End 和拖动原版 Esc 菜单滚动条的轨道与滑块，滚动位置限制在实际文本范围内。显示与布局使用原版 `EscMenuMainPanel.fdf` 和 `EscMenuTemplates.fdf` 的文本及滚动条资源。

待验证：实际窗口中的鼠标、键盘、滚动位置和中文编码，以及字体、布局和滚动交互与 Warcraft III 1.27 的对照。

对局界面的 Alt+Q／O／S／L／H 分别打开结束游戏、选项、保存、载入和帮助面板，复用 Esc 菜单的原 FDF 与现有动作。保存／载入限于本地对局；聊天、脚本对话框或其他覆盖窗口打开时不触发。F6 在本地对局保存独立快速存档，实际窗口按键和原版精度待验证。

F6 使用独立客户端的 `Saves/Quick/QuickSave.w3z`，再次保存替换此专用文件；同名手动存档保留。游戏内载入和主菜单载入列表提供“快速保存”入口；脚本存档事件沿用本地检查点流程。联机、回放及其他覆盖界面不执行快速保存；失败在对局内提示并记录诊断。该格式并非原版存档，实际 F6 输入、提示及原版命名待集中验证。

Ctrl+M 切换音乐，Ctrl+S 切换音效；沿用游戏内音频设置、各自音量、播放增益及持久化，聊天和覆盖界面不会触发。原版帮助文件列出这两个快捷键；实际窗口输入、音频设备及原版提示待批次验证。

空格键将镜头移向最近一次已接收的小地图提示，包括攻击警报、盟友信号及脚本提示；提示图标消失后本次视图仍记住位置。镜头跟随脚本、聊天、覆盖面板及回放播放保留各自的输入优先级；其他类型警报、重载后的历史和原版提示选择规则仍待完善或对照。

Ctrl+C／Alt+C 将镜头定位到当前活动头像所属单位，复用子组选择及镜头边界，不更改选区或下达命令；聊天、覆盖面板、脚本跟随镜头和回放输入保持现有优先级。实际窗口和原版跟随镜头规则待验证。

Page Up／Page Down 在正常对局分别按一个现有镜头预设放大／缩小，允许按住重复；复用鼠标滚轮的镜头字段与边界。聊天、面板及回放保留各自输入处理，实际窗口和原版连续缩放速率待验证。

Insert／Delete 在正常对局按住时旋转镜头，速度读取 `UI/MiscData.txt` 的 `CameraRates/Rotation`，并支持地图覆盖；修饰键、聊天、覆盖面板及回放不触发。脚本绑定单位且继承朝向时保留绑定朝向。实际窗口按住、原版方向与速率、联机及脚本镜头交互待验证。
