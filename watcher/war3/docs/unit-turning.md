# 单位转向与推进角

单位从 `UnitData.slk` 的 `turnRate` 与 `propWin` 初始化转向速度和推进角；`umvr`、`uprw` 的地图对象覆盖通过现有对象数据入口生效。`SetUnitTurnSpeed`／`GetUnitTurnSpeed`／`GetUnitDefaultTurnSpeed` 连接单位当前与类型默认转速；`SetUnitPropWindow`／`GetUnitPropWindow` 使用弧度，`GetUnitDefaultPropWindow` 返回源单位数据的角度。原安装 `Blizzard.j` 对前者的 BJ 包装转换为度，对后者直接返回。

固定模拟步进中，移动朝路线方向逐步转向，角度进入推进窗口后才向当前路线目标移动；窗口为零时仅允许已朝向目标的推进。攻击进入射程后朝目标转向并等待角度收敛，然后开始现有攻击前摇；固定建筑与不能转向的扎根古树沿用现有行为。每个单位单次步进只消费一次转向时间，避免移动和攻击重复消耗。幻象复制当前设置，单位变形和建筑升级按新旧类型默认值调整并更新默认属性。

当前转向使用 `turnRate` 弧度／0.03 秒的线性近似，攻击角容差采用 0.2 弧度；这些数值、插值、移动与武器开始时机、窗口边界及原版确定性尚未对照。源动画的方向插值和施法转向仍未实现；独立 gamecache 保存并恢复脚本修改的转速和窗口；原版 StoreUnit 是否保留这些状态仍需对照。异常参数夹取及变形中保留脚本修改的方式也待原版核对。

阶段集中验证：原版四族单位及 w3u 自定义转速／推进角、Setter 与 Getter 单位、零值／极值、路径拐角／避障／碰撞、不同目标方向与攻击前摇、固定建筑与古树、移动施法／暂停、幻象／死亡复活／变形／建筑升级及联机固定步进；对照原版视觉插值、操作反馈和帧耗时。尚未执行实际玩法或原版一致性验证。
