# 多选单位面板

选择多个单位时，在信息区显示最多 12 个实时单位头像及生命比例，并突出当前子组类型；单位图标随外观变化及现有资源流式加载更新。单选保留原有信息面板和货舱，多个单位时显示多选面板；命令区及当前主单位物品栏仍可使用。

鼠标点击头像保留该单位，Shift 点击移除该单位，Ctrl 点击保留已选同类型单位。技能或物品处于单位目标模式时，点击头像直接通过实际施法或物品命令处理；移动、攻击、采集及修理等目标命令复用现有目标订单。点目标技能与巡逻等要求地面位置的操作保持等待。实验局域网选择变更通过既有选择动作及时间片确认消费；回放输入仍受现有隔离约束。

多选头像使用原皮肤的 `GroupButtonBorder`、`SelectedSubgroupHighlight`、英雄光效与小型生命／魔法条纹理，地图 `CustomSkin` 覆盖优先于玩家种族及默认皮肤；资源由地图加载线程准备并复用现有 GPU 交付。皮肤纹理缺失时使用基础色块，损坏纹理仍报告解码错误。头像布局、分组、点击修饰键、目标优先级、颜色、焦点及纹理叠放的原版精度尚待对照。功能阶段核对 2–12 单位、混合单位及不同子组、资源加载／形态变化、选区清空和脚本事件重入、单位死亡／隐藏／易主、禁用控制或选择、各种目标模式、Shift／Ctrl、命令和货舱区域、实验联机确认／错误／切图、回放输入、不同窗口尺寸及原版界面行为。此实现尚未经过实际窗口运行验收。

支持同时指定单位和地点的物品可通过多选头像选择单位；纯地点物品保持目标位置提示，命令继续使用既有库存、排队与施法流程。Win32 Release 增量编译通过；游戏内 Agent 在隔离地图中点击双目标物品和第二个单位头像，目标生命从 650 变为约 124、物品被使用；纯地点对照保留物品与生命并提示选择位置。证据位于 `tmp/docs-artifacts/war3/agent-info/dual-item-agent-fixed/` 和 `point-only-item-agent/`。实际地图、原版交互、Shift 队列和联机待阶段验证。

本机复现脚本：`tmp/docs-artifacts/war3/agent-info/check-dual-item-fixed.ps1` 和 `check-point-only-item.ps1`；两者通过 `tools/agent-pointer.ps1` 点击库存第一格与第二头像，并通过 `tools/agent-capture.ps1` 记录选择和生命值。
