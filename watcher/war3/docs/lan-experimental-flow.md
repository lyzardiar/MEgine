# 自研客户端局域网实验入口

启动参数 `--experimental-local-lan` 开启自研客户端之间的对局实验。主机发布的房间名自动加 `[M3-LAB] `，实验浏览器仅显示带此标记的房间。实验 TCP 连接在普通加入请求之前交换私有握手，要求双方协议版本、能力位及各自可执行文件的 SHA-256 相同；未响应、格式不符或不一致时拒绝或超时，主机不会为其分配玩家槽。默认启动不启用实验对局交接，不改变普通局域网浏览协议。

实验流程由大厅冻结地图、槽位和随机种子，交接活连接到 `LanMatchLoading`；后台准备会话和 GPU 上传，在载入界面显示进度并等待所有玩家完成加载。准备完成后建立 GameView 和 LanRuntime，逐帧消费有序时间片。对局、载入和模型过场期间保持连接；载入期间断线、主机断线或运行错误关闭连接并返回 LAN 浏览页。最小化时大厅继续搜索／处理连接、地图核对和主机倒计时，对局继续消费网络时间片；载入保持连接并接收已完成的后台地图准备或场景数据；创建载入界面、启动尚未开始的场景加载和 GPU 上传在恢复窗口后继续。载入屏障沿用现有超时，长期最小化仍可能使其他玩家等待超时。

实验握手的数据为 `0xf7/0x70`，包含 `M3LH` 标记、协议版本 1、能力位 `0x0f` 和本地可执行文件 SHA-256 的 64 字节十六进制文本。客户端先发送握手、等待主机回送完全一致的报文，再发送普通加入请求；等待最长 15 秒。能力位标识本项目的内部对象编号、部分状态摘要、Trackable 动作和时间片支持，不保证完整玩法。可执行文件摘要读取磁盘路径上的文件，不能证明加载后文件未被替换，也不验证地图外的资源版本；握手不提供密码学身份认证，恶意对端可以仿造数据。地图仍按已有声明校验。不同二进制即使兼容也会被拒绝，必须使用同一份构建。

实验对象编号与状态摘要由 `LanLocalIdentity` 提供，仅供同版本自研客户端。摘要覆盖部分状态，不能保证发现所有失步；原版对象编号、校验算法和完整命令语义尚未完成。双方须使用同一地图及一致的同步对象创建序列；包含本地分支的地图可能无法同步。该私有握手不是原版 Warcraft III 协议，不能用于声称原版互通。

对局聊天分为全体、盟友和观察者，以自研 `0xf0`／`0xf1`／`0xf2` 动作进入有序时间片。接收范围在动作消费时按发送方联盟或观察者状态确定，双方以发送者的映射玩家触发地图聊天事件并在对应视角显示；自研回放记录同一时间片并在播放时消费。消息为最多 1024 字节的非空 UTF-8 文本，普通经典动作解析默认拒绝这些私有动作，只有自研对局和自研回放启用。所有动作仍发送至对局参与者，频道筛选只控制本地显示。原版聊天协议互通、频道和触发器语义及同步效果待阶段验证。

自研 `SyncSelections` 使用私有 `0xf3` 时间片分块交换所有人类玩家的选择快照；脚本纤程等待全部参与者的相同轮次后继续，`GroupEnumUnitsSelected` 在本线程读取完成的快照，子线程继承父线程视图。载入期的请求保留到连接就绪后发送，回放只消费记录的分片；结束时有未完成屏障会报告错误。每名玩家最多 4096 个对象、每片最多 128 个，轮次及存留快照有预算。同步屏障未完成或分片待发时阻断后续本地输入；发送持续受阻 15 秒会中断连接，首片进入所有端的时间片后超过 30 秒模拟时间仍未完成也会中止对局；模拟暂停时等待纤程在恢复后继续。各端必须以相同顺序调用同步，本地分支导致的调用顺序差异不受支持。该路径使用自研对象编号，仅同步脚本查询快照，不替代脚本本地选择的实时命令同步；原版协议与行为、断线和多端运行待阶段验证。

实验对局中，非主机玩家断线由主机把私有 `0xf5` 离开动作排入时间片；幸存端和自研回放按该顺序标记玩家离开并触发地图 `EVENT_PLAYER_LEAVE`，活动参与者和待完成选择同步屏障随之更新。玩家映射和槽位身份保持稳定；主机按剩余连接继续比较校验值。连接结束前已经接纳的动作按主机解析顺序排在离开之前，待发满时使用有界全局 FIFO 缓冲；超过缓冲预算的发送端会被断开，未接纳的输入可能丢失。非主机在游戏菜单确认离开时，先发送已排队动作及选区同步，再等待自身消费离开事件和回放记录后关闭连接；主机收到请求即停止等待该玩家的校验，因此尚未比较的离开前时间片不再由该玩家参与校验；房主离开结束房间并保存部分回放，主机迁移尚未接入。原版离开协议与真实双端游戏行为待阶段验证。

自研技能动作 `0xf6` 携带明确能力、目标／点位、排队与首个成功后停止标志，以及以高亮施法者优先的有序选择候选；接收端验证选择和对象后通过会话实际施法流程消费，并按实时权限和句柄处理脚本重入。Channel 的批量与首成功行为沿用单机规则。该动作仅供同构建实验客户端及其回放，不代表原版协议；真实多端、回放及原版语义待阶段验证。

自研单单位动作 `0xf7` 为建筑放置／训练／研究／升级、物品使用／放置／转交／换格、技能与修理自动施法开关、英雄技能学习、资源返还、指定乘员卸载、生产队列与建筑取消、祭坛复活和酒馆唤醒携带明确的选中单位、物品及目标身份；时间片消费时复核选区、控制权和物品归属，已知消失对象或已失效操作跳过，未知身份和畸形数据拒绝。该动作只用于同构建实验客户端及其回放；生产队列取消携带 64 位任务票号，消费时按当前票号查找，已完成或已取消的任务不会误伤后续同类任务；票号及全局计数纳入实验状态摘要。建筑升级取消核对原升级票号；祭坛复活和酒馆唤醒核对英雄死亡轮次，过期请求跳过，酒馆购买资格仍由实际会话决定。原版协议与真实多端行为仍待完成或验证。

自研脚本对话框点击使用私有 `0xf8` 时间片动作，传递按钮与对话框身份、按钮结构校验和点击者显示轮次；每个玩家的同一轮次最多触发一次，并通过实际 Dialog／Button 事件保留触发玩家与回调。各端可以仅在本地显示界面，接收端不依赖自身显示标志执行事件；较晚重新显示的同一对话框不会被旧点击关闭。对话框和按钮使用独立对象序号，不占用单位／物品序号；各端仍须按相同顺序创建这些界面对象，按钮位置／热键及退出属性也须一致，局部创建导致的身份差异尚不受支持。结构校验不是身份认证；已发出的点击仍可能在本地隐藏／重开后触发原按钮事件，其原版时序待对照。QuitButton 的 Dialog／Button 事件在各端按时间片执行，仅点击者发起离开；非主机等待离开事件及回放记录后断开，房主退出结束房间。需要结算时，离开后保留本机结算界面；回放只消费脚本事件，不主动离开。对话框打开时也可按 F10 打开对局菜单。实验会话中的 EndGame 生成本机退出意图，不暂停共享模拟；对话框回调按触发玩家定位退出者，GetLocalPlayer 分支按当前客户端处理。回放消费脚本但不发起离开。对话框回调中显式选择非点击者执行 EndGame 的本地分支尚未覆盖；多人 RestartGame／ChangeLevel 与完整原版时序仍待完成或验证。实际双端、回放和原版行为待阶段验证。

自研商店交易使用私有 `0xf4` 动作传递商店对象、商品类型与物品／单位类别；玩家必须已选择该商店，交易在有序时间片中调用现有商店消费者，扣费、人口、库存与销售事件由实际会话处理。已移除的已知商店或同一时间片中失效的交易会跳过；未知身份和畸形报文会拒绝。对象引用使用自研身份，普通经典动作解析不接受私有报文。Win32 Release 产品编译通过，单会话时间片最小检查覆盖单位／物品交易、过期动作和无效身份；真实双端、回放及原版购买协议互通待阶段验证。

本次握手的 Win32 Release 产品增量编译通过。阶段验证：相同／不同二进制和能力、原版／无响应主机及客户端、分包／粘包／延迟／超时／断线、槽位与重连；同版本双端建房／查找／加入、地图传输、加载屏障和选区／移动／技能、退出／断线、加载失败和取消、最小化、过场、内存释放；不同版本、原版客户端、作弊输入及长期同步均不能视为已通过。
