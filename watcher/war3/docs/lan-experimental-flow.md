# 自研客户端局域网实验入口

启动参数 `--experimental-local-lan` 开启自研客户端之间的对局实验。主机发布的房间名自动加 `[M3-LAB] `，实验浏览器仅显示带此标记的房间。该标记仅用于识别实验房间，不证明对端版本一致，也不能阻止其他客户端主动加入；不得用于宣称与原版互通。默认启动不启用实验对局交接。

实验流程由大厅冻结地图、槽位和随机种子，交接活连接到 `LanMatchLoading`；后台准备会话和 GPU 上传，在载入界面显示进度并等待所有玩家完成加载。准备完成后建立 GameView 和 LanRuntime，逐帧消费有序时间片。对局、载入和模型过场期间保持连接；取消、断线、载入或运行错误关闭连接并返回 LAN 浏览页。最小化时大厅继续搜索／处理连接、地图核对和主机倒计时，对局继续消费网络时间片；载入保持连接并接收已完成的后台地图准备或场景数据；创建载入界面、启动尚未开始的场景加载和 GPU 上传在恢复窗口后继续。载入屏障沿用现有超时，长期最小化仍可能使其他玩家等待超时。

实验对象编号与状态摘要由 `LanLocalIdentity` 提供，仅供同版本自研客户端。摘要覆盖部分状态，不能保证发现所有失步；原版对象编号、校验算法、完整命令语义和版本握手尚未完成。双方须使用同一版本、同一地图及一致的同步对象创建序列；包含本地分支的地图可能无法同步。

Win32 Release 产品增量编译通过。阶段验证：同版本双端建房／查找／加入、地图传输、加载屏障和选区／移动／技能、退出／断线、加载失败和取消、最小化、过场、内存释放；不同版本、原版客户端、作弊输入及长期同步均不能视为已通过。
