# 自身强化与防御能力

原型AHav、Absk、Adef、AHds、AEim、ANms及其w3a派生能力已接入实际会话、命令区和共享伤害链。当前为实现完成、待阶段运行验证；完整客户端与原版一致性尚未验收。

| 能力 | 实际消费者 |
| --- | --- |
| 天神下凡 | 源护甲、额外生命与固定攻击伤害、魔法免疫/伤害因子、模型缩放与Alternate序列；到期、死亡或能力移除回收额外生命，保留英雄成长与原句柄 |
| 狂暴 | 源移动/攻击速度和所受伤害增加；真实固定步进、攻击间隔及伤害结算，定时结束 |
| 防御 | 源穿刺伤害、输出、移动/攻击速度、魔法因子；普通missile武器按源概率反向生成真实弹道，消费原命中者及反弹伤害系数；Defend序列和科技前置 |
| 圣盾 | 有时限的实际无敌；攻击、伤害和法术目标共用能力查询；取消行为读取DataA与MiscGame开关 |
| 献祭 | 源开启费用、魔法缓冲门槛、持续耗蓝、伤害间隔/范围/目标类别；逐步扣蓝、范围火焰伤害、魔法耗尽关闭及原施法者/受害者特效 |
| 魔法护盾 | 源开启费用、冷却、吸收比例与每点魔法的伤害承载量；真实扣蓝、剩余伤害落到生命、魔法耗尽关闭 |

防御、狂暴、献祭和魔法护盾走即时施法路径，保留正在执行的移动/攻击。订单及施法事件使用实际单位/能力句柄，回调中删除、转让或禁用单位时停止提交后续效果。关闭命令免魔法消耗，不重置开启冷却；开启和关闭不作为自动施法开关。源图标/位置/热键、活动状态、冷却和工具提示共用会话状态。

物品原型AHds与Absk也接入useItem，真实消耗次数/魔法、登记物品冷却、生成相同限时无敌/狂暴效果及物品事件；物品效果不要求单位持有对应技能。复合主动物品及其他原型仍保留明确的未实现错误。

持续技能仅更新登记的活动单位；献祭的伤害扫描按源脉冲发生。切图释放会话中的状态、登记和内存资产，不写派生资产或地图解包目录。

## 来源和必要检查

## 阶段验证范围

合并验证六种能力的源等级/w3a覆盖、费用/缓冲/冷却与事件顺序、行进和攻击期间开关、重复订单/取消/回调重入、到期/死亡/移除/复活及英雄成长。检查防御与狂暴对实际移动/武器/伤害的消费，圣盾对真实武器/法术/脚本伤害的保护，护盾部分吸收/空魔法/多种伤害与反魔法外壳组合，以及献祭目标类别/范围/脉冲/耗蓝/暂停/运输/变形。

防御反弹当前覆盖普通missile武器并限制同一弹道再次反弹；弹射、穿透、溅射、无限连续反弹及完整原版判定仍待实现或核对。献祭的缓冲/耗蓝/范围边界、护盾公式和各种伤害交互、额外生命回收规则、自动AI策略及完整音效/模型动作/附件/GPU效果均待阶段对照。原版像素、三图长局、内存与切图释放继续使用对应阶段队列，旧MEngine批次保持原状态。
