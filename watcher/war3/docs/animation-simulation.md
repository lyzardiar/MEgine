# 单位动画队列与模拟时钟

单位与可破坏物的排队动画由固定模拟步进消费。会话从公共／地图覆盖归档直接读取 MDX 的 SEQS 元数据，并按模型路径缓存；无须创建渲染器或解码纹理。模拟和模型渲染共用动画名称匹配规则，按当前序列长度推进队列。暂停单位不会推进；未找到模型或序列时保留队列。

常规动画队列的出队不再依赖相机可见性、窗口帧率或网络视图的绘制次数。模型切换、动画索引、采集携带动画与 alternate 名称继续使用实际单位状态。可破坏物使用待处理集合，避免遍历全地图。区域装饰物动画仍在绘制时修改可破坏物并清空其队列，隐藏窗口和多客户端下存在状态差异，必须迁入会话模拟；动画事件、原版随机序列择取与准确时序仍待还原或验证。

待集中验证：原版地图与自定义模型中可见／离屏／隐藏单位及可破坏物、暂停与倍速、死亡／移动／施法及形态切换、不同长度连续队列、无效序列和模型缺失；复核画面与原版时序，并在联机多客户端比较同步状态和性能。涉及输入和实际场景的结果不能由编译代替。
