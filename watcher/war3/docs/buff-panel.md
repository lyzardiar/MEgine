# 单位状态图标

单选单位面板读取单位当前实际 Buff 与光环，以 Buff ID 合并重复来源并按 ID 稳定排序，最多显示 8 个状态。图标、名称及描述来自原资源 AbilityFunc／AbilityStrings 的 Buffart、Bufftip 和 Buffubertip；图标按现有后台资源流程读取，失效或尚未上传时使用空底框。鼠标悬停显示原文本，状态结束后不再显示，切换单位及切图时跟随会话状态。

悬停提示根据实际换行计算标题和说明高度，底边保持在信息栏上方；标题最多显示 4 行，说明最多显示 30 行，超过上限的内容尚无滚动入口。Win32 Release 客户端编译通过；本次环境创建 Direct3D 9 设备失败，尚未取得修改后的游戏画面，实际布局与原版一致性待验证。

状态栏使用单行八个 0.015 方形图标，放在单位信息区域右下；当前建筑、货舱和生产详情不显示该栏，单位定时生命条有状态图标时收窄以避免重叠。原版父容器与详情切换、具体状态选择条件和定时生命条仍待运行对照；排序、文本变量展开、图标层叠和分页尚未完成。`war3map.w3h` 的 Buff 对象覆盖已接入对象表，具体范围见 [Buff 覆盖](buff-overrides.md)；特殊状态如果不在单位 Buff／光环集合中也尚未显示。源文件中的提示和持续时间不构成原版表现验收。

功能阶段验证单／多选与子组切换、Buff 施加／刷新／移除／驱散／死亡、光环进出／来源变化、多来源合并、图标不存在／加载失败／后台上传、鼠标悬停及长描述、暂停／隐藏界面、连续切图、设备恢复、不同窗口尺寸和三图性能；对照原版排序、数量、UI 资源及自定义覆盖。

原版 1.27 的 `CBuffBar` 构造区域宽 0.12、高 0.015，创建 8 个 0.015 方形图标；单位详情的右下锚点偏移为 -0.003、+0.0056875。`CInfoBar` 的详情区域宽 0.188125、高 0.1140625，左下锚点水平偏移 0.309375；原件还按状态切换并隐藏上一详情。证据在 `tmp/docs-artifacts/war3/buff-layout-1.27-disassembly.txt` 和 `buff-detail-switch-1.27-disassembly.txt`。坐标以标准屏幕根为依据，精确父节点与各类单位的详情切换仍需核对。
