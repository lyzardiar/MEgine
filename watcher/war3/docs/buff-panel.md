# 单位状态图标

单选单位面板读取单位当前实际 Buff 与光环，以 Buff ID 合并重复来源并按 ID 稳定排序，最多显示 12 个状态。图标、名称及描述来自原资源 AbilityFunc／AbilityStrings 的 Buffart、Bufftip 和 Buffubertip；图标按现有后台资源流程读取，失效或尚未上传时使用空底框。鼠标悬停显示原文本，状态结束后不再显示，切换单位及切图时跟随会话状态。

当前使用基础排布和提示框，尚未完成原版位置、排序、文本变量展开、图标层叠、分页和显隐规则。`war3map.w3h` 的 Buff 对象覆盖已接入对象表，具体范围见 [Buff 覆盖](buff-overrides.md)；特殊状态如果不在单位 Buff／光环集合中也尚未显示。源文件中的提示和持续时间不构成原版表现验收。

功能阶段验证单／多选与子组切换、Buff 施加／刷新／移除／驱散／死亡、光环进出／来源变化、多来源合并、图标不存在／加载失败／后台上传、鼠标悬停及长描述、暂停／隐藏界面、连续切图、设备恢复、不同窗口尺寸和三图性能；对照原版排序、数量、UI 资源及自定义覆盖。
