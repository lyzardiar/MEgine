# 实验局域网中过期的选区和编组

实验对局的选区和控制组动作可能在玩家发送之后、时间片消费之前遇到单位被移除。接收端使用已有的同构建对象身份和移除记录核对：已知移除的单位成员从本次选区／编组动作中跳过，其他有效成员照常处理；选区新增时，已变为不可选择的存活单位也跳过。全失效的编组写入空组，避免保留旧成员。未知身份、非单位类型和重复编组身份仍拒绝，经典协议保持原有严格规则。动作仍由同一时间片顺序消费，不更改单位或地图资源。

`tests/order_queue_tests.cpp` 增加真实会话中移除、有效成员、未知身份、经典拒绝、编组召回及不可选单位的消费者断言。实际双端／回放、同时间片先后删除、空组／混合多对象、不同选区模式、隐藏／死亡／易主、重新创建的不同身份、脚本重入和原版行为留待集中验证；本次仅差异检查，未编译或运行。原版网络对象分配与协议互通仍未实现。
