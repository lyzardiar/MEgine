# 地图传送门

带 `Awrp` 能力的单位保存传送目标和激活状态，脚本通过 `WaygateSetDestination`、`WaygateGetDestinationX/Y`、`WaygateActivate` 和 `WaygateIsActive` 访问。只有脚本明确设置目标后，已激活的传送门才会传送单位；目标 (0,0) 也可显式设置。原版新门的默认激活与未设置目的地语义仍待对照。

传送区域由技能 `DataA`／`DataB` 作为宽高，当前按轴对齐矩形检测；原版区域形状尚待对照。单位进入区域后寻找合法落点并更新真实单位位置、行动状态、场景效果及视野；目的地被占时在后续步重试。到达其他门的区域后保留进入状态，避免连续往返；离开后可再次进入。普通智能目标命令可让单位接近已启用的门，进入检测也接收地面移动和脚本位置变化。

存在传送门时，每个模拟步构建单位区域网格并按门矩形筛选，传送完成后重建网格维护区域成员；大范围门按已有非空网格筛选。`Awrp` 源数据的 `Wrp1`／`Wrp2` 为传送区域宽度／高度，本机 1.27 的 `nwgt` 使用 `Awrp`，两项均为 400。本机 `(4)WarChasers.w3m` 的脚本通过 `CreateUnit`、`WaygateSetDestination`、`WaygateActivate` 初始化两座预放置门。其他地图若只在 `war3mapUnits.doo` 记录目标或激活状态，当前尚未读取该字段。

落点、目标类型、与自动寻路和队列的交互、特效／声音、区域时序、原版默认状态、多个门与拥挤情况下的表现均待实际运行和原版对照；当前没有宣称完整原版一致性。

实验联机状态摘要包含门的目的地、激活、目标是否已设置以及按网络对象身份排列的区域成员。阶段执行 `war3_waygate_tests.exe <data-root> <BootyBay.w3m>`，并补充实际玩家右键／穿越、重复进入、多个单位、地形阻挡、单位死亡／移除、地图自定义能力、两端与回放及原版地图的运行验证。
