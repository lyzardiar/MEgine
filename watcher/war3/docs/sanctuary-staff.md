# 避难权杖

暗夜精灵奇迹古树出售的 `ssan` 使用 `ANsa`。物品选择目标、射程、费用、45 秒冷却与原施法事件接入现有物品和施法流程；释放时将目标传送到施法者所属玩家的主基地附近，沿用路径占位和保存权杖的基地筛选。目标或基地失效时不移动。

受伤目标获得 `BNsa` 状态：保留原图标和目标模型，无法移动、攻击或施法；按英雄／普通单位分别等待 DataB／DataC 秒后以 DataE 每秒恢复生命，生命恢复满或死亡时清除效果。DataD 暂按百分比减少所受魔法伤害。角色暂停时恢复时钟停止；替换效果与死亡复用状态资源清理。满生命目标仍可传送，当前无需进入恢复状态。

源数据来自本机 1.27 的 `AbilityData.slk`、`ItemData.slk`、`ItemStrings.txt`、`ItemAbilityFunc.txt`、`ItemAbilityStrings.txt` 和 `UI/WorldEditStrings.txt`。原版 DataA／B／C／D／E 分别为 15／1／5／10／15；物品描述说明传送至自身最高等级主基地、晕眩并持续治疗。基地筛选及原静态依据见[保存权杖](preservation.md)。

Win32 x86 Release 产品编译通过。DataD 的单位和应用范围、基地混合种族顺序、免疫／中立／自身目标、延迟、驱散、已满生命、治疗和伤害并发的原版行为仍需运行对照；状态的本地显示、物品使用事件、实际窗口操作和多人同步留待集中验证。本项实现不表示完整战役和原版行为已验收。
