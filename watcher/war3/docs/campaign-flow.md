# 战役入口与关卡切换

战役菜单从原版 CampaignStrings 和 FDF 读取 ROC／TFT 战役、章节、难度和背景，依据本地进度开放入口；选择章节后直接读取原安装的地图归档，并进入现有地图准备和游戏加载流程。战役资料和难度写入独立用户目录的 Campaign/profile.bin；脚本可修改战役／章节／过场可用状态，并通过 ChangeLevel 请求下一关，跨关英雄与数值使用 [gamecache](campaign-gamecache.md)。重新开始、回菜单和强制选择战役接入相应入口。自定义地图切换路径限定在原安装 Maps 或当前地图所在目录内，保持其原有会话类型。

这是功能接入，尚未经过完整战役运行或原版一致性验证。教程完成标志目前仅保存，尚无消费者；模型过场时间线与声音、第四个 Mission 字段的行为、完整章节解锁和配音、原版存档／回放／局域网以及 .w3v 文件兼容尚未完成。原安装目录只读，战役数据不生成地图解包资产。战役资源目录、路径与原版资料证据在 tmp/docs-artifacts/war3/campaign/。

战役菜单的影片条目读取 Movies 目录同名文件：虽然扩展名为 .mpq，其内容为 BLZ0 AVI／MP3。客户端以 DirectShow 从原文件播放，通过原安装的 blizzard.ax 免注册构造解码器，不写解包文件；支持静音、跳过及返回菜单。原版安装的解码器按 Win32 架构和 SHA-256 校验。资料片结局 MDX 含多个独立动画片段和事件，其完整时序／声音尚未接入，选择时明确报错。影片实际画面、听感、跳过／窗口恢复及原版一致性待功能阶段验证。
