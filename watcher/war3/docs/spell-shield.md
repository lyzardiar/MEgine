# 魔法护盾护身符与神符

原版物品 `spsh` 提供 `ANss` 魔法护盾。单位或可用库存提供该能力时，指定的敌方单体法术在释放阶段被拦截；施法者已经消耗魔法并进入自身冷却，护盾按能力等级的 `Cool` 进入冷却。原版 1.27 一级冷却为 40 秒，地图能力覆盖沿用对象数据。友方治疗和无目标范围法术不消耗该护盾；移除或禁用来源后不再拦截。护盾触发使用源 `CasterArt`，单位冷却重置沿用既有接口。

原版护盾神符 `rsps` 拾取时消费 `ANse`：以源 `Area` 和目标类型选择附近友军，为各单位施加一次性 `BNss` 护盾。源范围为 1400，源持续时间为零，当前保留状态直到拦截或被移除；非零地图覆盖使用对应持续时间。状态进入现有图标、驱散与死亡清理，神符护盾与护身符分别消耗，当前优先消耗神符状态。

当前拦截范围为已实现的指定敌方单体法术，包含风暴之锤、霜冻新星、缠绕、净化、变形、法力燃烧和减速等；范围法术、攻击强化、终极技能和未列出的能力不经过这一拦截。多个相同护身符能力来源合并为单位上的一份冷却；物品在不同持有者间转移时使用各持有者的冷却。指定技能清单、范围伤害组合、弹道拦截时点、事件／音画、神符与护身符叠加次序、驱散／法术偷取、终极技能、复制／死亡／转移和多来源规则尚需原版对照。

Win32 Release 客户端及测试目标编译通过。隔离地图中 `war3_spell_tests <data-root> <fixture> spell-shield` 与 `shield-rune` 各 1/1：检查护身符、神符的范围与一次性状态、无敌友军、敌方和范围外单位、消耗、冷却恢复及移除；目标关闭自然生命恢复以隔离伤害。实际窗口、联机及原版一致性未验证。
