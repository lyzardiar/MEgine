# 回放的技能与建造菜单

经典动作 `0x66` 和 `0x67` 分别表示玩家打开英雄技能菜单和建造菜单，按单字节动作编解码；支持常规与实验时间片。动作记录在 `LanSimulation` 的逐玩家展示状态，不改变单位、命令或同步游戏状态。播放时，`GameView` 根据当前视角玩家的实际选中单位，在命令区使用已有技能学习／建造菜单进行绘制。选区或子组改变、控制组选择、Esc、发出命令和玩家离开时清除相应菜单状态；其他玩家的操作不会覆盖本地显示。

依据为 [w3g_actions.txt](https://github.com/nielsAD/gowarcraft3/blob/f13251b6caed199c3347214f4591e7ccaa96c7c7/file/w3g/w3g_actions.txt) 固定提交 `f13251b6caed199c3347214f4591e7ccaa96c7c7` 的经典动作格式说明；其记载这两项可在不可学习／无法建造时发出。文档只提供动作内容，不确认原版界面清理时序，当前清理规则需用 1.27 对照。实验对局打开技能／建造子菜单时发送对应动作，成功发送后打开本地界面，发送失败时显示提示；回放由时间片恢复该玩家的菜单。实验对局的菜单关闭额外记录内部 `0xfb` 动作，取消按钮、右键、菜单内 Esc 和界面切换可由实验回放恢复；原版关闭报文及完整回放仍待实现或对照。原版对象映射仍未实现。

待集中验证：动作编解码、同帧动作顺序、不同玩家及子组、无选中和非英雄／无建造能力、反复打开／取消、选择变化、普通／实验网络、回放视角和暂停／加速、完整画面与原版行为；`tests/order_queue_tests.cpp` 新增消费断言尚未编译或运行。
