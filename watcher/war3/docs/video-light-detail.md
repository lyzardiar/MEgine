# 视频选项中的模型灯光

主菜单与游戏内视频选项接入原 FDF 的灯光档位；确认后保存到用户目录 `Settings/video.bin` 第四版，取消或 Esc 放弃草稿。第一至第三版设置读取时默认高档，原有粒子、遮挡及阴影设置保留。低档跳过 MDX 模型内灯光，中档最多消费每个模型一个可见灯光，高档消费全部可见灯光；其他场景照明尚未实现。档位作用于模型绘制，不改变游戏模拟。档位划分是当前实现，尚无原版阈值证据。

待集中验证：主菜单和游戏内鼠标／键盘选择、确认／取消／Esc、切图及重启保存；旧版和损坏文件；无灯光、单灯光、多灯光、动态可见性及附件模型；实时切换后画面与性能、设备恢复、菜单和过场模型，并对照 1.27 原版档位与画面。本次未编译或运行。
