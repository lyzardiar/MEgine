# 虚无能力与 DotA 虚灵之刃

单位持有 `Aetl` 及其派生能力时进入现有虚无状态；能力添加、移除、法术书与可用物品更新均刷新该状态。虚无状态接入单位类别查询、普通攻击、目标选择、伤害和治疗计算，并与已有放逐和灵魂行者状态共存。

固定版 `Units/AbilityData.slk` 将 `Aetl` 标记为 `Ethereal`。DotA_v6.83d 的虚灵之刃 `I0LT` 通过原图脚本临时添加、移除该能力。其地图 `war3mapMisc.txt` 将 `EtherealDamageBonus` 覆盖为 `1.40,1.00,1.00,1.40,1.00,1.40,1.00`，伤害沿用该地图配置；不能据默认地图的零倍率推断 DotA 脚本伤害。

Win32 Release 客户端及测试程序编译通过。独立会话 `ethereal-ability` 1/1 覆盖能力添加／移除、类别查询、普通攻击限制、默认配置下的物理和魔法伤害，以及被动物品的持有与移除。DotA 原图隔离探针直接创建单位与 `I0LT`：目标 1 秒时有 `Aetl`、虚无查询为真且不能主动攻击，5 秒时虚无状态消失，记录 `tmp/docs-artifacts/war3/dota-ethereal/after.log`。探针直接施法并注入伤害，未覆盖自然购买或游戏窗口。

阶段核对物品和能力派生／禁用／共享、法术书和多来源、形态／死亡／复活／缓存恢复、状态和伤害类型叠加、地图倍率、真实窗口／原版动画与联机确定性。
