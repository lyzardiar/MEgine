# 高级工具提示

游戏性选项使用原 FDF 的 `TooltipsCheckBox`／`TooltipsLabel`；标签 `ENHANCED_TOOLTIPS` 在原 `GlobalStrings.fdf` 中为“高级工具提示”。确定后会影响当前游戏 HUD：启用时命令按钮悬停显示源 `Ubertip` 描述；关闭时保留名称、快捷键、费用／魔法／冷却及无法执行的原因，隐藏扩展描述。该设置不改变命令、资源或同步模拟。取消或 Esc 丢弃草稿。

该值与本地相机／游戏性设置共同保存到 `Settings/camera.bin` 的第 4 版；旧版文件默认启用，保持现有提示行为。文件损坏或不可读时沿用现有默认与不覆盖策略。不同对局和重启沿用已保存值。

原版扩展提示的具体内容、默认值、显示时序、显示区域、物品／单位／菜单及状态信息的完整范围尚未核实；当前只连接已有命令面板提示。阶段需验证鼠标／键盘操作、确认／取消／Esc、悬停状态与禁用原因、不同能力／商店／建筑按钮、旧设置升级／损坏／多实例及原版对照。Win32 Release 客户端增量编译通过，未执行实际界面或原版一致性验证。
