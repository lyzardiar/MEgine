# 英雄快捷栏位置预留

资料片战役 `Maps/FrozenThrone/Campaign/UndeadX01.w3x` 的 `war3map.j` 在创建战役英雄前调用 `SetReservedLocalHeroButtons(1)`。客户端保存该本地界面设置，英雄快捷栏将本地英雄优先放入前方，允许通过共享控制操作的其他玩家英雄从预留范围之后开始排列。空预留位置不拦截鼠标；英雄按钮、F1–F7、选择与命令使用同一槽位列表。脚本调用不改变地图模拟或联网同步状态。

依据：原安装 `UI/TriggerStrings.txt` 描述预留位置不供共享控制英雄使用；`UI/TriggerData.txt` 指定整数、编辑器默认 3 和范围 0–6。Game.dll 1.27 SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a` 的注册入口 `0x6f1edede` 对应 native `0x6f1f65c0`，经 `0x6f3b3020` 保存整数后刷新界面；REA 证据 `ev_f03f1858800dab9eb12f26890c391025fd301ba7ef12a3f44206f5c74476cc67`、`ev_24f030ba29b9e208cb704b3fc30c96ccd930ecaf551a8878fb4dd2ac29762020`。

客户端目前按对象创建顺序先列本地英雄再列共享英雄，显示最多七格，并将预留数量限制在显示范围；未设置时默认为零。原版默认预留数、英雄增删及共享控制变化时的槽位稳定性、隐藏／死亡和共享英雄可见性、极端整数行为尚待原版对照。需在 UndeadX01 实际运行、共享控制和 F 键／鼠标选择中验证。
