# Human05 村民撤退的路径状态

Human05 原图中村民进入撤退区域后先移除触发单位，再对同组单位调用 `SetUnitPathing`。该原生函数对失效单位句柄无操作，有效单位仍更新路径占地。

定向检查：隔离 Win32 x86 探针运行原图，越过此前失效句柄异常，约 80 秒恢复控制，并推进至 380 秒；记录 `tmp/docs-artifacts/war3/human03-continuation-1031/human05-item-pathing.log`。该探针同时包含 Human05 物品放置修复。

待阶段验证：对照原版 1.27 对空、已移除单位的语义，在产品客户端验证撤退及有效单位路径占地。REA 当前未配置深度分析提供程序，未获得原版函数反编译证据。
