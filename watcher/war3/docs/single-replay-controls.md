# 单机游戏控制命令

游戏菜单的暂停／继续和游戏速度确认通过 `GameView::submitPlayerCommand` 提交 `SetGamePause`／`SetGameSpeed`，与普通玩家命令共用会话分发入口。暂停命令带目标状态，速度命令带 0–4 档；本地玩家和无本地玩家时的默认视角可执行，其他玩家及网络槽位被拒绝。JASS 的 `PauseGame`／`SetGameSpeed` 仍由脚本直接执行。联网及实验回放界面保持原有控件禁用与输入隔离。

该入口只汇聚外部游戏控制变更，尚未记录模拟步进、命令或初始地图／玩家／战役缓存，也不创建回放文件，不能播放单机或原版回放。脚本暂停、菜单打开时的时间冻结和运行时顺序仍须由后续录制器忠实记录或复现。

集中验证：真实菜单五档确认／取消、暂停／继续与脚本状态交错；检查非本地、无本地视角、无效速度和网络／回放隔离；运行 `tests/game_flow_tests.cpp` 新增会话断言，最终在录制／播放接入后核对控制顺序及模拟一致性。
