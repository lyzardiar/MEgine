# 随机中立单位和物品

`ChooseRandomCreep`、`ChooseRandomNPBuilding`、`ChooseRandomItem` 和 `ChooseRandomItemEx` 使用公共资源及地图对象覆盖构建候选，抽取结果作为真实类型 ID 返回给脚本。候选按请求条件缓存，地图会话隔离；随机选择使用既有会话 RNG，空集合返回 0。单位按中立种族、建筑与当前地形集筛选；中立建筑还检查随机建筑开关。物品读取物品分类、随机掉落开关和源等级，普通接口使用 `oldLevel`，扩展接口使用 `Level`；等级 -1 表示任意。自定义单位和物品继承原型与覆盖字段。

原安装 `Game.dll` SHA-256 为 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`。原版 native 注册入口分别为 `0x6f1db0a0`、`0x6f1db100`、`0x6f1db0c0`、`0x6f1db0e0`。只读 Rizin 观察：`0x6f655520`／`0x6f655820` 依据类型和地形集筛选单位，`0x6f639b20` 依据物品分类和等级筛选；空集合返回 0，等级 -1 跳过等级比较，随后从候选集合选择。普通物品调用传入类型 7，并走不同等级访问器。源码中 `UnitUI` 的 `special`／`campaign` 与原版筛选标志的对应是当前实现假设，尚未确认；对象扫描顺序及会话 RNG 的抽样结果也未证实与原版一致。

待功能阶段验证原版固定种子与不同地形集、单位类别／英雄／特殊与战役对象、自定义继承和字段覆盖、物品各分类／等级／随机标志、任意及无匹配等级、重复调用与随机序列，以及实际地图掉落和多客户端同步。候选缓存限制为每类 4096 组不同过滤条件；原版边界与统计分布仍需对照。产品不加载 `Game.dll`。

Win32 Release 客户端增量编译通过；代表地形的源表候选已静态核查，实际脚本与对局尚待验证。
