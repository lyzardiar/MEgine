# 对局聊天窗口

游戏顶部“聊天”和 F12 打开原版 `UI\\FrameDef\\UI\\ChatDialog.fdf`，展示聊天历史、玩家／盟友／观察者／所有人四种目的地和原确认按钮；Shift+F12 保留原消息纪录窗口。鼠标选择单选项和玩家下拉菜单，方向键切换目的地，Esc、F12 或确认关闭。窗口开启期间沿用现有游戏菜单输入屏蔽，不暂停模拟；回放不能发送聊天。

普通 Enter 打开输入栏，使用聊天窗口当前选中的目的地；Shift+Enter 选择所有人，Ctrl+Enter 选择观察者。私聊将玩家 ID 交给现有会话受众过滤，实验局域网使用额外 `0xfc` 动作携带目标槽位，正常频道维持 `0xf0`–`0xf2`；私聊目标离开后，窗口保留原目标并标记为已离开；发送时校验失败并保留输入，直到主动选择其他目标。目标在消息抵达前离开时丢弃该私聊。该动作仅供同构建实验联机及其回放使用，原版局域网协议尚未实现，不能视为保密通道。

历史只读取当前会话中对本机可见且标记为玩家聊天的消息，并转义用户文本中的颜色控制符；脚本消息继续进入消息纪录窗口。各窗口的可见性、滚动、目标变更、断线、回放、多人受众、键盘焦点、汉字编码、覆盖、资源释放与原版默认频道和界面仍需集中验证。

对局输入栏支持左右方向键、Home、End、Delete、退格与光标处插入；UTF-16 代理对按完整字符移动和删除。输入内容超过可见宽度时显示光标附近文字，发送仍使用完整内容；原有 256 个 UTF-16 代码单元上限、频道和发送流程保持。隐藏客户端键盘消息检查 `abcd` 中间删除并插入后显示 `abXd`；实际前台输入、中文输入法、鼠标定位、长文本与原版光标样式仍待验证，局域网大厅聊天输入暂不使用该编辑器。
