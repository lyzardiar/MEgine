# 对局聊天窗口

游戏顶部“聊天”和 F12 打开 `UI\\FrameDef\\UI\\ChatDialog.fdf`，展示聊天历史、玩家／盟友／观察者／所有人四种目的地和确认按钮。编辑草稿时也可以打开这个窗口。用鼠标选择单选项和玩家下拉菜单，或用方向键切换目的地。Esc、F12 或确认关闭窗口并返回草稿，普通 Enter 发送。Shift+F12 打开消息纪录窗口。聊天窗口开启期间屏蔽普通游戏输入，模拟继续运行。回放只提供聊天记录查看。

普通 Enter 打开输入栏，使用聊天窗口当前选中的目的地。打开输入栏时，Shift+Enter 选择所有人，Ctrl+Enter 选择盟友。私聊按发送者和收件人筛选界面显示，同构建的 `0xfc` 动作携带目标槽位，其他频道使用 `0xf0`–`0xf2`。目标离开后标记「已离开」，发送失败时显示提示并保留草稿，用户可用 F12 主动选择其他目标或频道。应用时间片动作时复查收件人是否仍在线，丢弃在离席动作之后到达的私聊。时片及自研回放包含私聊动作。原版局域网协议待实现。

历史只读取当前会话中对本机可见且标记为玩家聊天的消息，并转义用户文本中的颜色控制符；脚本消息继续进入消息纪录窗口。各窗口的可见性、滚动、目标变更、断线、回放、多人受众、键盘焦点、汉字编码、覆盖、资源释放与原版默认频道和界面仍需集中验证。

对局输入栏支持左右方向键、Home、End、Delete、退格与光标处插入；UTF-16 代理对按完整字符移动和删除。输入内容超过可见宽度时显示光标附近文字，发送仍使用完整内容；原有 256 个 UTF-16 代码单元上限、频道和发送流程保持。隐藏客户端键盘消息检查 `abcd` 中间删除并插入后显示 `abXd`；实际前台输入、中文输入法、鼠标定位、长文本与原版光标样式仍待验证。

局域网房主与来客共用字符边界编辑，支持方向键、Home／End、Delete、退格、鼠标定位及光标附近显示。消息上限为 254 个 UTF-8 字节，竖线在历史中按全角显示，发送保留原文本。切换焦点时清理未完成代理对，发送成功后清空草稿。聊天历史保留最近 200 条消息，按可用宽度折行，并使用消息入队时的发送者名称。正式客户端已验证中文编辑、焦点、254 字节长消息和席位复用后的署名。前台输入法与原版操作待验证。

历史区支持滚轮、滚动条箭头、轨道翻页和拖动滑块。单击历史区后可用 Page Up／Page Down 翻页，Home／End 跳到首尾。滚轮操作保留输入焦点和草稿插入点。收到新消息时，正在翻阅的内容保持在原位置，超出 200 条而淘汰当前内容时显示最旧保留消息。滚到底部后自动跟随新消息。

对局聊天在输入框内单击可将插入点定位到可见文本的字符边界；长文本继续围绕当前插入点滚动，点击标签前部或文本尾部限制在当前可见区间。实际前台鼠标、输入法、长文本和原版交互仍待功能阶段对照。

对局聊天输入框的所有人、盟友、观察者和私聊前缀读取 `GlobalStrings.fdf` 的 `COLON_MESSAGE_ALL`、`COLON_MESSAGE_ALLIES`、`COLON_MESSAGE_OBSERVERS` 和 `COLON_MESSAGE_PLAYER`；私聊按源格式插入完整玩家名，资源缺项时沿用客户端回退文字。离开标记仍使用客户端文字。实际多语言窗口、长名称裁剪和原版显示时机待功能阶段对照。
