# 法术弹道的目标高度与追踪

法术弹道发射时使用目标单位的 `UnitWeapons/impactZ` 与目标当前飞行高度确定落点；弹道追踪期间继续读取目标的移动类型和飞行高度。目标移动时，飞行全程距离随剩余路程增长，使游戏画面的高度插值和弧线不会过早抵达终点。范围命中、法术伤害、目标判断和事件顺序继续由原有施法流程处理。

实现复用地图覆盖后的单位源表，并与普通追踪武器弹道使用相同的目标高度、路径距离规则。链式法术下一跳沿用对应目标；无效目标仍按原有流程释放。原版是否对所有法术弹道采用相同锚点和弧线规则尚需对照。

待集中验证：施法者和目标不同碰撞／impactZ、自定义对象覆盖、飞行高度及单位移动／变形、目标死亡／隐藏／移除、链式弹道的各跳、长距离和短距离、画面轨迹及原版 1.27 逐帧对照，兼顾多人确定性和高密度性能。`tests/spell_tests.cpp` 已新增实际暴风之锤弹道的目标高度和追踪距离断言；本次未编译或运行。
