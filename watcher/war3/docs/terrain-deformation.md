# 地形波纹变形

`TerrainDeformRipple` 在会话中创建有时钟的地形波纹；`TerrainDeformStop` 按指定时长淡出，`TerrainDeformStopAll` 清除当前波纹。地图资源保持只读，效果不创建解包文件。地形高度查询、单位贴地与地面、悬崖和荒芜绘制消费同一变形场；水面保持原高度。效果按 128 单位地形角点采样并插值，受影响可见区块更新顶点缓冲，纹理不重建；结束后恢复静态顶点，未受影响区块不上传。

`TerrainDeformCrater` 按时间形成中心向边缘余弦衰减的凹坑；非永久凹坑完成后恢复，永久凹坑自然完成后将自身最终位移保存在地形高度场。Stop 完成清除尚在形成的效果，不移除已固化地形；Stop 尚未结束而自然到期时固化当时的淡出幅度。`TerrainDeformWave` 沿归一化方向传播，以移动线段及余弦径向衰减生成位移，周期末尾淡出；两者与 Ripple 共享停止、单位高度和区块绘制。持久凹坑的原版高度量化、零时长、波浪零方向／速度、超界参数及重叠时序尚待对照；当前拒绝负半径、非正速度和非零距离的零方向。
