# 地形波纹变形

`TerrainDeformRipple` 在会话中创建有时钟的地形波纹；`TerrainDeformStop` 按指定时长淡出，`TerrainDeformStopAll` 清除当前波纹。地图资源保持只读，效果不创建解包文件。地形高度查询、单位贴地与地面、悬崖和荒芜绘制消费同一变形场；水面保持原高度。效果按 128 单位地形角点采样并插值，受影响可见区块更新顶点缓冲，纹理不重建；结束后恢复静态顶点，未受影响区块不上传。

原版 1.27 Game.dll 的 Ripple 回调按半径、起始比例、总进度、空间／时间波数、深度和负值限制计算位移；正时长按次数结束，负时长保持，Stop 使用单独淡出时钟。源证据：`ev_13e0d73228d776cb08d8304f604c7634fb3382d48beb5d50166da9ab3f894ebf`、`ev_6f8da73306f627c8f84b78d4094e32736f6eb1f581eb8a2d6213046f645369e3`、`ev_0e51921cecafe836b66093fa359963823943f160d2a88d8bb386e3e96b08bd08`、`ev_d9c4a061d201d13f9dea9e7648561f7dc8d0d6ab6f8872d89c732d232b719826` 和 `ev_197d1f8d7f7713ea412ea71c409c713384bd2ef18e083bbeb80637ddbab2453c`。当前时钟使用会话固定步进；原版每帧毫秒取整、数值精度、采样分辨率、零／负时长和暂停时序尚待对照。原件静态路径显示负时长记录的周期数继续增长，总进度可能超过 1，长期表现仍需运行对照；零时长、单周期产生的零位移不占用活跃波纹预算，多周期静态波纹保留并待原版对照。深度限制为绝对值 1,000,000、同时最多 256 个有效波纹。其他 Crater／Wave／Random 原生接口、可破坏物贴地与完整地形表现仍待实现。

阶段运行 `python tests/generate-game-flow-fixture.py --data-root <data-root>` 和 `war3_game_flow_tests.exe <data-root> <fixture.w3m>`，并验证 DotA 技能、单位与地形一致性、波形叠加／淡出／结束、边界与离屏恢复、暂停／切图、GPU 设备恢复和大量波纹性能，实际画面及原版一致性尚未验收。
