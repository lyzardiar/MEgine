# 回放玩家离开记录

回放播放驱动收到 W3G `0x17` 玩家离开记录时，解析记录中的连接原因、玩家编号、对局结果与计数字段。对开始后、原因 `0x01`（远端连接关闭）且编号映射到当前活动非主机玩家的记录，回放通过 `LanSimulation` 与会话既有的玩家离开流程更新槽位、处理等待中的选择同步并触发 `EVENT_PLAYER_LEAVE`，随后继续播放。回放表现层清理玩家子组／菜单并丢弃回放过程中的本地网络输出。该记录不推进模拟时钟，处理顺序与相邻时间片保持一致。

玩家离开记录不推测胜负或据结果字段发出胜利／失败事件；这些状态仍由已重建的对局和脚本驱动。播放器拒绝未知编号、重复或非活动玩家、该玩家尚有未完成的缓存同步、未知结果、主机及开始前记录。`0x0c` 保存者及 `0x0e` 等原因、开局阶段离开和主机离开的原版行为仍待完成；播放器不会将它们伪装成普通远端离开。已录制的自研局域网回放仍使用已有的私有时间片离开动作，不额外生成 `0x17`。

格式依据为 blue、nagger 的 [W3G 格式说明](https://github.com/nielsAD/gowarcraft3/blob/f13251b6caed199c3347214f4591e7ccaa96c7c7/file/w3g/w3g_format.txt) `0x17 LeaveGame`，固定版本 `f13251b6caed199c3347214f4591e7ccaa96c7c7`。该实现接入现有回放运行分支，不改变原版回放对象编号校验；当前产品仍只接受同构建自研回放，完整原版回放尚不能播放。

待集中验证：离开记录在时间片之间的顺序、有效及已离开玩家、地图 `EVENT_PLAYER_LEAVE` 回调、正在等待的选择／缓存同步、不同结果与本地视角、非法和重复记录、后续玩家动作及两端／回放状态。原版 1.27 的离开事件与结果时序仍需实机对照。

Win32 x86 MSVC 以 `/utf-8 /Zs` 检查 `replay.cpp`、`lan_simulation.cpp`、`game_view.cpp` 和 `main.cpp` 通过；未运行产品播放或专项测试。
