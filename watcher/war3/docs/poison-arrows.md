# 毒箭与 DotA 推进

`AEpa` 毒箭使用源目标筛选、弹道、额外武器伤害、魔法消耗及自动施放订单。命中时按 `DataB`／`DataC`／`DataD`／`DataE` 和单位／英雄时长创建毒状态，复用既有毒剂的持续伤害、移动和攻击速度、叠加与清理；手动施放在攻击发射时触发技能效果事件，攻击命中前建立状态，使地图伤害事件可以读取该状态。`enemies`／`allies` 目标别名与 `enemy`／`friend` 同样进入武器目标筛选。

Win32 Release 客户端及测试目标编译通过；`war3_spell_tests.exe <data-root> <fixture> poison-arrow` 1/1，覆盖手动施放、魔法消耗、技能效果与命中时状态、持续伤害和自动施放。DotA_v6.83d 隔离会话中魅惑魔女学习 `A0DY`，在相距约 500 的敌方单位上分别执行手动和自动攻击，均观察到约 132 点总生命损失及对应魔法消耗；探针位于 `tmp/docs-artifacts/war3/dota-hero-1031/enchantress-impetus-probe.cpp`。
