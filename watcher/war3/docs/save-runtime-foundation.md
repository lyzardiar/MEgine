# 战役存档的脚本执行状态

JASS 运行时的操作数、调用帧、局部变量与当前 native 参数由运行时按线程和嵌套层级持有；诊断接口返回副本，可观察等待、回调和取消时的执行状态。命名函数和 code 启动使用可识别的结构化线程入口，诊断可读取入口、参数和状态；匿名任务及部分触发器闭包仍保留。游戏实际执行仍使用现有 Fiber 与 native 回调，运行时编号仅在进程内有效。

JASS 运行时可将一个或一批结构化线程在已登记的简单睡眠 native 中暂停时的剩余时间、调用帧、操作数和局部槽复制到另一运行时并继续执行。批次只保存一份源码身份，按原线程顺序建立新线程，保留不同到期时间及同一到期时间的执行顺序；批次中任一线程无法恢复时清理整批。恢复前校验源码、调试编译选项、调用关系和槽类型；同一脚本的函数引用移除原运行时指针并在目标运行时重新绑定。非零句柄要求调用方提供双向稳定编号映射；重复引用复用映射，编号冲突或映射失败时拒绝。会话线程的事件上下文及其选择视图可随线程传递；模块声明的继承关系用于检查兼容静态类型的编号一致性。对象存在性和生命周期由对象恢复层负责。批次中包含嵌套 native、未支持的线程等待／外部等待、共享调度域、实验选择同步或跨运行时函数引用时仍拒绝。

基础类型全局值允许在运行时已让出执行时单独采集；调用方须先恢复全局值及所引用对象，再恢复线程。线程和会话上下文可编码为独立的 `JSTH` 版本 3／`JSSC` 版本 3 字节组件，两者仍可读取各自的版本 1、2，包含源码名称及 SHA-256、调用帧、值、上下文和选择视图；组件内容另带 SHA-256，读取前校验摘要，并限制字节、线程、槽、数组和文本数量。源码摘要用于拒绝脚本版本不匹配，组件摘要用于发现数据损坏，并不提供身份认证。隔离会话通过真实游戏事件启动两个触发器动作，将组件写入临时文件并读取，恢复到使用不同触发器句柄的会话后继续读取事件与触发器；实际地图、完整触发器链及对象图仍待验证。

默认等待模式的触发器动作可进入结构化线程。序章原图在 120 秒静音模拟后，隔离检查清空队列并通过原 `QueuedTriggerAddBJ` 启动 `gg_trg_Waste_Queue_Time`；其原动作睡眠期间被编码、取消并在同一会话恢复，到期后通过 `GetTriggeringTrigger` 将自身从队列移除。日志位于 `tmp/docs-artifacts/war3/single-serial-trigger/prologue-serial.log`。该检查复用已有世界对象，不代表跨进程或完整战役存档恢复。

组件本身不保存全局值或世界对象，也没有连接保存菜单、自动写入目录或读取原版存档；不得将它当成完整游戏存档。未登记的线程等待及其他 native 栈仍会阻止采集。

完整恢复仍需解决 Fiber 中其他 native 调用栈、调度器等待关系、触发器回调与上下文、句柄引用及 codeOwner 指针，并将全局、世界和玩家状态、随机数、事件、计时器、活动命令及地图身份组成统一事务；还需接入保存／载入事件、用户界面及原版格式。兽族战役切区涉及多区域存档，单独保存英雄或 gamecache 无法代替完整世界保存。
