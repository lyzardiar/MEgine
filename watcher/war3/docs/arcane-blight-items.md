# 抗魔药水、蜘蛛丝与献祭头骨

抗魔药水 `pams` 的 `AIxs` 接入持有者的抗魔状态，蜘蛛丝 `silk` 的 `AIwb` 接入单位目标蛛网及物品施法；费用、冷却、次数与事件复用现有物品链。献祭头骨 `skul` 的 `Ablp` 使用地面点目标，按源范围、步长和间隔在会话固定步扩张或移除荒芜，效果不依赖物品或施法者继续存在；排队与实验联机沿用物品命令，活动扩张状态和容量预留纳入实验联机摘要；地表 WPM 荒芜位和地形角点荒芜位以增量指纹纳入摘要，避免逐帧扫描；指纹存在碰撞概率，也不覆盖其他寻路位。

献祭头骨通过点目标施法链接近目标、预留扩张容量，并在释放时支付及触发事件；目标、支付／事件顺序、扩张覆盖及重叠、地图自定义字段、多人同步、视觉和原版时序均待阶段验证。原版 1.27 资源参数和来源见 `tmp/docs-artifacts/war3/equipment/source.json`。
