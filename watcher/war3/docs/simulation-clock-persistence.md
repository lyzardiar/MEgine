# 模拟时钟快照

`ScriptSession::encodeSimulationClock` 编码固定步进的模拟时间、未消费余量、暂停状态和游戏速度，写入带版本和内容摘要的 `SCLK` 字节组件。恢复先完整检查摘要、格式、有限数值、1/32 秒时间网格、余量与枚举范围，再同步脚本调度时钟并设置会话字段。模拟时间上限为 2^40 秒；摘要用于发现损坏，并不提供身份认证。

采集要求已初始化的本地会话和脚本当前已让出执行；恢复要求完成配置和玩家设置，但尚未运行地图 main、创建单位、启动 AI 或登记计时器／计时事件，且不存在活动线程和脚本上下文。调用方须在恢复对象、事件和睡眠线程之前恢复此组件，并保证地图、脚本及全部组件属于同一快照。`SCLK` 版本 2 同时保存昼夜时刻、速度、暂停及临时昼夜效果，并校验地图昼夜规则；读取版本 1 时保留目标会话已有昼夜状态。该组件不包含世界对象、计时器、事件、随机数、脚本线程或绝对期限对象；孤立恢复不能构成有效对局存档，也不提供原版格式或菜单入口。
