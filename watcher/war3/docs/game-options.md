# 游戏内选项与本地设置

F10／Esc 菜单的“选项”入口使用原版 `UI\FrameDef\UI\EscMenuOptionsPanel.fdf`，可进入游戏性页面，通过原 `MouseScrollDisable` 复选框切换鼠标边缘滚动，并使用原鼠标／键盘滚动滑块分别设置本地相机速度。控件支持鼠标和键盘操作；确定应用，取消或 Esc 丢弃草稿，设置不修改同步游戏状态。鼠标与键盘速度分别作用于各自输入，并分别读取源 CameraRates 的 Strafe／Forward 基础值。当前 0–100 滑块暂按 0.5–1.5 倍线性映射，默认 50 对应既有基础速度；原版滑块映射与默认值尚未证实。

声音页面接入原版音效和音乐复选框及 0–100 音量滑块，支持鼠标拖动和键盘调整；确定应用，取消或 Esc 丢弃草稿。独立用户增益叠加脚本音量组及原有淡入淡出，不改写 JASS 音量，不影响 `--mute`；地图配置与 main 启动前加载，普通音效、堆叠环境声、地图音乐、主题音乐、主菜单音乐和过场声音均有消费者。游戏内过场读取当前会话的已确认设置；音量为零时过场不初始化音频输出。游戏会话中的静音增益仍可能创建音频设备，无设备运行使用 `--mute`。

设置分别保存在独立用户目录 `Settings/camera.bin` 与 `Settings/audio.bin`，默认启用边缘滚动、滚动速度均为 50，并使用完整音量。旧版相机设置可直接读取，保留已有开关并在确认修改后写入新版格式。路径按 `MEGINE_WAR3_USER_DIR` 或 `%LOCALAPPDATA%\MEgine\War3` 解析，写入前检查不与只读原安装重叠，并通过临时文件原子替换。临时文件名发生冲突时采用新的序号重试。设置无法读取或格式不受支持时使用默认值并记录日志，本次会话不覆盖原文件；保存失败记录日志，当前运行中的选项仍生效。

原版 FDF 来自 `War3Patch.mpq`，SHA-256 `50800656634111843bf0d1aa4c59c7f296914c8279a592ff8367b6a9b0812659`；本次核对了游戏性与声音页面使用到的帧名称。Win32 Release 产品编译与差异检查通过。实际窗口布局、焦点、快捷键、鼠标拖入／拖出、取消／确认、菜单内 Esc 与建筑施工隔离、跨对局与重启保存、损坏文件和不同用户目录的行为尚待集中验证。

游戏性页面的生命条选项和按住 Alt 临时显示已接入，显示可见存活单位的当前生命比例；隐藏单位、战争迷雾与视野规则沿用现有选取路径。生命条采用屏幕空间基础色块和估计高度，原版纹理、单位高度、颜色与按键行为尚待对照。该设置随相机设置保存，旧版本设置读取后默认关闭。

游戏性页面接入五档游戏速度：确认后写入当前会话，取消或 Esc 丢弃草稿；脚本 SetGameSpeed 与 GetGameSpeed 消费同一状态。单机主循环以该状态调整实际时间到固定 1/32 秒模拟步进的换算，镜头输入仍使用实际时间；暂停与菜单沿用现有逻辑。当前五档暂映射为 0.5／0.75／1／1.25／1.5 倍，原版速度倍率、标签、地图与跨对局默认值待对照。联机选项中的速度控件禁用，网络时间片与脚本速度同步仍待实现。

视频页面接入原版粒子和遮挡下拉菜单。粒子低／中／高分别将 PRE2 发射密度调整为原模型的 25%／50%／100%；既有粒子自然消退，材质／条带／闪电与模拟逻辑不受该选项影响。遮挡开启时，使用现有场景对象遮挡检测和透明渐变；关闭时停止遮挡扫描并让已淡出的物件恢复，同时保留脚本 EnableOcclusion 的独立限制。确定后生效并写入独立用户目录 `Settings/video.bin`，取消或 Esc 丢弃草稿；旧版文件默认启用遮挡，损坏文件保留且使用默认值。粒子设置由使用同一渲染器的模型消费，遮挡设置作用于当前游戏场景，切换对局沿用已保存值。粒子比例和遮挡的原版精度尚待对照；窗口输入、GPU 表现、连续切图及设备恢复待功能阶段验证。

游戏性页面的高级工具提示开关连接命令面板的扩展描述；确定后保存，取消或 Esc 丢弃草稿。基础名称、费用和禁用原因始终保留，原版显示范围待验证，见[高级工具提示](enhanced-tooltips.md)。

游戏性页面的编队移动开关控制单机多选移动、攻击移动和巡逻的现有编队目标分配；关闭后各单位接收相同目标点，排队命令保留提交时的选择。确定后保存至 camera.bin，取消或 Esc 丢弃草稿，旧文件默认开启。游戏中 Alt+F 可切换并保存，聊天及其他界面不触发；快捷键来自源 MiscUI。联机选项暂锁定开启以保证所有客户端使用相同确定性命令；原版队形、速度协调及开关默认值和实际交互仍待对照。

当前实现鼠标边缘滚动、鼠标／键盘滚动速度、生命条、单机游戏速度、编队移动、单机子组命令修饰键、高级工具提示、音效／音乐开关及音量、粒子密度和遮挡开关；细分声音项、其他视频和网络选项尚未实现，未完成控件暂时禁用或隐藏，不能视为完整原版选项界面。

游戏性子组选项及同类型选取接入范围见[子组命令](subgroup-order.md)；原版交互和联机子组命令待完成或验证。
