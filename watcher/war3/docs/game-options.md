# 游戏内选项与相机设置

F10／Esc 菜单的“选项”入口使用原版 `UI\FrameDef\UI\EscMenuOptionsPanel.fdf`，可进入游戏性页面，通过原 `MouseScrollDisable` 复选框切换鼠标边缘滚动。鼠标和键盘可操作复选框；确定应用，取消或 Esc 丢弃草稿。生效值只影响本地相机的屏幕边缘移动，不影响键盘方向键，也不修改同步游戏状态。

设置保存在独立用户目录 `Settings/camera.bin`，默认启用边缘滚动。路径按 `MEGINE_WAR3_USER_DIR` 或 `%LOCALAPPDATA%\MEgine\War3` 解析，写入前检查不与只读原安装重叠，并通过临时文件原子替换。临时文件名发生冲突时采用新的序号重试。设置无法读取或格式不受支持时使用默认值并记录日志，本次会话不覆盖原文件；保存失败记录日志，当前运行中的选项仍生效。

原版 FDF 来自 `War3Patch.mpq`，SHA-256 `50800656634111843bf0d1aa4c59c7f296914c8279a592ff8367b6a9b0812659`；本次核对了使用到的 28 个帧名称。Win32 Release 产品编译与差异检查通过。实际窗口布局、焦点、快捷键、鼠标拖入／拖出、取消／确认、菜单内 Esc 与建筑施工隔离、跨对局与重启保存、损坏文件和不同用户目录的行为尚待集中验证。

当前只实现鼠标边缘滚动开关；游戏速度、键盘／鼠标滚动速度、提示、编队、生命条、视频、声音和网络选项尚未实现，未完成控件暂时禁用或隐藏，不能视为完整原版选项界面。
