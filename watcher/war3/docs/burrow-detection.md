# 钻地侦测

Abur 及源派生能力使用既有单位变形、钻地不可移动／攻击、隐形位和侦测消费；地穴恶魔、甲虫与蛛怪的源类型按 Abur 配置的普通／钻地单位选择。Abdt（Burrow Detection (Flyers)）现接入被动侦测原型，使用源 Rng、DataA 及地图 w3a 覆盖，进入现有侦测网格、联盟共享、可见性、攻击与地图绘制的共同判定。

本机 1.27 公共 AbilityData 中 Abdt 的 Rng1 为 900，DataA1 为 0；该配置不提供检测位。自定义覆盖可设置检测位 2（钻地）或 1／3，并采用对应共享网格与失效机制；未给所有飞行单位自动添加该能力。Abdt 原版自动赋予规则及零检测位的原版语义尚未确认。

待功能阶段使用 undead forms 夹具与消费者验证原始零掩码、自定义 2 掩码、能力增加／删除、位置和范围、敌对／共享玩家、侦测与普通隐形组合、单位死亡／易主／变身、甲虫召唤与钻地／出地、地图加载／切换以及原版行为。现有夹具新增自定义 A0BD，专项尚未执行。
