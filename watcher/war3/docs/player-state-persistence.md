# 玩家基础状态快照

`ScriptSession::encodePlayerStates` 编码 16 名玩家的完整 `states` 映射和两项维护费覆盖标志。`states` 被资源收支、人口、玩家状态原生函数及对局结果等现有消费者使用；键和值均逐项保留。`restorePlayerStates` 验证 PSTA 版本、玩家数、布尔标记、累计条目预算、重复键和完整数据边界，先为全部玩家构造临时状态，再统一替换；失败不更改任何玩家状态。恢复不会触发玩家状态变化事件，也不会自行重算人口或维护费。

接口要求会话已初始化、地图世界及玩家设置已就绪，调用位于会话所属线程，当前无脚本执行、脚本线程或回调，并拒绝联网会话。这些限制用于当前基础接口的安全边界，含活跃脚本线程的真实存档仍需实现一致的冻结与恢复协议。

本快照未包含单位／建筑、生产队列、玩家联盟、税率、科技、计时器、事件、统计或地图身份；人口及维护费与单位、订单、科技和资源须作为同一时刻的完整会话事务恢复。该接口尚未接入存档文件、载入菜单或战役地图切换，不支持原版存档格式，禁止作为完整存档单独使用。

待集中验证：多玩家非默认键和值、极值及维护费覆盖往返；截断、额外数据、重复键、错误玩家数和超预算均不修改任何玩家；活动脚本及联网拒绝；与后续单位／队列／科技和事件状态一致性及真实战役恢复。
