# 亡灵第二关乌瑟尔死亡对白

亡灵第二关的原图在乌瑟尔死亡后用 `ReplaceUnitBJ` 移除原单位，再继续用旧句柄发出对白。`GetOwningPlayer` 对失效单位返回空玩家，`GetPlayerColor` 对无效玩家返回颜色值 0；`IsUnitHidden` 对失效单位返回 false。有效玩家颜色和有效单位的隐藏状态继续使用实时状态。对白定位和单位指示复用现有脚本路径。

固定版 Game.dll SHA-256 为 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`。REA 的 Rizin 0.8.1 只读指令显示 `GetPlayerColor` 注册入口 `0x6f1e3ca0` 在玩家解析失败时返回零，`IsUnitHidden` 入口 `0x6f1e86c0` 在单位解析失败时返回零；指令与原图定位记录位于 `tmp/docs-artifacts/war3/undead-goal-1031/`。

定向检查：隔离 Win32 x86 探针使用与现有核心库同布局的快照并重新编译两个修改单元；装载原图后人工击杀布赞及三名圣骑士，越过乌瑟尔死亡对白的原异常并推进至 400 秒，记录 `undead02-final.log`。在该场景检查原句柄的所属玩家、玩家颜色和隐藏状态均返回 0，有效玩家颜色仍为 3，不兼容玩家句柄返回 0。探针通过直接击杀驱动剧情，未证明实际战斗、画面、音频或整关通关。
