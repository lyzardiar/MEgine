# 自定义地图图像

`CreateImage` 创建独立 image 句柄，`DestroyImage` 销毁状态；支持 `ShowImage`、位置、颜色、恒定高度、渲染开关、始终渲染、水面选项与图像类型，句柄可经 hashtable 存取。纹理按可见图像进入现有异步 MPQ 读取／解码／GPU 上传队列，切图随场景资产释放；无地图解包或原安装写入。DotA 的数字纹理调用使用此链路。

当前实现以尺寸和位置减原点生成地形贴合网格，保留源纹理 alpha 与脚本颜色；恒定高度采用固定世界高度。正常图像参与迷雾，renderAlways 关闭该图像的迷雾调制；水面下图像在水面前绘制，aboveWater 使用地形／水面较高高度且在水面后绘制。useWaterAlpha 根据同地图 Water.slk 的深度透明度与脚本水色 alpha 调整透明度；图像按 type 升序绘制。面积按 128 单位网格细分，每轴最多 64 段；透明度、水面、类型排序、原点／Z 和默认状态均为当前实现，尚未与原版画面或函数行为对照，不能视为完全还原。

单会话最多 8192 个图像，坐标和尺寸限制在有限值且绝对值不大于 1000000；负尺寸明确失败。缺失或无法解码的纹理按现有场景加载错误处理。尺寸 Z 已保存，当前为地面二维网格并不构造体积几何；不同 imageType 的原版特殊混合／排序及阴影、水面 alpha 语义尚需实现或证实。

阶段集中验证 DotA 运行期的数字、地图覆盖纹理、创建／颜色／显示／移动／销毁、hashtable 句柄和本地玩家分支，细分地形／斜坡／悬崖／水面／恒高、迷雾／renderAlways、GPU 设备恢复、资源释放和高密度性能；与 1.27 逐项对照图像类型、顺序、坐标、透明度及无效输入。Win32 Release 客户端增量编译通过；未执行实际运行、GPU 或原版对照。
