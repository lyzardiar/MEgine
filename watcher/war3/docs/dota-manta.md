# 镜像物品与幻影斧

`AOmi` 原型的主动能力物品通过物品施法调用既有镜像转换、负面状态清理、幻象创建和冷却。转换期使用仍有效的物品施法票据跟踪来源；普通单位技能仍要求单位保有相应能力。幻象数量、伤害倍率、寿命和转换延迟读取地图能力定义。

Win32 Release 客户端及 mobility 测试程序编译通过。DotA_v6.83d 原图隔离会话直接创建圣骑士与幻影斧 `I09F`，使用后恢复原英雄并创建两名幻象，观察输出倍率 0.33、承伤倍率 3.5 和物品冷却；记录 `tmp/docs-artifacts/war3/dota-item-probe/I09F-clones.log`。共享单位技能回归 `mirror` 1 通过、0 失败，不加载 Game.dll。

阶段核对实际购买／合成、远程英雄与物品替换、幻象属性和命令、负面状态清理、转换中取消／死亡／物品移除、召唤事件与重入、不同地图覆盖、真实窗口、原版和联机。
