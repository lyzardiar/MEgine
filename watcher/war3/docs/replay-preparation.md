# 回放地图与会话准备

`ReplayPreparation` 读取已解析回放中的初始玩家、槽位和随机种子，使用既有异步 `LanMapCheckTask` 将录制路径限制在安装目录 `Maps` 内，读取不超过 256 MiB 的地图字节快照，并在内存中核对地图成员。录制的有效地图 SHA-1 或非零／非全 1 校验值存在时与既有 W3GS 地图计算结果比较；录制尺寸非零时与地图元数据比较。验证成功后复用同一快照建立 `MapPreparation` 会话、按槽位设置玩家及随机种子，并返回配置完成的 `PreparedReplay`。没有有效校验字段的旧回放仅按受限路径选择地图，不能证明地图身份。资源直接来自公共／地图归档，不生成解包文件。

调用方必须在回放前选择一个录制的人类玩家作为本地视角；不指定时优先录制房主，否则选首个活动人类。`PreparedReplay::startMain` 供无渲染消费者显式启动；游戏渲染流程应将 session 交给 `GameLoading`，由它启动 main，二者不可重复调用。准备期间可轮询或取消，失败保留错误，转交后会话独立存活。

槽位按 W3I 可玩玩家顺序对应回放槽位，与现有自建 LAN 使用同一受限映射；未占用槽内的无效队伍／颜色／种族／让分值只用于兼容不参与对局的空槽，会被归一化。主菜单播放入口已连接自研同构建局域网记录，完整原版槽位映射、观察者、战役回放及原版对象编号尚未完成；不同版本共用脚本、录制者的本地分支和现有 W3GS 地图摘要算法可能导致校验拒绝或初始化差异。此实现不能视为可播放回放或原版一致性通过。

功能阶段应检查 W3G 路径编码、遍历／符号链接／大小／扩展名限制、匹配／失配／无摘要的地图、玩家与槽位顺序、旁观者／电脑／关闭槽、种子和取消／重试、地图切换以及 `main` 初始化；还需要真实 1.27 样本、动作和原版状态对照。Win32 Release 产品增量编译通过，尚未运行或验收。
