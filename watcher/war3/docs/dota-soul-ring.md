# 刀阵物品与灵魂之戒

`AEfk` 原型的主动能力物品通过通用物品施法执行，沿用技能事件、魔法消耗、冷却和刀阵范围效果；地图脚本接收相同技能事件并处理自定义物品效果，参数由地图能力及脚本决定。

Win32 Release 客户端增量编译通过。DotA_v6.83d 原图隔离会话直接创建英雄和灵魂之戒 `I0LL`：使用前生命 518、魔法 0，一秒后生命约 364、魔法约 151，冷却期间再次使用被拒绝；13 秒时魔法约 13，记录 `tmp/docs-artifacts/war3/dota-soul-ring/after-checked.log`。自然恢复及其他地图逻辑也在该会话中运行，数值不作为原版精度结论。

阶段核对购买／合成和真实操作、生命不足、满魔及临时魔法消耗与到期、死亡／移除／物品替换、技能事件和冷却、多物品／地图覆盖、实际刀阵物品目标及伤害、窗口、原版和联机。
