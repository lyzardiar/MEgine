# 地图脚本模型镜头

地图脚本可通过 `SetCinematicCamera` 指定从地图或公共 MPQ 加载的 MDX/MDL 镜头模型。当前会话记录设置时的场景相机目标、朝向和模拟时间；模型由后台资源流式读取，使用第一段序列、第一台镜头的位移、目标、翻滚及视锥生成游戏场景视图，并更新声音监听。`ResetToGameCamera` 清除模型镜头并恢复现有游戏相机；切图时状态随世界释放。资源加载失败或模型没有镜头时保留普通场景相机，不解包模型。
