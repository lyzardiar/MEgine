# 黑暗之门

战役能力 `ANdp` 接入点目标命令、魔法／冷却与真实召唤事件。技能从源能力的单位列表读取可生成类型，在最小与最大数量之间取值，按单位移动类型和碰撞半径寻找合法位置，创建施法者所属的实际单位。门的源 `EffectArt` 在目标位置播放；电脑战斗施法可选择目标位置。地图覆盖能力和单位数据沿用现有归档优先级。

原版 1.27 的 `Units/AbilityData.slk` 指定一级候选 `nbal,nfel`、数量 3–5、施法距离 800、冷却 100 秒；`UI/WorldEditStrings.txt` 将对应字段标记为产出单位、最小单位数及最大单位数。参数按实际技能等级读取。

当前在施法释放时创建所有单位，使用现有会话随机流和合法落点；生成间隔、候选权重、随机流顺序、召唤单位寿命以及原版事件顺序尚未对照。门动画／声音、地图覆盖、水陆／飞行混合、无空间和召唤回调重入、电脑战术、联机及真实战役画面待阶段验证。共享候选落点复用按移动类型与碰撞半径区分，机械小动物的不同运动类型也需回归。
