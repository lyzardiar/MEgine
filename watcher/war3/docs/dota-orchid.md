# DotA 紫怨与被动法术书

DotA_v6.83d 的紫怨 `I012` 包含主动 `ANso`、装备属性和仅含被动技能的法术书 `A0TE`。当物品同时存在其他主动能力时，被动法术书继续借出能力与更新装备，但不占据该物品的主动使用入口；可独立打开的法术书及含主动子技能的书籍继续沿现有入口处理。`ANso` 物品使用进入单位目标、支付、冷却、弹道和灵魂燃烧状态流程。

Win32 Release 客户端编译通过。原图隔离会话直接创建紫怨和敌方目标：第 1 秒目标沉默、第 7 秒不再沉默，装备提供 30 攻击与 0.3 攻速；移除物品后这两项及书籍借用能力均消失，记录 `tmp/docs-artifacts/war3/dota-orchid/after-stats.log`。原版 `sbok` 单独使用可打开书籍，记录 `tmp/docs-artifacts/war3/dota-orchid/book.log`。探针未经过购买、真实输入或完整对局。

阶段核对随机／嵌套书籍、含主动子能力的复合物品、多来源与替换、目标和状态叠加／驱散、费用／冷却／事件、原版及真实窗口和联机。原力法杖隔离场景的目标位移受地图区域限制，记录 `tmp/docs-artifacts/war3/dota-force-staff/before.log`；其他位置及实际交互仍待验证。
