# 昼夜模型光照

地图脚本 `SetDayNightModels` 指定的地形和单位 DNC 模型经地图优先的归档解析及后台模型流式加载。MDX 解析器支持只包含光源的模型；以游戏昼夜时钟相对于一天长度的比例采样 DNC 的 Stand 序列，读取方向光颜色、方向、强度、环境色及其动画轨道。光照模型缺失、解析失败、缺少方向光或采样值无效时，场景沿用现有绘制，相关加载失败写入场景日志，不写出解包文件。

场景模型的可着色层按骨骼与世界法线计算 DNC 环境光和方向光，并叠加已有模型内光源；Unshaded 层不受其影响。地形和荒芜层在迷雾纹理之后调制 DNC 光照颜色，不重建静态地形缓冲；地形目前按水平法线计算，水面、粒子、HUD 和天空不消费该光照。场景结束后清除渲染器光照，避免影响界面与其他模型。脚本换 DNC 后的模型异步载入，载入前使用无 DNC 的既有绘制。模型缺少方向光、采样无效或计算异常时记录一次路径错误并回退。

本机 1.27 原安装 war3.mpq 列表中找到的 13 个 DNC 模型均包含一个方向光；BootyBay 和 Amazonia 脚本均指定 `Environment\\DNC\\DNCLordaeron` 的地形和单位模型。该清单不保证包含归档中未列出的模型。当前只读取第一个方向光；自定义多光源、点光／环境型 DNC、地形坡面法线、水面及其与模型自身光源的准确组合尚未实现。精确光照方程、昼夜轨道时间映射、光源方向、颜色空间、设置切换与视觉一致性需要原版对照。

性能边界：场景对象沿用已有视锥裁剪；无几何或全为 Unshaded 层的模型不额外计算世界法线和光照，其他可见模型仍需 CPU 骨骼法线与逐顶点照明，密集地图的帧耗时和内存须实测。必要开发检查：初版 Win32 MSVC `/Zs` 检查模型、地形及 GameView 翻译单元通过；最后一次修改待产品编译确认；需在完整产品构建后集中验证原图昼夜、脚本动态切换、无效与缺失资源、阴影与战争迷雾、设备重置、密集场景逐顶点光照 CPU 开销和帧耗时，以及切图释放。
