# 单位动画混合

脚本 `SetUnitBlendTime` 设置单位的过渡时长。可见单位切换模型序列时，渲染实例保存上一姿态，按时长混合骨骼的平移、四元数旋转和缩放；附着特效读取同一实例及 LookAt 朝向。设置为零时即时切换。模型资产共享，混合状态属于单位实例，不参与模拟状态。

单位默认使用 MDX MODL 的混合时间，脚本可覆盖为正值或零；显式动画及动画队列的重启使用实例代数识别，同序列普通循环不触发混合。混合时钟跟随单位动画倍率并在暂停或零倍率时冻结。非活动混合复用共享局部姿态及蒙皮缓存，活动过渡保持实例隔离。攻击、施法等其他业务重启、首次出现和离屏重入的历史姿态，以及混合时钟的原版语义仍待实现或对照。单位变形、附件、模型替换、多单位共享、动画重入与实际 GPU 画面留阶段验证；该实现不代表完整战役或原版表现验收。
