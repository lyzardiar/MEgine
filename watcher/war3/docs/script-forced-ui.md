# 地图脚本强制界面按键

`ForceUIKey` 读取字符串首字节，将小写 ASCII 转为大写，仅接受字母及数字；空值和其他字符无操作。`ForceUICancel` 请求当前命令取消。两者写入会话有界队列，游戏视图按顺序每帧最多消费一个，通过现有命令栏、目标模式、建筑取消和单机／实验联机的玩家命令入口执行；无人控制、菜单、聊天及对话期间消费的请求不会改变命令界面。切图时队列随会话释放。脚本事件在 UI 消费期间再次产生的请求保留给后续帧，避免在渲染中递归重入；实验回放消费但不再次产生玩家命令。

REA 对 Warcraft III 1.27 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）的静态检查：`ForceUIKey` 入口 `0x6f1e0f00` 仅取首字节，转为大写并限定 A–Z／0–9；`ForceUICancel` 入口 `0x6f1e0e80` 发送特殊键值 512。两个入口通过界面虚函数同步派发；当前队列在后续帧消费，不保证脚本内立即生效。界面焦点、暂停／过场、错误参数、队列满、重入、双端和原版时序均待阶段对照。
