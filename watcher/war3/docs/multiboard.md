# 多列计分板

脚本 multiboard 和 multiboarditem 句柄连接会话状态，支持创建／销毁、显示／最小化／全局抑制、标题及颜色、行列变更、单元格句柄／释放、批量和单项文本／颜色／宽度／图标／样式。调整尺寸保留交集单元格，移除区域的句柄停止生效；销毁清理关联句柄。

游戏 HUD 使用原版 UI/FrameDef/UI/Multiboard.fdf、皮肤和默认图标，按状态绘制列宽、文本颜色和图标，文本支持 Warcraft 颜色标记；地图或公共归档中的图标按需读取并后台交付。标题栏按钮连接本地最小化，计分板区域拦截场景指针输入。

原 FDF 没有动态行或屏幕锚点定义，当前行间距、宽度分配和位置是近似实现；超过可显示高度的行暂被裁切，多计分板可视排列及图标边框仍待完善。多人各客户端独立显示／最小化、缩行后的句柄语义、Clear 和全局样式更新语义需原版对照；单板支持至 256 行列、8192 格。

Win32 Release 产品编译通过。独立定向探针验证 Prologue02 脚本环境的创建、行列、单元格状态、调整尺寸后的句柄、释放、销毁及原 FDF／默认图标隐藏窗口绘制，未加载 Game.dll。该探针没有覆盖真实 GameView 输入或 DotA 界面；原始文件在 tmp/docs-artifacts/war3/multiboard-probe/。
