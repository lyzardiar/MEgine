# 局域网当前研究与训练取消

经典动作编码将当前研究的取消发送为 `0x10`、订单 `851976`；消费端结合当前选区中的唯一单位，在时间片执行时选择取消该单位的施工、建筑升级或当前非英雄复活生产任务。取消生产沿用会话的退款、人口和研究／训练取消事件。多个单位选中时，当前研究的发送端要求唯一类型子组，发送子组记录并设置 `0x40` 标记，接收端按子组目标消费该订单；多选下的其他队列取消目前明确拒绝。英雄复活继续使用独立的 `0x1d`，普通非当前队列单位继续使用带槽位和类型的 `0x1e`。

证据来源为 blue、nagger 的 [w3g_actions.txt v1.00](https://github.com/nielsAD/gowarcraft3/blob/f13251b6caed199c3347214f4591e7ccaa96c7c7/file/w3g/w3g_actions.txt)；原文将 `0x10` 订单 `08 00 0D 00` 标记为 train、research 取消，同时将 `0x1e` 限定为单位队列、`0x1d` 用于英雄复活。该公开资料描述回放动作，并非本机 1.27 多人抓包；不能据此宣称原版客户端互通。`0x10` 不携带任务身份，前一个任务在到达前完成时可能作用于后续当前任务，实际原版时序仍待对照。发送端仅允许用此方式取消当前槽位的研究，未实现任意排队研究的原版编码。

定向用例 `tests/order_queue_tests.cpp` 登记了经典编码、时间片消费、资源退款、后续任务保留、训练取消、唯一子组、重复类型拒绝及多选队列取消拒绝；尚待集中执行。真实双客户端、多人时序、重入、子组选择、原版报文及退款事件待阶段验证。实验对局继续使用已有带任务票据的私有动作，不改变原版大厅启动边界。
