# 装备属性与永久物品

13类装备原型及7类永久物品已连接实际英雄、战斗、恢复、视野和物品使用。当前为实现接入、必要产品编译通过；新增玩法、原版精度及UI仍待阶段运行验证。

| 原型 | 实际消费 |
| --- | --- |
| AIab三围 | 力量/敏捷/智力、主属性攻击、派生生命/魔法/攻速/护甲/恢复及GetHeroStr/Agi/Int；装备贡献与脚本奖金分开，丢弃不撤销永久成长 |
| AIat/AIde/AIas | 源攻击、护甲及攻速；实际武器载荷、受击结算和攻击间隔 |
| AIml/AImm | 源最大生命/魔法；装备变化合并直接容量及三围派生变化，调整当前资源比例，死亡状态保持死亡 |
| AIms | 移动速度、MoveSpeedBonusesStack开关及最强正/负奖励；实际移动、寻路接近与返回 |
| Arel/AIrm | 固定生命恢复及普通魔法恢复倍率；与单位/英雄/科技、昼夜/荒芜和光环的现有恢复流程组合 |
| AIsr/AIva | 源伤害奖励/法术减伤及攻击吸血；实际命中伤害/生命回流，吸血仍检查真实单位/敌人/建筑/机械/幻象 |
| Amim/Ault | 持有魔免及夜间视野，供魔法目标、伤害、查询与实际迷雾网格消费 |
| AIam/AIim/AIsm/AIxm | 永久敏捷/智力/力量/全属性；英雄基础属性及相应生命/魔法等派生状态 |
| AImi/AIem/AIlm | 永久生命、经验及等级；真实成长/技能点/升级事件、次数/冷却/物品事件及消耗品释放 |

装备定义按能力/等级缓存，物品清单按类型缓存。每件物品独立贡献，保留同类副本的属性叠加；移动遵循源叠加开关，减伤/吸血当前取同类最强值。单位直接获得的同原型能力也有实际消费者。

拾取、交换、丢弃、销毁、能力增删/等级/英雄学习、科技、归属和形态变化更新装备贡献。数值在拾取/丢弃事件之前更新；没有新增全场逐帧物品扫描。原AInv的使用权限控制携带被动与主动使用，死亡掉落字段进入真实死亡物品流程。完整取得/丢弃权限和其他库存规则继续实现或验证。

幻象保留来源库存贡献快照，按IllusionsGetAttackBonus/AttackSpeedBonus/MoveSpeedBonus/DefenseBonus开关消费；不复制真实物品句柄，也不重复添加已复制的容量或三围。正常英雄的永久属性、脚本奖金、装备属性及已应用派生数值分开记录。

一个主动能力与已支持被动能力组成的物品已接入使用流程：主动目标/费用/共享冷却取实际主动能力，装备被动继续生效。原gvsm的AIcm控制魔法和AIi6智力奖励可共用此流程；同一物品带有其他主动技能时，全部候选均为被动效果的法术书只作为能力来源，不占据物品的主动使用入口；未知能力及尚未实现的多个主动能力组合仍明确失败。原物品图标/槽位与命令区、英雄实际属性和资源显示复用更新后的状态，完整源布局/工具提示/奖励颜色仍待阶段还原。
