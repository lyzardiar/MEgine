# 多列计分板本地折叠

自研局域网和回放允许各玩家点击原计分板折叠按钮。各客户端的折叠状态保存在 GameView 中，只影响当前界面的布局、点击命中和显示，不修改网络锁步会话；计分板脚本再次调用 MultiboardMinimize 时清除旧的本地状态，界面恢复脚本指定值。计分板销毁后清理本地状态，聊天、任务、联盟、消息记录、菜单及脚本对话框打开时屏蔽按钮输入。单机沿用既有会话内折叠行为。

局域网／回放的 IsMultiboardMinimized 继续返回脚本状态，当前不反映用户本地点击；此设计保持本地输入不改变模拟，原版 getter 与局部状态的精确语义待对照。

待集中验证：两客户端分别折叠／展开、多板与脚本反复设置相同值、显示／隐藏／销毁、命中区域变化、原版按钮贴图、输入焦点与所有弹窗、断线／返回、回放观看操作对模拟与下一局的影响；核对原版各客户端及 IsMultiboardMinimized 行为。尚未编译或运行。
