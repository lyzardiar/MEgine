# 玩家广播文本

`DisplayTimedTextFromPlayer` 使用给定玩家的名称替换消息中首个 `%s`，`%%` 显示一个百分号，并将消息交给全部本地视角；`DisplayTimedTextToPlayer` 仍只发给指定玩家。胜利、失败和离开提示沿用原 `Blizzard.j` 调用路径。空名称使用本地化玩家称呼与序号。其他 printf 格式修饰、重复占位符、原版最大长度和特殊输入暂未完整还原。

固定版 `Game.dll` SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`；注册入口 `0x6f1dfd90` 在 `0x6f1dfde1` 读取玩家名称、`0x6f1dfdf4` 将其作为格式化参数，在 `0x6f1dfe46` 直接提交文本；区别于单玩家文本路径，这里没有本地玩家检查。`0x6f24a890` 的空名称处理会使用本地化 PLAYER 和玩家序号。原始只读反汇编应保存在 `tmp/docs-artifacts/war3/`，不分发原版文件。
