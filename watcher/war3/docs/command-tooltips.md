# 游戏命令工具提示

命令按钮悬停采用原版 `UI/war3skins.txt` 的 `ToolTipBackground`、`ToolTipBorder` 和金币、木材、魔法图标，沿用客户端从原资源加载的主字体，以及 FDF 文本渲染对颜色代码和换行的处理。标题保留源名称与快捷键；实际费用和冷却来自命令状态；高级工具提示开启时显示源扩展描述，禁用时同时显示不可执行原因。高级工具提示关闭时保留基本名称、费用、冷却及禁用原因。

提示根据内容换行并在可用屏幕空间内调整高度；超过可见区域时通过 Page Up／Page Down 分页，切换悬停对象重置位置。描述保留原颜色和段落，不再固定截取 48 字；为防止异常脚本文本耗尽资源，最多处理 65536 个字符及 4096 行。提示资源在当前游戏视图中按需加载并随视图释放，未写入原版安装目录。

原 1.27 的工具提示图层、颜色、精确位置、内边距、价格排列、字体缩放、折行与极长文本行为尚未核对；分页键是当前实现的长内容访问方式。待阶段验证鼠标悬停／离开／控件遮挡、所有种族资源、技能／商店／建造／学习／禁用／费用变化、不同分辨率／DPI、中文和颜色代码、设备恢复及原版 UI 对照。Win32 Release 客户端增量编译通过，尚未运行验收。
