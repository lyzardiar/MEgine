# 毒素攻击与物品法球

弹射武器的后续单位目标按源溅射目标关系筛选；源目标字段没有声明敌友关系时，默认选择敌方单位。地图显式指定阵营时沿用已有目标筛选，攻击者自身仍被排除。DotA_v6.83d 原图中，月之女祭司学习月刃后攻击敌人，距离更近的友军不再被弹射命中，第二个敌人受到衰减伤害。多阵营关系、地面物品和可破坏物、自定义显式目标及原版筛选规则仍待阶段对照。

本功能包将原资源中的毒素、减速毒、六类法球原型和腐蚀喷吐接到独立客户端的实际攻击、库存、状态、科技与生命周期。实现和必要编译已完成；玩法、原版精度及完整表现尚待功能阶段验证。

| 范围 | 实际消费 |
| --- | --- |
| Apoi／Apo2／Aven／Aspo及派生 | 攻击发射快照、命中后毒剂、秒伤、独立时限、移动与攻速削弱、源叠加位及可否致死位 |
| 火焰／冰霜／腐蚀法球 | 实际装备伤害、附近敌人附伤、源冰冻减速、负护甲和时限 |
| 毒液法球 | AIpb装备伤害与原物品配套Apo2毒伤 |
| 闪电／缓慢／黑暗法球 | 源普通／英雄／召唤物概率、净化／缓慢命中、致死前黑箭标记与真实死亡召唤 |
| Acor腐蚀喷吐 | Recb前置、启用原第一攻城武器、建筑目标、原酸液模型及独立持续伤害 |
| 库存与生命周期 | 获取／掉落／移除／能力等级／研究／归属／变形刷新；SetPlayerAbilityAvailable刷新装备、启用武器与原附件；切图随会话释放 |

法球装备伤害通过既有库存统计叠加，攻击准备不重复计入。一次攻击选择一个法球，当前按库存格及物品能力顺序，再选择单位直接持有的法球；灼热／霜冻／黑暗等主动攻击增强已经占用该次攻击时不另选物品法球。第二武器使用原单位的目标、射程、伤害、攻速及原法球模型。已有非零武器速度保留，法球显式速度可覆盖；当二者都缺省且武器为弹道类型时，暂用每秒1500单位，复用飞行、追踪、命中与清理流程。该数值参考原毒刺能力 Apoi 的 Missilespeed，尚未证明是原版法球缺省值；飞行时序及目标失效行为仍待对照。

毒剂保留每次命中的来源、原玩家、能力、伤害／减速、叠加位、时限和秒脉冲余量。伤害叠加位开启时各剂独立计伤，否则取最强剂并使用共享秒时钟；移动／攻速分别合计可叠加剂和最强不可叠加剂。未开启致死位时，实际伤害回调前后均限制受害者至少保留1生命。暂停停止时钟；死亡与状态移除清理剂量；来源被移除或易主后，周期伤害保留原玩家归属。每状态剂量预算为1,024。

当前毒素按物理、不可驱散且拒绝魔免目标的状态处理。原版叠加身份、逐次／逐来源／覆盖规则、驱散与免疫分类、脉冲精度、来源消失后的击杀收益以及灵魂链接与非致死伤害的组合仍待核对。法球择取优先级、多法球／箭矢组合、首次命中减甲、火焰范围分类及触发时机同样保持待验证。

腐蚀喷吐的 Cor1／DataA 是每秒伤害：原始值为 50，持续时间为 5 秒，目标是建筑。第一武器命中后按技能和来源保存独立时钟；相同来源命中刷新持续时间并保留下一次伤害的时间，不同来源各自计时。暂停单位停止时钟，目标死亡或移除时清除；来源被移除或易主后保留原攻击玩家归属。该状态不占用地图 BuffID。伤害类型、免疫／护甲交互、刷新和多来源叠加、事件次序、非整秒持续时间及完整画面均待原版对照。

源依据为本机Warcraft III 1.27.0.52240的AbilityData／AbilityMetaData、UnitWeapons／UnitMetaData、各族与物品能力配置、ItemData及UI/UnitEditorData叠加位。Game.dll SHA-256为e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a。REA只做定向静态读取，GetMissileSpeed入口为0x6f3f8980；这不证明原客户端完整弹道或玩法语义。源成员归档／摘要、提取脚本、原生入口与REA证据位于tmp/docs-artifacts/war3/weapon-effects/。运行产品不加载原版Game.dll，也不解包地图。
