# 鼠标预选

地图脚本可用 `EnablePreSelect(state, ui)` 控制当前会话的鼠标预选与预选圈显示。默认启用；切图时由会话状态释放。鼠标位于游戏场景且没有打开菜单、对话、聊天或目标命令时，客户端根据当前画面中可见、可选择的存活单位计算悬停目标，并以半透明选取圈显示；该反馈不会更改选区或触发选中事件。

命中计算复用单位、地面物品和场景对象绘制遍历，仅投影视口内对象。鼠标移动后重新采样，其余情况下最多间隔 50 毫秒采样以追踪镜头和对象变化；预选圈复用下一帧绘制。可见且位于当前视野内的地面物品和存活可破坏物使用半透明黄色选取圈，已选中的物品保留正常选取圈；模型尚未加载时不参与预选。可破坏物的圈大小依据其半径估算，原版表现待对照。

`common.j` 声明了该接口；目前的两个参数含义、鼠标命中方式、颜色／透明度和刷新时序为待原版对照的实现。阶段验证应覆盖输入／显示开关组合、单击／框选／技能目标、悬停对象被隐藏／移除／移动／拾取／破坏、迷雾变化、同时选中和悬停不同对象、镜头移动、暂停和菜单切换，以及大地图帧耗时与原版表现。
