# 物品栏移动与转交

玩家可拖动已持有物品到另一个栏位、友方单位或地面；轻点仍使用物品，右键按现有入口放在持有者附近。放置和转交使用真实单位移动订单：单位接近目标后再执行，转交复用原有掉落／拾取事件和装备刷新。栏位交换在模拟步进中完成；物品不可丢弃、不可控制、目标失效或目标背包无空位时不执行。拖拽取消、失效和遮挡会抑制场景输入穿透。

`UnitDropItemPoint`、`UnitDropItemTarget` 和 `UnitDropItemSlot` 已接到同一订单消费，`getitem` 订单可走既有真实拾取路径。脚本移除物品与玩家发出的放置命令保留各自入口；放置位置在掉落事件前写入，避免事件回调转移后被覆盖。

Game.dll 1.27 的原 native 注册与订单编号只读反汇编见 `tmp/docs-artifacts/war3/item-orders-1030/`；本实现的接近距离、可转交对象、栏位交换与事件精确时序仍待原版对照。目标单位满包、路径不可达、共享控制／丢弃权限、英雄头像拖放和各类回调重入留待集中验证。联机 `getitem`、地面放置、单位转交及换格已接入网络动作，换格报文为暂定映射，原版报文和完整多人拖放仍待验证。放置指令在取消旧订单并复核回调后才建立路径；不可达路径会结束订单，掉落回调移动物品时保留脚本位置。

物品栏悬停显示实际物品名称及源 `Ubertip`，地图自定义字符串与数据引用沿用现有解析；增强提示关闭时只显示名称。长说明使用 PgUp／PgDn 翻页，拖动、空格或界面遮挡时不显示提示。不同种族、长文本、原版布局及实际窗口待阶段验证。
