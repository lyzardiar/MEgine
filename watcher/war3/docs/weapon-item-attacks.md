# 武器攻击地面物品

游戏界面攻击模式可以选取可见的地面物品，地图脚本可使用目标攻击订单。单位仅使用目标类型包含 item 的已启用武器，按实际距离移动、播放攻击、经过源前摇／冷却、掷伤害骰子并发射弹道。命中消费物品生命及原有物件死亡事件，死亡后沿既有移除流程清理。Shift 排队与实验联机使用现有目标订单、物品身份和时间片消费者。

源 1.27 数据中人族步兵、兽族步兵、食尸鬼、弓箭手的对应武器目标包含 item；代表物品 phea、rhe1、ratf 的源 HP 为 75。物品进入背包、隐藏、无敌、死亡或移除后不再作为武器目标；命中时重新检查物品及其生命轮次，死亡回调改变物品或攻击者状态后复用现有清理与重入保护。范围、直线及弹跳武器也可按自身范围目标类型命中地面物品；范围／直线仅在范围目标包含 item 时遍历额外物品。

当前物品攻击目标半径采用 16，弹道高度采用 32，原版精度、护甲／伤害分类、攻击被动／法球、拾取后再次掉落期间旧弹道的行为与画面均待对照。实际窗口／物品点击、近战／远程、背包拾取、死亡事件重入、排队和实验联机双端尚未验证。原数据查询脚本为仓库根目录 tmp/docs-artifacts/war3/inspect-weapon-items.py。
