# 世界昼夜时钟快照

`GameClock::encodeState` 把世界昼夜时钟的当前时刻、速度、暂停状态、临时时间效果及其剩余时长编码为版本化 `WCLK` 字节流；`restoreState` 验证格式、规则和数值后一次性恢复，不触发时钟变化事件。`World::clock()` 已供 JASS 时间原生函数和模拟步进直接消费；恢复后这些消费者使用恢复后的时钟。

字节流同时保存来源 `DayLength`、`DayHours`、`Dawn`、`Dusk` 的原始值，只有目标时钟规则逐位一致才可恢复。该检查不能替代完整地图、脚本和资源版本身份校验。非有限或越界时间、负剩余时间、无临时效果却有非零备份时刻、无效布尔值、截断和多余字节均被拒绝，拒绝时不改变目标时钟。

此接口只负责世界时钟内存编码／恢复，尚未接入存档文件或战役切换。计时器、触发事件、模拟时间、单位和对象状态、线程及音频未包含；调用方必须在会话所属线程的安全边界，将这些状态和时钟作为同一时刻的整体恢复，不能孤立恢复正在运行的会话。原版存档格式兼容与完整会话恢复均未实现。

待集中验证：正常／暂停／不同倍速、昼夜边界、临时效果结束前后继续推进、规则不匹配与损坏数据的事务性拒绝、时钟事件重建和实际战役还原。
