# 永久攻击伤害物品

`AIaa` 读取源 `DataA1`，在实际物品使用或自动拾取后为单位累计永久攻击伤害，允许正负数及非英雄；物品的次数、消耗、冷却和拾取／使用事件沿用实际库存流程。该值进入单位武器与攻击面板，保留于单位变形，幻象创建时复制；独立 gamecache 保存和恢复该值。

DotA 自定义对象包含英雄 +10／20／30／40 和负值，以及普通单位 +4／8／12／16 和负值的 powerup。脚本是否在特定对局使用这些对象、原版幻象继承、负伤害边界、实际战斗、界面和事件顺序尚待阶段验证；本项不代表完整物品玩法已完成。

Win32 Release 客户端已编译；独立 gamecache 正负值和旧版本读取的隔离检查通过，实际物品使用待验证。
