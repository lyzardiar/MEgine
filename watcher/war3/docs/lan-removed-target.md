# 已移除目标的联机命令

同构建实验联机和自研回放的 `0x12` 目标订单在时间片消费时解析目标。如果目标的自研身份已明确登记为移除，且目标类别与订单允许的单位、物品或可破坏物类型一致，则跳过该订单，继续消费时间片中的后续动作。它覆盖移动／攻击等目标命令、单位目标技能及复活目标；毁树技能允许被移除的可破坏物。保留现有选区和其他命令；不退化成地面坐标命令，也不回滚已发生的其他操作。此情形可能出现在一名玩家已提交针对单位或地面物品的操作、另一项动作在该命令的时间片消费前删除了目标。

只有显式启用同构建实验协议时使用这一处理；普通经典动作仍拒绝无法解析的对象。未知编号、已移除但类型与订单不符的身份、非法坐标和不支持的订单仍拒绝。自研对象身份保留已移除条目，严格核对种类和序号；本机制不实现原版对象代际、原版目标消失后的回退规则或与原版客户端互通。

`tests/order_queue_tests.cpp` 增加待执行断言，覆盖已移除单位后仍消费后续停止指令、经典模式拒绝、未知编号和类型不匹配；还需集中验证已移除的物品和可破坏物、单位／物品技能与复活目标、同一时间片中的目标移除／选择变化、双方及回放一致性。原版 1.27 的目标失效时序和实际命令行为尚待运行对照。
