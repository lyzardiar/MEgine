# 单位地面阴影

从 UnitUI 的 `unitShadow`、`shadowW`／`shadowH`、`shadowX`／`shadowY` 和 `shadowOnWater` 读取纹理、尺寸、偏移及水面标记，沿用地图对象覆盖和继承。普通单位 `Shadow` 和飞行单位 `ShadowFlyer` 从 `ReplaceableTextures\\Shadows` 直接读入内存并流式上传。原版 1.27 的两张纹理均为 64×64 黑色 BLP，使用各自的透明度；不生成本地解包文件。

阴影按当前单位类型和变形外观绘制，跟随位置及脚本缩放；隐藏、死亡、移除和本地玩家不可见时停止绘制。纹理按地图生命周期共享；贴片采样地形或水面高度、参与视锥裁剪和现有迷雾绘制。贴片尺寸、偏移方向、缩放和水面边界为当前实现，需阶段性与原版对照。

建筑 `buildingShadow` 是独立掩码数据，与普通单位纹理不同，其渲染和缩放尚未接入。待合并验证：实际地图中的陆地、坡面、浅水、飞行单位及建筑，动态创建／死亡／隐藏／变形、迷雾和切图资源释放；核对原版画面、偏移、透明度及大规模场景性能。
