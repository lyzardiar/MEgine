# 单位地面阴影

从 UnitUI 的 `unitShadow`、`shadowW`／`shadowH`、`shadowX`／`shadowY` 和 `shadowOnWater` 读取纹理、尺寸、偏移及水面标记，沿用地图对象覆盖和继承。普通单位 `Shadow` 和飞行单位 `ShadowFlyer` 从 `ReplaceableTextures\\Shadows` 直接读入内存并流式上传。原版 1.27 的两张纹理均为 64×64 黑色 BLP，使用各自的透明度；不生成本地解包文件。

阴影按当前单位类型和变形外观绘制，跟随位置及脚本缩放；隐藏、死亡、移除和本地玩家不可见时停止绘制。纹理按地图生命周期共享；贴片采样地形或水面高度、参与视锥裁剪和现有迷雾绘制。贴片尺寸、偏移方向、缩放和水面边界为当前实现，需阶段性与原版对照。

建筑 `buildingShadow` 使用独立 BLP 掩码，读取地图覆盖与公共归档并复用场景图像缓存。按地图地形原点将掩码投影到每格 32 世界单位的网格，非透明像素组成半透明黑色地面阴影；相互覆盖的建筑取较大透明度，避免重复叠暗。位置跟随实际单位，建造、移除、死亡、隐藏、变形及古树拔根按当前单位状态更新；网格贴合地形，受本地可见性、迷雾和视锥裁剪，切图时随场景释放。网格尺寸、偏移及二值掩码参考 [Warsmash 地形实现](https://github.com/Retera/WarsmashModEngine/blob/master/core/src/com/etheller/warsmash/viewer5/handlers/w3x/environment/Terrain.java)，不代表已验证原版精度。

建筑掩码组合按当前可见单位的身份、外观类型、网格位置和透明度缓存；创建、移除、隐藏、死亡、变形、拔根、移动、资源就绪及可见性变化都会更新组合。绘制时按 16×16 网格块重新计算视锥裁剪，动态迷雾和变形仍逐帧采样；同一块的相邻网格复用公共角点。缓存上限为 65,536 个非空块，超出时明确报错。

地图 `war3map.shd` 只从当前地图归档读取至内存；尺寸必须为 `(地形宽−1) × (地形高−1) × 16` 字节，每字节对应从地形原点开始的 32 世界单位网格，缺失时为空。每个字节按一半强度加入静态网格，与动态建筑阴影取较大透明度以避免重叠区域重复叠暗。遮罩按 16×16 分块缓存，建筑变化时仅重建旧位置与新位置涉及的块；每个受影响块先恢复静态遮罩，再合成所有与该块重叠的建筑，其余块保持不变。探索过但不可见的区域仅显示静态阴影，未探索区域不显示。切图释放地图数据和缓存，不生成解包文件。格序与半强度参考 [Warsmash 地形实现](https://github.com/Retera/WarsmashModEngine/blob/master/core/src/com/etheller/warsmash/viewer5/handlers/w3x/environment/Terrain.java)，原版绘制和迷雾语义仍需对照。

本机 BootyBay 与 Amazonia 的 SHD 长度分别为 294,912、147,456 字节，与其 W3E 对应网格相符，数据均为 0 或 255。当前建筑阴影不随脚本模型缩放，建筑贴图非零 alpha 使用统一强度。待合并验证：实际地图中的陆地、坡面、浅水、飞行单位及建筑，动态创建／死亡／隐藏／变形／拔根、静态与建筑重叠、灰度／缺失／错误尺寸数据、迷雾和切图资源释放；核对原版画面、偏移、透明度及大规模场景性能。
