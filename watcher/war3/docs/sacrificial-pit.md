# 牺牲深渊与阴影

源能力 Alam 和 Asac 已连接侍僧与牺牲深渊的目标命令。侍僧通过现有施法接近目标，深渊目标命令转交侍僧执行；双方必须同属一个玩家、拥有相应能力且深渊可用。侍僧到达后消耗实际单位，深渊启动真实生产队列，使用原阴影 ushd 的生产时间与人口；完成后通过已有单位创建、集结点和生产事件生成阴影。原阴影自身的隐形与侦测沿用单位能力消费者。资源直接读取原版安装。

源 AbilityData 中 Alam 目标为同玩家建筑，Asac 目标为同玩家地面有机非英雄，Asac 范围为 75；原 usap 持有 Asac，ushd 生产时间为 15 秒。当前转化使用 ushd 固定类型，侍僧在转化开始时移除；取消生产不会恢复侍僧，深渊发起命令转交给侍僧，事件次序与原版机制尚未对照。多名侍僧竞争、死亡／移除／转让／禁用、人口不足、取消、脚本重入、实验联机、画面与原版完整流程均待阶段验证。

Win32 Release 客户端编译通过；功能验证由统一批次安排。原数据查询脚本位于仓库根目录 tmp/docs-artifacts/war3/inspect-sacrifice.py，不随产品运行。
