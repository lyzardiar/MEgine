# 施法单位状态技能与自动施放

医疗、减速、心灵之火、嗜血、回春、邪恶狂热、诅咒、驱散魔法、驱逐魔法和反魔法外壳已连接实际施法、状态与命中链。反魔法外壳同时消费Aams完全魔免和Aam2吸收盾两份原版配置。当前共33种主动/持续施法原型，另有14种光环/攻击被动；完整技能、对战与原版一致性仍未完成。

定义来自1.27.0.52240公共MPQ的AbilityData/AbilityMetaData、Profile、效果资料和地图w3a覆盖。物理重击、光环和定时生命不作为普通驱散状态清除；召唤/幻象消费实际单位生命周期，伤害和魔法损失使用源字段。单体能力沿用同一魔法/冷却/前后摇/订单/施法事件链。护甲/伤害奖励与既有光环结合，同一种状态修正取当前较强值后参与计算。

源Requires/Requiresamount进入按钮、手动施法、接近/释放前复核及自动施法判断；例如心灵之火需要Rhpt等级2、嗜血需要Rost等级2，驱散需要Rhpt、回春需要Redc，反魔法外壳需要Ruba。它们复用真实玩家科技计数，尚未研究时不会因已持有能力而直接开放。

## 自动施放与界面

医疗、减速、心灵之火、嗜血、诅咒和驱逐魔法读取原Orderon/Orderoff。字符串/ID订单、单位默认auto列表及按钮右键共用同一状态；左键仍为普通手动施法。命令区显示源Art/Unart与原自动施法说明，并预载两种图标。

UI/war3skins.txt中的CommandButtonAutocast指向UI/Feedback/Autocast/UI-ModalButtonOn.mdl。该源模型没有GEOS，四个PRE2粒子位于原界面按钮坐标；使用已有粒子实现、界面正交投影和每按钮独立实例绘制，未替换成自绘边框。为避免新启动资源阻塞，只执行此新增模型的必要CPU导入，4个源发射器成功消费，无Game.dll/GPU；真实界面尺寸、混合、深度、缩放及粒子画面继续待验收。

自动施法每四个1/32秒步进查询一次，使用512世界单位空间格。医疗优先处理至少缺少一次治疗量的友军，驱逐优先有效状态/召唤；心灵之火考虑可攻击友军，嗜血考虑交战友军，减速/诅咒考虑交战目标并消费Always Auto字段。不会离开射程追逐或打断移动、采集、施工、修理、其他施法及攻击前摇。候选排序使用用途、治疗需求、距离、句柄和能力，避免无效随机消耗。

自动施法保存原攻击/地面攻击/保持状态，在自然完成后恢复；完成和结束回调后复核单位、所有权、施法/战斗修订及当前订单，回调中的新命令优先。主动取消不强行恢复旧命令。自动施法优先级、阈值、交战定义、刷新频率、打断/目标丢失后的继续行为及完整原版AI仍待对照。
