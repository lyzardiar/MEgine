# 水面与两栖单位路径

单位移动类型读取原 UnitData `movetp` 和地图对象覆盖 `umvt`：`foot` 等陆地类型使用 WPM 的 unwalkable 位 2，`fly` 使用 unflyable 位 4，`float` 使用 unfloatable 位 64，`amph`／`hover` 使用 unamphibious 位 128。陆地、水面与两栖单位共享现有地面动态阻挡，飞行单位使用现有飞行动态阻挡。路径搜索仍采用既有净空、对角约束和有限 A*。

实际单位的移动、追击和重算，以及训练／购买生成、召唤、变形、传送、闪烁、运输卸载及骑乘结果的落点查找均按对应类型选择地图路径位；已有布尔调用保留陆地／飞行语义。原 UnitData 摘录包括 `nbot` 的 `float` 与 `nzep` 的 `fly`，源摘要 SHA-256 `34a0c8083f146b5d3e25d92a19a8822151d4b26dfe9c1c325a6229466d1b04d6`，原始摘要见 `tmp/docs-artifacts/war3/transport/source.json`。路径位名称与数值沿用现有源建筑放置规则。

水陆边界、hover 和 amphibious 精确语义、动态障碍物、地图覆盖、船厂／海军实际生成及战役海岛地图尚待集中验证；船只专属碰撞和完整原版路径行为仍需实现或对照。

风步状态影响动态单位碰撞：有效期间与非建筑单位互相穿行，地图路径和建筑阻挡保留；状态终止后恢复普通碰撞。源能力的淡入、终止和原版行为仍需对照，见[风步、闪烁与镜像](mobility.md)。

目标路径格不可通时，仍先采用原有最近候选及直线路径；若直线被阻挡，一次有界 A* 会同时考察原目标周围最多 8 格的可通候选，按实际路径代价加剩余距离选择可达落点，同分时优先靠近目标，避免仅因首候选隔墙而拒绝其他可达落点。候选和搜索保留固定范围及 131,072 节点预算；无法找到可达候选时返回失败。目标本身可通但被隔墙等障碍隔离时，普通地面移动及攻击移动在原有有界 A* 搜索失败后，从已闭合的起点可达格中选择到目标八方向网格距离最小的格；距离相同依次取较短路径和较小格号。该逻辑与 131,072 节点的既有搜索预算共用，仅在确实接近目标时返回，攻击移动／巡逻以实际落点作为行动目标以避免反复全图重算，发令事件仍使用原点击坐标。目标追击、施法及生产／传送落点查询继续使用严格路径。预算耗尽时的结果只代表已搜索范围，移动及阻挡变化、各移动类型、命令队列和原版目标选择精度待阶段验证。`war3_world_tests` 的 `world_blocked_goal_reachable_alternative` 覆盖隔墙时的可达替代点和候选全部不可达，本次 1 通过、0 失败。

## 水面显示高度

水面采样使用渲染水网格相同的 W3E 水位、湿格标志、`Water.slk` 地形集偏移与三角面插值。水面／两栖单位的模型、选中圈、附着效果、可见性遮挡目标和相机跟踪使用水面与地形较高者；地图点击与相机中心使用可见表面高度。武器与法术弹道保存起点和目标的移动类型，并在反弹、分裂和目标移动时更新，渲染按对应基面取高，发射者消失后不依赖其句柄。陆地和飞行单位仍沿用地面基准，地面特效和 JASS 地形高度不改为水面。

原版船只高度、浅水边缘、hover／amph 高度、射线／透明水面选择、闪电原版高度和源单位变形时序未完成对照；真实水面画面、遮挡、模型／弹道和性能待集中验证。

## 水面单位闪电

技能与攻击产生的跟随单位闪电在绘制时依据端点单位当前移动类型修正水面基准；延迟攻击闪电保留发射和目标的移动类型，单位失效后仍能使用其最后位置的对应基面。直接通过脚本指定的闪电坐标不做水面修正，脚本移动闪电会解除原有单位跟随及基面标记。逻辑坐标和 JASS 接口保持原有语义。

船只／两栖单位跨岸或变形、端点失效、脚本移动、闪电链／抽取／锁镣以及延迟攻击的实际 GPU 画面和原版精度待集中验证。

## 寻路搜索开销

单次有界 A* 在最多 4,194,304 格的地图经过 4,096 次通行检查后缓存本次结果；最多 1,048,576 格时，在发现 2,048 个搜索节点后转为连续节点表，否则保留稀疏节点表。短距离搜索避免分配全图缓存。缓存仅存在于本次同步查询，不跨越动态阻挡或地形更新；直线路径、候选排序、代价、对角约束和 131,072 节点上限保持不变。

对 OrcX03b 当前核心的隔离模拟采样显示主要 CPU 落在追击路径搜索；探针完成 main 并创建 261 个单位，约 620 秒 CPU 后仍未完成预定 120 秒模拟，已主动终止。原始记录和采样位于 `tmp/docs-artifacts/war3/orcx03b-current/`，不能作为优化后真实对局的性能结论。

Win32 Release 产品编译通过，隔墙可达替代点和不可达部分路径定向检查各 1/1 通过。512×512 隔墙夹具每类连续 3 次搜索，半径 0／32、严格／部分路径的结果摘要一致，单类耗时由 148–231 毫秒降至 61–68 毫秒；1028×1028 稀疏回退夹具各 1 次搜索结果摘要一致。512×512 局部绕障各类连续 300 次的结果摘要一致，优化前耗时 8–15 毫秒，优化后 8–16 毫秒。以上为单次本机实验，地图持续对局、帧时间、内存、动态阻挡及原版路径语义仍待阶段验证。

同一世界保存最多 512 条直接映射的失败路径查询；键包含起止格、碰撞半径、移动类型、是否允许部分路径及路径版本，仅在搜索返回空路径时缓存。静态地形路径位和动态障碍更新均改变路径版本，使旧结果失效；成功路径不缓存，路径点仍按当前请求计算。

Win32 Release 编译通过；隔墙缓存失效检查覆盖重复失败、地形开闭、半径和部分路径隔离及动态障碍移除，1/1 通过，已有隔墙和部分路径检查各 1/1 通过。512×512 隔墙对同一严格失败目标连续查询 30 次，半径 0／32 的实验耗时由 636／670 毫秒降至 21／22 毫秒，部分路径结果摘要一致；结果来自单次本机夹具。OrcX03b 的无前章 gamecache 静音探针从 main 推进前 10 秒，未加载 Game.dll；较晚阶段持续追击及实际帧时间仍待验收。实验记录位于 `tmp/docs-artifacts/war3/orcx03b-current/failed-cache-*.log` 和 `optimized-progress.log`。
