# 水面与两栖单位路径

单位移动类型读取原 UnitData `movetp` 和地图对象覆盖 `umvt`：`foot` 等陆地类型使用 WPM 的 unwalkable 位 2，`fly` 使用 unflyable 位 4，`float` 使用 unfloatable 位 64，`amph`／`hover` 使用 unamphibious 位 128。陆地、水面与两栖单位共享现有地面动态阻挡，飞行单位使用现有飞行动态阻挡。路径搜索仍采用既有净空、对角约束和有限 A*。

实际单位的移动、追击和重算，以及训练／购买生成、召唤、变形、传送、闪烁、运输卸载及骑乘结果的落点查找均按对应类型选择地图路径位；已有布尔调用保留陆地／飞行语义。原 UnitData 摘录包括 `nbot` 的 `float` 与 `nzep` 的 `fly`，源摘要 SHA-256 `34a0c8083f146b5d3e25d92a19a8822151d4b26dfe9c1c325a6229466d1b04d6`，原始摘要见 `tmp/docs-artifacts/war3/transport/source.json`。路径位名称与数值沿用现有源建筑放置规则。

水陆边界、hover 和 amphibious 精确语义、动态障碍物、地图覆盖、船厂／海军实际生成及战役海岛地图尚待集中验证；船只专属碰撞和完整原版路径行为仍需实现或对照。

风步状态影响动态单位碰撞：有效期间与非建筑单位互相穿行，地图路径和建筑阻挡保留；状态终止后恢复普通碰撞。源能力的淡入、终止和原版行为仍需对照，见[风步、闪烁与镜像](mobility.md)。

目标路径格不可通时，仍先采用原有最近候选及直线路径；若直线被阻挡，一次有界 A* 会同时考察原目标周围最多 8 格的可通候选，按实际路径代价加剩余距离选择可达落点，同分时优先靠近目标，避免仅因首候选隔墙而拒绝其他可达落点。候选和搜索保留固定范围及 131,072 节点预算；无法找到可达候选时返回失败。目标本身可通但不可达时仍沿用原有失败行为，原版目标选择精度及大规模寻路性能待阶段验证。`war3_world_tests` 的 `world_blocked_goal_reachable_alternative` 覆盖隔墙时的可达替代点和候选全部不可达，本次 1 通过、0 失败。

## 水面显示高度

水面采样使用渲染水网格相同的 W3E 水位、湿格标志、`Water.slk` 地形集偏移与三角面插值。水面／两栖单位的模型、选中圈、附着效果、可见性遮挡目标和相机跟踪使用水面与地形较高者；地图点击与相机中心使用可见表面高度。武器与法术弹道保存起点和目标的移动类型，并在反弹、分裂和目标移动时更新，渲染按对应基面取高，发射者消失后不依赖其句柄。陆地和飞行单位仍沿用地面基准，地面特效和 JASS 地形高度不改为水面。

原版船只高度、浅水边缘、hover／amph 高度、射线／透明水面选择、闪电原版高度和源单位变形时序未完成对照；真实水面画面、遮挡、模型／弹道和性能待集中验证。

## 水面单位闪电

技能与攻击产生的跟随单位闪电在绘制时依据端点单位当前移动类型修正水面基准；延迟攻击闪电保留发射和目标的移动类型，单位失效后仍能使用其最后位置的对应基面。直接通过脚本指定的闪电坐标不做水面修正，脚本移动闪电会解除原有单位跟随及基面标记。逻辑坐标和 JASS 接口保持原有语义。

船只／两栖单位跨岸或变形、端点失效、脚本移动、闪电链／抽取／锁镣以及延迟攻击的实际 GPU 画面和原版精度待集中验证。
