# 整数游戏状态

`SetIntegerGameState`／`GetIntegerGameState` 在每个独立会话保存 `GAME_STATE_DIVINE_INTERVENTION`（0）和 `GAME_STATE_DISCONNECTED`（1）的完整 32 位整数。索引超出 0–1 时写入忽略、读取返回零。两个状态默认零；状态 1 当前只由脚本显式设置，远端玩家离开不会自动等同于本地连接断开。

`TriggerRegisterGameStateEvent` 支持 0、1 的整数状态及 2 的昼夜浮点状态，整数事件与昼夜事件使用独立类型。整数状态赋值改变时按当前比较条件观察 false→true 边界，同值不触发；注册记录当前匹配状态，不立即执行。回调重入改变同一状态时终止旧轮次中尚未派发的事件，事件目标编号经 `GetEventGameState` 返回。无效触发器或状态编号返回空事件。

固定版 Game.dll 的原注册点 `0x6f1ece49`／`0x6f1ece5d` 指向写入入口 `0x6f1f5ac0`、读取入口 `0x6f1e2b30`；二者将 0、1 映射至 `0x6f2676f0` 的两项独立状态，对越界分别忽略／返回零。`0x6f039900` 原写入保存整数值并在值变化时发出属性通知，`0x6f039860` 读取该值；`0x6f1f9650` 支持登记 0／1 整数状态事件及 2 的浮点事件，`0x6f1e22b0` 读取事件上下文中的状态编号。证据为仓库固定 Rizin 0.8.1 对原文件的只读反汇编，Game.dll SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`。

当前零初值、整数与实数阈值的换算、跨越规则、注册时行为和重入派发顺序尚未与原版运行时对照；整数阈值比较当前将整数转换为 float，较大数值可能损失精度。实验联机的本地断线处理及其状态同步尚未接入，不能将正常远端离开当作本地断线。Win32 Release 客户端与 session 消费者已编译；`tests/session_tests.cpp` 增加赋值、边界、事件编号、相同值、重入和销毁检查，尚未执行；还需原版时序／全部比较符／阈值／网络断线及时钟事件隔离验收。
