# 单位目标法术物品

雷霆蜥蜴钻石 `thdm` 的 `AIcl`、神圣法杖 `schl` 的 `AIhl`、萨满图腾 `shtm` 的 `AIps` 分别按源能力原型进入现有连锁闪电、神圣之光和净化施法流程。物品槽命令复用目标筛选、技能事件、冷却、费用、使用次数与既有弹道／状态消费；神圣法杖的被动光环仍通过装备能力处理。

基准为 Warcraft III 1.27 的公共 MPQ 中 ItemData.slk 与 AbilityData.slk；源 AIps 的目标为单位。地图将净化目标改为树木时，物品目标选择和命令尚未支持可破坏物。目标规则、连续弹跳、装备光环、费用／次数／事件与原版时序、实际操作和多人同步均待阶段验证。
