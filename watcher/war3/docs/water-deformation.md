# 脚本水面形变

地图脚本可调用 `SetWaterDeforms(boolean)` 控制当前会话的水面形变；切换地图时随世界状态释放。现有实现暂以关闭为默认，开启后将当前地形形变的高度增量应用于受影响的水面分块顶点；关闭或形变结束后恢复原始水位。水面高度查询使用同一组角点与三角插值，以供现有可见高度和水面透明度消费者使用。分块在形变版本或开关变化时更新，并沿用现有视口裁剪与 GPU 提交。

`common.j` 声明了该布尔接口；此实现对原版默认值、影响对象、形变公式及切换时序尚无行为对照，属于待验证的近似。水色、纹理动画和水面深度着色仍采用既有实现，未增加单位或物体产生的水波、碰撞或其他水面交互。阶段验证应覆盖开关组合、动态和永久形变、形变期间切换、边缘与非平坦水位、隐藏后重现、切图释放、实际 GPU 画面、性能及原版对照。
