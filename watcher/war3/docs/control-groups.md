# 玩家控制组

游戏中 Ctrl+0–9 把当前可控制选区保存到对应控制组，Shift+数字将当前单位追加到组（最多十二个），数字键召回该组；短时间再次按相同数字时将镜头移到有效组成员的中心。按键自动重复不触发重复召回或聚焦；菜单、聊天、任务、联盟、脚本对话及禁用选择时不消费编组按键。

控制组保留单位句柄，删除或失去控制权的单位从组中移除；召回暂时跳过不可选择、隐藏、死亡或不可见单位。单机召回通过既有选择事件路径，联机使用已实现的选区动作和异步回显，不直接改写同步选区。选区相同的再次召回不重复触发选择事件。选组顺序、添加规则、死亡英雄与共享控制恢复、定位时限及网络回显需与原版对照；目前未完成真实窗口与联机验收。
