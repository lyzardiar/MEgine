# 单位动画稀有度

`SetUnitAnimationWithRarity` 接入单位动画状态和 MDX 序列选择，重置原动画队列与时间；选中的序列编号由场景绘制、附件和排队动画步进共同消费。模型读取保存 SEQS 稀有度字段。当前在同等名称匹配中，普通类型优先零稀有度序列，稀有类型优先正稀有度序列；缺少对应类别时回退到首个最佳名称匹配。未找到模型或序列时保留动画名供既有渲染路径处理。

分类、回退及多序列择取是暂定规则；原版随机权重、空句柄和动态模型变化须对照。NightElfX01 战役脚本存在直接调用，Win32 Release 客户端已编译；实际运行、模型显示、排队动画、多人确定性和原版一致性待阶段验证。
