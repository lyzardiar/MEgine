# 法术书与遗忘之书

Aspb法术书和Aret遗忘之书已连接真实库存、能力来源、施法、冷却、英雄技能点和原命令面板。原sbok的根须缠绕／驱散／吼叫可进入既有实际技能消费者；tret退还已学习技能等级并恢复学习入口。必要产品编译通过，玩法与原版一致性仍待功能阶段验证。

| 范围 | 实际消费 |
| --- | --- |
| Aspb定义 | 读取源DataA技能列表、DataB共享冷却、DataC／D随机数量、DataE基本订单；选择结果保存在原物品实例或单位直接持有的书籍状态中，反复打开／库存移动不重新随机 |
| 能力来源 | 单位原有等级与书籍借用等级分别记录；库存／书籍增减、能力可用开关、脚本等级修改、科技、变身和工程替换更新实际能力。丢弃最后一个来源时回收借用能力，并取消只由该来源支持的施法 |
| 子菜单 | 库存点击／小键盘或单位书籍订单打开原命令区；显示原子技能图标／位置／热键与冷却，支持嵌套、取消目标、右键／Esc逐级返回，切换单位／菜单／任务与失效时清理 |
| 实际施法 | 子能力进入普通目标／点／无目标／自动、支付／事件与效果流程；即时强化、相位、攻击增强箭矢和普通施法均接入共享冷却；已有被动／装备／科技消费者读取借用能力 |
| 共享与合并 | 相同基本订单的书籍合并子技能；共享标志开启时，成功施放的冷却传到该组及包含它的父级书籍所持子技能，相关库存书籍也记录冷却；冷却期间可打开书籍查看状态 |
| Aret／tret | 使用原库存／次数／费用／冷却／事件入口；只退还英雄学习列表中自身已学等级，保留原技能点，移除对应自身能力／自动开关／非借用技能冷却与句柄，再刷新被动／装备／工程并显示原特效。书籍借用技能继续由其来源提供 |

每本书最多显示11项技能，为原取消按钮保留一格。列表最多256个候选，活动书籍最多256个、嵌套深度最多16；循环或超预算定义明确失败。随机选择复用当前确定性随机源，原版抽样及调用顺序尚未对照。未知子技能继续显示或报告未实现，不创建空效果。

原资源来自本机Warcraft III 1.27.0.52240的AbilityData／AbilityMetaData、ItemData、ItemAbilityFunc／Strings及原模型。sbok为AEer、Adis、Aroa三选三，共享冷却开启；tret持有Aret，1次、可消耗。REA中CAbilitySpellBook的配置入口0x6f4fa680读取基本订单，不能解析时使用0xD0280（852608）；原CAbilityRetrain订单入口0x6f545320返回0xD01F7（852471）。新增spellbook订单按名称有序注册；未推断注册遗忘之书的字符串别名。Game.dll SHA-256为e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a。源归档／成员摘要、字段、原生表及REA记录在tmp/docs-artifacts/war3/spellbooks/；产品不加载Game.dll，不解包地图。
