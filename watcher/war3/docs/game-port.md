# 游戏端口选项

主菜单“选项 → 游戏性”使用原版 `GamePortLabel` 和 `GamePortEditBox` 输入游戏端口。输入框支持数字、退格、Delete、方向键、Home、End、Tab 和鼠标聚焦；确认时检查 1–65535，取消或 Esc 放弃草稿。无效值留在选项页并提示，修正后可重新确认。

端口保存在独立用户目录 `Settings/network.bin`，默认 6112；加载失败时使用默认值并记录日志，损坏文件不自动覆盖。创建局域网房间时读取该设置，TCP 监听所选端口并在 GAMEINFO 中公布实际端口；端口占用时显示创建失败，不回退到其他端口。局域网发现继续使用既有 UDP 6112。原安装目录只读，设置通过临时文件原子发布。仅用户界面创建的房主使用该设置，程序化测试房主默认仍由系统分配 TCP 端口。

源界面为本机 1.27 `War3Patch.mpq` 的 `UI/FrameDef/Glue/OptionsMenu.fdf`，SHA-256 `9fbd1b7013d0d33b22989cdf89034b7361bdae08dcffb584a062cefd9d27fe85`；`GamePortEditBox` 字符串在固定版 `Game.dll` 的 REA 证据 `ev_bbec1ea533f62ef1389fc50f5a96913392a703ee8f8ff0fe4dab219abbbaeb07` 可见。原版端口设置的有效范围、重启与传输协议细节仍待运行对照，当前存储是独立客户端格式。
