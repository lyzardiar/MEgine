# 玩家暴露视野

地图脚本 `CripplePlayer(player, force, flag)` 记录目标玩家向哪些玩家暴露的掩码，开启时读取玩家组快照，关闭时清空暴露。对战的原 `MeleeExposePlayer` 脚本通过此入口使用该状态。暴露玩家的存活、未隐藏单位作为指定观察玩家的视野来源，单位移动、创建、死亡、归属变化及正常迷雾刷新复用现有会话流程；切图时状态随会话释放。该实现暂按单位视野范围产生迷雾可见区域，隐形侦测及特殊单位处理继续使用现有可见性规则。

REA 对 1.27 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）的静态分析显示，入口 `0x6f1df100` 验证玩家和玩家组后调用 `0x6f241240`；后者在开启时保存玩家组掩码、关闭时清零。现有迷雾半径、隐形侦测、单位资格、原版视觉效果与联机一致性需要阶段运行对照。
