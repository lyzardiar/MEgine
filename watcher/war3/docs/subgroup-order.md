# 子组命令修饰键

游戏性选项使用原 `SubgroupCheckBox` 与 `SubgroupLabel`；确认后保存至独立用户目录 `Settings/camera.bin` 第六版，取消或 Esc 丢弃草稿。旧版设置默认关闭，读取后按原方式迁移，不修改游戏安装。

单机开启后，按住 Ctrl 对高亮子组下达移动、攻击移动、巡逻、目标命令、停止或保持命令；地图和小地图上的目标单击与右击分别使用鼠标按下时的 Ctrl 与 Shift 快照；地面及目标命令的 Shift 队列保留所选子组。立即停止／保持沿用现有非排队入口。子组沿用当前类型分组，其他已选单位不接收命令；Ctrl+数字编组使用既有输入路径。自研实验联机允许使用该选项：当地面移动／攻击／巡逻、目标命令及停止／保持只作用于高亮类型时，发送子组标识及命令并由所有客户端按时间片筛选同类型选择；Shift 队列沿用命令的排队标志。子组类型成员必须与发送端当前选择一致。自研实验联机的技能使用明确能力与有序施法者列表，Channel 保留高亮施法者优先、候选顺序及首个成功后停止的配置；同类型多单位生产子组及原版互通仍待实现或对照。

来源：[Blizzard 经典子组说明](https://classic.battle.net/war3/basics/specialcommands.shtml) 描述 Ctrl 在选项启用时只向高亮子组发送命令。当前类型分组尚未区分携带物品的同类型单位或完整原版优先级；默认值、输入时序、图形界面和实际运行还需要与 1.27 对照。阶段需检查设置确认／取消及旧文件迁移、键盘和鼠标左右键／小地图／Shift、选择保持、无子组／死亡／易主、技能与普通命令、编组热键、网络延迟／多端和真实窗口。

地图界面 Ctrl+单击可控单位，或在双击时两次点中同一可控单位，会选择屏幕内同类型、可选择且当前可见的单位；点击目标优先，最终最多选择 12 个。Shift 与同类型选择组合时保留现有选区并追加未选单位，单击仍使用既有的 Shift 单个切换。联机通过原有选区变更动作编码，等待时间片确认后应用，未直接修改本地模拟；等待确认期间后续选取沿用现有阻断规则。

同类型判定目前只比较单位类型，拥有物品或不同所有者但共享控制的组合、选择顺序、屏幕边缘／雾中/幻象、敌方和非控制单位的原版语义，以及 Shift 与双击的交互仍待对照。切换视角、快捷键和 UI 区域、12 上限、网络延迟／断线亦需功能阶段运行验证。
