# 子组命令修饰键

游戏性选项使用原 `SubgroupCheckBox` 与 `SubgroupLabel`；确认后保存至独立用户目录 `Settings/camera.bin` 第六版，取消或 Esc 丢弃草稿。旧版设置默认关闭，读取后按原方式迁移，不修改游戏安装。

单机开启后，按住 Ctrl 对高亮子组下达移动、攻击移动、巡逻、目标命令、停止或保持命令；地图与小地图上的目标单击和右击使用输入时的 Ctrl、Shift 状态。停止和保持也支持 Shift 排队，未按 Shift 时立即执行并清除原队列。子组使用实时类型与携物规则，其他已选单位不接收子组命令；Ctrl+数字编组使用既有输入路径。实验联机对普通子组命令发送完整成员名单，并在时间片执行时复核选区和控制权；技能、生产、物品及队列取消沿用各自的身份与票号验证。经典互通和真实双端行为仍待对照。

来源：[Blizzard 经典子组说明](https://classic.battle.net/war3/basics/specialcommands.shtml) 描述 Ctrl 在选项启用时只向高亮子组发送命令。携物子组和英雄等级排序已实现，其他类型的完整原版优先级仍待对照；默认值、输入时序、图形界面和实际运行还需要与 1.27 对照。阶段需检查设置确认／取消及旧文件迁移、键盘和鼠标左右键／小地图／Shift、选择保持、无子组／死亡／易主、技能与普通命令、编组热键、网络延迟／多端和真实窗口。

地图界面 Ctrl+单击可控单位，或在双击时两次点中同一可控单位，会选择屏幕内同类型、可选择且当前可见的单位；点击目标优先，最终最多选择 12 个。Shift 与同类型选择组合时保留现有选区并追加未选单位，单击仍使用既有的 Shift 单个切换。联机通过原有选区变更动作编码，等待时间片确认后应用，未直接修改本地模拟；等待确认期间后续选取沿用现有阻断规则。

同类型判定目前只比较单位类型，拥有物品或不同所有者但共享控制的组合、选择顺序、屏幕边缘／雾中/幻象、敌方和非控制单位的原版语义，以及 Shift 与双击的交互仍待对照。切换视角、快捷键和 UI 区域、12 上限、网络延迟／断线亦需功能阶段运行验证。

Tab 按按键事件记录的 Shift 状态选择正向或反向子组，避免同一帧内修饰键状态变化影响方向。隔离视图输入覆盖三种类型的连续正向和反向切换；真实窗口和原版反向切换规则仍待验证。

Shift 停止与保持在当前订单结束后执行。排队停止后的后续移动可继续；保持后续队列的原版处理方式尚待动态对照。旧版本无法读取包含这些新允许命令的排队订单快照。
