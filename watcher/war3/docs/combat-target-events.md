# 战斗目标事件

`GetEventTargetUnit` 读取单位目标事件的目标句柄。单位自动索敌或接受新的主动攻击目标时产生 `EVENT_UNIT_ACQUIRED_TARGET`；主动目标在后续模拟步派发，先处理订单事件。相同目标重复下令不重复产生获取事件；已有攻击目标进入当前武器射程时产生 `EVENT_UNIT_TARGET_IN_RANGE`。离开射程后再次进入可再次触发；更换目标时重新计算。事件按现有触发器条件与过滤器执行，回调后在下一模拟步检查攻击状态，避免沿用已失效的目标或命令。

仅为已注册这两类事件的地图扫描对应订阅；地图从未注册时不对每个索敌或射程转换遍历触发器。主动攻击的触发条件、时序与重复目标规则属于当前实现，尚未通过原版证据验证；射程边缘和最小射程、触发器禁用／销毁／重入、回调时机与原版一致性尚待完成或对照。此实现不能作为全部战斗事件的验收结果。
