# 状态提示的对象字段

单选单位的 Buff 和光环提示在地图字符串解析后复用技能提示的对象字段展开，支持 `<对象ID,字段>` 和 `<对象ID,字段,%>`；对象表使用当前地图覆盖和继承数据。无法识别的引用原样保留。图标路径不进行提示字段展开；提示仍按 Buff ID 在当前会话缓存，来源能力动态等级和运行时数值替换尚未实现。

待集中验证：原版 Buff、地图 w3h／w3a／w3u 等覆盖、WTS 文字、普通字段与百分比、无效引用、中文、多个状态及悬停、 Buff 更新和地图切换；对照原版字段与等级规则、面板布局和文本裁剪。`tests/spell_tests.cpp` 增加共享解析器的普通字段及未知引用检查，尚未编译或执行；实际窗口尚未验证。
