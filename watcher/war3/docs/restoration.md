# 雕像恢复与月亮井补给

Arpl枯萎精髓、Arpm灵魂触摸、Arpb生命／魔法恢复、Ambt月亮井及Amb2魔法电池变体已连接独立客户端的实际施法、命令、生命／魔法、原图标／特效和生命周期。必要产品编译通过；完整玩法、数值时序及原版一致性仍待功能阶段验证。

| 原能力 | 实际消费 |
| --- | --- |
| Arpl／Arpm／Arpb | 读取源等级恢复量、最低缺损、范围、冷却、目标及状态时限；恢复真实生命／魔法，应用短时正面状态，绘制原施法与命中特效 |
| 雕像计费 | Cast为受影响人数上限，0表示不限；DataE为计费人数上限。命令可用／施法要求使用最大费用，释放时按实际择取人数结算，至少计费1人；原Arpl／Arpm每人2魔法、最多计5人 |
| Ambt／Amb2 | 用源生命／魔法费用系数计算实际恢复。原月亮井每1魔法可恢复2生命或0.5魔法；Amb2为只恢复魔法的1:1变体。两类恢复先各分一半预算，再使用另一类未用预算，真实扣除供给方魔法并夹取接收方上限 |
| 自动与输入 | 原replenish／replenishlife／replenishmana及on／off、recharge及on／off订单；命令区原按钮／热键／右键自动边框共用已有施法入口。自动恢复从原范围内选择有需求目标 |
| 右键月亮井 | 受补给单位接受smart订单，沿实际路径接近所选供给者；进入范围后由供给者施放，保留等待／取消／目标死亡移除／能力禁用／归属与资源失效检查；手动远距离指定目标也进入该接近流程 |
| 夜间回蓝 | Ambt DataE夜间恢复标志进入单位缓存，实际再生时使用世界昼夜；能力／等级／科技／类型／归属和可用开关刷新，移除后解除限制，不逐帧扫描能力 |

恢复共用原目标掩码及可见性。生命／魔法满值、机械／有机、友军／本人、幻象是否允许恢复、状态时限、暂停与死亡均有真实判断；目标掩码按引用复用，避免每个候选目标复制集合。雕像生命恢复使用已有虚无治疗倍率。月亮井不额外套用法术治疗倍率。

本机REA静态入口：CAbilityReplenish的0x6f4edf20／0x6f4fcbc0，以及ManaBattery的0x6f612330／0x6f6283a0；0x6f0527e0／0x6f052af0为相关乘除运算入口。源码读取AbilityData／AbilityMetaData、各族AbilityFunc／Strings、UnitAbilities／UnitBalance和原模型。源成员归档／摘要、字段、原生类表及REA记录在tmp/docs-artifacts/war3/restoration/。Game.dll SHA-256为e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a；产品运行不加载它，不解包地图，也不修改原安装。静态依据不等同运行或完整原版一致性通过。

- 月亮井两种资源同时缺损／单一缺损／单一系数、预算不足／剩余／上限及原浮点精度；自动DataC门槛当前按供给者魔法及目标折算需求共同判断，确切原筛选条件和顺序待对照。
- 手动远距离指定、右键多单位接近／供给者忙碌、路径失败／移动与停止、供给者死亡移除／易主／禁用／转型、触发器改变命令或资源时的事件／扣费顺序。当前雕像先预扣最大费用后返还差额，真实事件可观察到该顺序；原事件间精确结算时点仍待对照。
- 夜间恢复、昼夜切换／时间倍率／暂停、研究和地图覆盖、完整AI调度与原声音、三图长局及切图释放。

月亮井水面使用 Ambt 的 `EffectArt` 按井的种族选取模型，随单位渲染并按 `DataD × 当前魔法／最大魔法` 调整地面高度；能力移除、禁用或变化时更新，隐藏、死亡和建造期间停止绘制，单位移除由现有效果生命周期回收。恢复施法仅播放 CasterArt 与 SpecialArt。模型和字段来自源能力及地图覆盖，水位计算参照 [OpenWarcraft3](https://corepunch.github.io/open-realm/games/warcraft-3/ability-and-item-effects/) 的实现，尚未证明与 1.27 原版一致。

源 MoonWell.mdx 的骨骼和附件中没有可直接识别的水面节点或水纹理；Ambt 的效果模型是独立的 MoonWellTarget.mdl 或 CorruptedMoonWellTarget.mdl，原模型来自 war3.mpq，SHA-256 为 `32c9cc736ae4ebf3d23cc37f46cb6f6ff6f0bb1dbed03d72a8a063dc95921686`。阶段验证空／满魔法、水位变化、多个种族与自定义能力、建造／升级／复活／隐藏、能力禁用和原版画面；自动默认状态、Amb2的全部原移动分类，以及窗口／GPU／声音／性能仍待阶段实现或验证。
