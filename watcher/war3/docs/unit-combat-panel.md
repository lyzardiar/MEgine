# 单位战斗信息面板

单选单位的信息区展示其当前启用武器的伤害区间和护甲，以及原有英雄等级、属性与技能点。多选时信息区显示头像，不再叠画单选的英雄、资源、训练或施工状态；命令按钮仍按现有选中单位和子组操作。

攻击区间使用真实武器基础伤害、骰子、英雄主属性、科技、装备、光环和状态倍率，与战斗准备共用基础伤害计算；不包含攻击目标、临时特效、暴击、重击及其他概率技能或目标减伤。护甲与物理伤害处理共用源基础值、科技、装备、敏捷、光环、状态及尖刺外壳计算。计算仅用于显示，不消耗随机数，也不下达游戏命令。多武器以斜杠分隔；训练、研究、建造、升级和反召唤时保留任务进度显示。

武器显示读取 `UnitWeapons/showUI1` 和 `showUI2`，地图 `war3map.w3u` 的 `uwu1`／`uwu2` 可覆盖；关闭显示不改变实际武器和攻击命令。没有可显示的武器时仍显示护甲，不显示空攻击项。原版 1.27 的 `War3Patch.mpq` 中，部分建筑第一武器启用但 `showUI1=0`；农民的两项显示字段均为 1，第二武器目标是树木，是否存在进一步的原版显示筛选尚待对照。

Win32 Release 客户端和 `war3_passive_tests` 编译通过；`weapon-ui` 最小检查 1/1 通过，覆盖农民两把武器、自定义单位隐藏第二武器或唯一武器、原版隐藏武器建筑，以及显示开关不移除实际攻击能力。真实界面与原版逐项表现仍待集中验证。

数值格式、排列、原版增益显示和极值截断尚待对照；阶段核对四族、英雄／非英雄、武器启停／形态、科技／装备／光环／状态、双武器、单位销毁或易主、生产进度、多选切换、不同窗口比例与设备恢复。`tests/passive_tests.cpp` 增加光环变化后面板伤害和护甲的检查，尚未运行。
