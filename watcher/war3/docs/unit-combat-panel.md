# 单位战斗信息面板

单选单位的名称位于信息区顶部中央，生命与魔法值位于头像下方。英雄显示专有名字，等级、职业及经验进度位于名字下方；攻击与护甲在信息区左侧纵向显示，主属性图标及三项属性位于右侧。状态图标和标题沿用当前状态面板。农民等双武器单位在第二列显示另一把武器；多选、货舱和生产使用各自面板。

攻击与护甲使用原版 `SimpleInfoPanel.fdf` 的 0.032 图标、0.0085 标签和上下排列的标签／数值，并读取原版皮肤及地图覆盖。数值来自实际武器、英雄属性、科技、装备、光环和状态；基础值与固定增减值可分离时，以白色基础值及绿色／红色增减值显示。攻击倍率导致两端增减不同的情况显示实际伤害区间，不用单一加成数值代替。护甲展示基础护甲及当前总护甲的差值。源字符串表缺项时使用中文回退。

武器显示读取 `UnitWeapons/showUI1` 和 `showUI2`，地图 `war3map.w3u` 的 `uwu1`／`uwu2` 可覆盖；显示开关不改变实际武器和攻击命令。原版 1.27 的农民两项显示字段均为 1，第二武器目标是树木，进一步的原版筛选仍待对照。

Win32 Release 编译通过；`war3_passive_tests.exe <data-root> <fixture> weapon-ui` 1/1 通过，覆盖双武器、隐藏标志及固定攻击加成和护甲减益与实际数值一致。游戏内置截图检查了农民、圣骑士与装备攻击加成的圣骑士，记录位于 `tmp/docs-artifacts/war3/agent-info/`。布局参考用户提供的原版画面及原版 FDF，非像素级一致性验收。

阶段核对四族、英雄双武器、状态图标较多时的布局、携带资源、长名称与极值、倍率和护甲加成的原版拆分／舍入、等级经验、生产／货舱、地图皮肤、不同窗口比例和实际操作。

英雄经验条收在信息框内并与攻击行留出间距；物品图标、冷却遮罩、点击和拖拽命中使用同一组物品格坐标。使用游戏内置 Agent 选中带六件物品和 100 点经验的圣骑士，取得 1258×904 的实际渲染帧，六个图标在格内，经验条有填充且未与攻击行重叠；证据位于 `tmp/docs-artifacts/war3/agent-info/layout-six-items-xp/`。物品点击、拖拽、冷却以及四族和不同 DPI 尚待阶段验证；当前坐标基于人族界面，未完成原版精度验收。

游戏内 Agent 使用实际输入路径将圣骑士第一个物品拖至第二格，截图状态确认两件物品的句柄交换；验证记录位于 `tmp/docs-artifacts/war3/agent-info/pointer-drag/`。左／右键、冷却及其他种族仍待阶段验证。

经验条填充使用紫色调制源皮肤纹理，与提供的原版画面颜色一致；圣骑士 100 点经验的游戏内截图见 `tmp/docs-artifacts/war3/agent-info/xp-purple/`。颜色值参考画面，具体色值及自定义皮肤仍待原版对照。
