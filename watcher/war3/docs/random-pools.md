# JASS 随机单位池与物品池

`CreateUnitPool`／`CreateItemPool` 创建会话句柄，增加、移除和销毁直接操作各自的池。`PlaceRandomUnit`／`PlaceRandomItem` 按正权重从条目中选择，使用会话共享随机状态，并调用真实的单位／物品创建流程。池句柄可通过原有 hashtable 类型化保存与载入；销毁后句柄仍可能留在脚本或 hashtable 中，再使用会按会话无效句柄处理。

当前实现为每次增加保留一个条目，移除时删除该类型全部条目；权重为零的条目不会被抽中，负数和非有限权重明确拒绝。池为空或全部权重为零时放置返回空句柄且不消耗随机数。池最多 65536 个条目，超限明确失败；选中不存在的对象类型时沿用创建流程的失败行为。这些边界、重复类型、权重和随机数消耗次序尚无原版运行证据，不作为原版一致性结论。

待功能阶段集中验证：common.j 签名与实际地图脚本调用；单一／多项／零权重、重复增加和移除、空池、无效对象、创建位置与玩家归属；相同种子及跨客户端锁步；对象预算、销毁后句柄和 hashtable 保存／载入；与原版 1.27 对照选择比例、随机步进、异常参数和生命周期。不得仅以构建结果视为实际玩法或原版一致性通过。
