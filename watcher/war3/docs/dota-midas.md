# DotA 迈达斯之手

DotA_v6.83d 的实际物品 `I06D` 使用 `ANab` 原型的地图能力 `A28Y` 和攻击速度被动。物品栏将其识别为单位目标；实际使用通过酸性炸弹的既有施法、支付、弹道和脚本事件流程处理，地图定义及脚本决定额外效果。该路径同时适用于其他使用 `ANab` 原型的物品，不改变单位技能入口。

固定版地图的 `A28Y` 目标为非英雄、非远古的敌方或中立生物，施法距离 600、冷却 100 秒。Win32 Release 客户端编译通过。隔离会话从原图创建圣骑士、敌方步兵及实际 `I06D`，使用后目标生命降至零、英雄经验从 0 增至 102、物品仍持有且冷却剩余约 95 秒；探针见 `tmp/docs-artifacts/war3/dota-midas/current.log`。探针直接创建单位和物品，没有通过购买、自然对局或游戏窗口验证，数值不能视为与原版完全一致。

阶段验证实际购买／合成及拖放、不同目标和所有者／远古／魔免、施法距离与取消、冷却、死亡事件／奖励、地图脚本重入、联机及原版画面和操作。
