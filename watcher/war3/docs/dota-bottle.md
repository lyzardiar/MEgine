# 魔瓶与物品目标

`ANcl` Channel 使用源目标配置判断可选单位及地面物品；物品坐标、可见性和存活状态参与施法距离与有效性检查，游戏界面可选择地面物品。物品施法消耗完成后先发布技能生效事件，再发布物品使用事件，保留脚本对物品句柄的操作。

DotA_v6.83d 的隔离探针将地面急速符 `I006` 装入空瓶 `I0AM`，脚本移除符文并生成 `I0H1`；单位及背包内物品不能作为该物品的目标。日志 `tmp/docs-artifacts/war3/dota-bottle/capture-release.log`。客户端编译通过，`remove-item`、`reset-cooldown` 各 1 通过、0 失败；臂章开关及希瓦效果的原图隔离探针继续运行。

原图隔离探针对六种符文执行收取和释放后均恢复三次使用的魔瓶；急速符产生移动倍率 2，赏金符增加金币与经验。数组越界读取及空物品句柄异常已按原版入口修复，日志位于 `tmp/docs-artifacts/war3/dota-bottle/`。回复、幻象和双倍伤害符的效果尚未在该探针观察到，幻象与双倍伤害符在释放后仍留在地面；其拾取和效果流程待修复。事件顺序、其余符文效果、原版一致性、实际窗口操作及联机均待验证。
