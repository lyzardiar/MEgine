# 客户端功能验收矩阵

基准：Warcraft III 1.27.0.52240，Win32 x86。每项需记录相同输入、地图、设置、随机条件下的实际运行证据；没有证据的项目保持待验收。完整矩阵通过后开展 MEngine 移植。

| 范围 | 实现状态 | 验收要求 |
| --- | --- | --- |
| 自有 EXE、参数、独立编译 | Win32 Release 独立构建、真实运行通过，无 Game.dll | 无 MEngine/Node/Rust/Game.dll 运行依赖 |
| 公共 MPQ、地图覆盖、内存缓存 | 覆盖、错误传播、预算和引用生命周期通过；会话持续切图待实现 | 正确优先级、错误传播、有界缓存、切图释放 |
| Direct3D 9、窗口、设备恢复 | 基础批次 D3D9/9Ex 绘制和恢复通过；本批扩大创建回退，新增路径待有可用显示会话时复测 | 真实帧输出、连续缩放、最小化、设备丢失恢复 |
| BLP、字体、音频 | 解码、原版字体帧输出、Miles 内存 MP3 状态与释放通过；音效/听感待验收 | 真实透明通道、原版字体、音乐与音效 |
| 原版主菜单、选图、载入界面 | 基础主菜单通过；单人/选图、源展示规则与焦点链已实现，CPU 对照通过；新增 GPU/交互、完整还原与载入待完成 | 原版三维场景、布局、输入和过渡 |
| MDX/MDL、动画、材质、粒子 | MDX800 基础路径已有菜单 GPU 帧；MDL/灯光/雾/粒子/完整节点规则待实现，logo 比例待还原 | 绑定骨骼、混合/深度、附件、完整特效 |
| 地形、水、迷雾、装饰物 | W3E11 源角点读取通过；渲染、水、迷雾和装饰物待实现 | 原地图空间、材质、水面和可见性 |
| 地图定义与基础路径源数据 | W3I18/25、WTS、WPM0 读取与三图比对通过，尚未消费为游戏会话 | 源玩家、势力、科技限制、随机表、相机与路径位 |
| 对象定义、覆盖、路径、碰撞 | 待实现 | 单位属性、放置、路径网格和寻路 |
| JASS、AI、原生函数、触发器 | 待实现 | 原版 config/main、计时器、句柄和执行顺序 |
| 四族规则、技能、物品、科技 | 待实现 | 从选图到胜负、返回菜单的可玩对局 |
| ROC/TFT 战役、任务、过场 | 待实现 | 关卡、配音、任务状态和进度 |
| 原版存档、回放 | 待实现 | 格式互通、确定性、载入与播放 |
| 局域网 | 待实现 | 双客户端命令同步、校验和重连边界 |
| OpenGL 兼容路径 | 待实现 | 相同场景、材质、输入与资源生命周期 |
| Amazonia、BootyBay、DotA_v6.83d | 源记录/中文元数据与产品 probe 通过；地图初始化、玩法与性能待实现/验收 | 初始化、玩法、性能与持续切图 |
| 性能、无解包与资源释放 | 待验收 | 同机冷/热载入、帧耗时、内存与磁盘增长 |
| 旧转换缓存清理 | 等待直接加载验收 | 核对引用和目录边界，记录回收空间 |

基础批次证据见 [测试队列](testing-batches.md)，仅覆盖已实现范围，不能替代完整客户端验收。World Editor 和在线平台服务不在此次范围。旧 MEngine 批次继续延期，见仓库根目录 `docs/designs/frostbound-realms/native-loading-handoff.md`。
