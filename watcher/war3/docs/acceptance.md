# 客户端功能验收矩阵

基准：Warcraft III 1.27.0.52240，Win32 x86。每项需记录相同输入、地图、设置、随机条件下的实际运行证据；没有证据的项目保持待验收。完整矩阵通过后开展 MEngine 移植。

当前已接通基础战斗、科技研究、采金/伐木、四族基础施工/协作、矿井转换、建筑升级/修理与源荒芜能力。DotA原main和早期模拟通过，最新DOO层加载3,871个可破坏物；完整对局、GPU、原版数值/时序与UI仍待阶段验收。旧BootyBay画面/输入证据仅保留其原验证版本范围。最新实现与证据入口见 `progress.md`、`implementation-roadmap.md` 和 `testing-batches.md`。

2026-10-26起采用[集中实现清单](implementation-roadmap.md)，先覆盖功能流程，再集中测试修正。W022–W024新增对象/单位/物品、天气状态和普通数字声音基础代码已接入，只有产品编译与静态签名检查，尚未获得运行验收；下表原有通过记录保留对应验证版本范围。
