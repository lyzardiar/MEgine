# 客户端功能验收矩阵

基准：Warcraft III 1.27.0.52240，Win32 x86。每项需记录相同输入、地图、设置、随机条件下的实际运行证据；没有证据的项目保持待验收。完整矩阵通过后开展 MEngine 移植。

| 范围 | 实现状态 | 验收要求 |
| --- | --- | --- |
| 自有 EXE、参数、独立编译 | 已实现，待批次验证 | 无 MEngine/Node/Rust/Game.dll 运行依赖 |
| 公共 MPQ、地图覆盖、内存缓存 | 已实现，待批次验证 | 正确优先级、错误传播、有界缓存、切图释放 |
| Direct3D 9、窗口、设备恢复 | 已实现，待批次验证 | 真实帧输出、连续缩放、最小化、设备丢失恢复 |
| BLP、字体、音频 | 基础解码、字体和菜单音乐边界已实现；待批次验证 | 真实透明通道、原版字体、音乐与音效 |
| 原版主菜单、选图、载入界面 | 待实现 | 原版三维场景、布局、输入和过渡 |
| MDX/MDL、动画、材质、粒子 | 待实现 | 绑定骨骼、混合/深度、附件、完整特效 |
| 地形、水、迷雾、装饰物 | 待实现 | 原地图空间、材质、水面和可见性 |
| 对象定义、覆盖、路径、碰撞 | 待实现 | 单位属性、放置、路径网格和寻路 |
| JASS、AI、原生函数、触发器 | 待实现 | 原版 config/main、计时器、句柄和执行顺序 |
| 四族规则、技能、物品、科技 | 待实现 | 从选图到胜负、返回菜单的可玩对局 |
| ROC/TFT 战役、任务、过场 | 待实现 | 关卡、配音、任务状态和进度 |
| 原版存档、回放 | 待实现 | 格式互通、确定性、载入与播放 |
| 局域网 | 待实现 | 双客户端命令同步、校验和重连边界 |
| OpenGL 兼容路径 | 待实现 | 相同场景、材质、输入与资源生命周期 |
| Amazonia、BootyBay、DotA_v6.83d | 待实现 | 初始化、玩法、性能与持续切图 |
| 性能、无解包与资源释放 | 待验收 | 同机冷/热载入、帧耗时、内存与磁盘增长 |
| 旧转换缓存清理 | 等待直接加载验收 | 核对引用和目录边界，记录回收空间 |

World Editor 和在线平台服务不在此次范围。旧 MEngine 批次保持原状态，见 `docs/designs/frostbound-realms/native-loading-handoff.md`。
