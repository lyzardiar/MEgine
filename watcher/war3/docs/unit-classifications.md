# 单位分类与脚本接口

`UnitAddType` 和 `UnitRemoveType` 操作单位分类状态：支持巨型、召唤物、亡灵、机械、工人、自爆、城镇大厅、古树和牛头人。有效类型的重复添加／移除仍返回 true，空单位和其他类型返回 false。`IsUnitType` 读取当前状态；其他英雄、飞行／地面、免疫、负面状态等类型沿用各自的实际判定，不能通过这两个接口伪造。

`IsUnitType` 的疾病和中毒分类读取当前会话的真实状态：疾病云雾使用 `Plague`，攻击毒素及暗影突袭使用各自的毒状态；状态移除、过期和死亡清理由既有状态生命周期处理。原 `common.j` 定义两项枚举为 12 和 21；具体原版毒状态覆盖范围、回调与死亡时序待集中对照。

分类状态参与实际目标筛选及行为：机械／古树／亡灵／巨型等参与攻击、技能、光环、运输、尸体和修理判定；城镇大厅参与 AI 与传送目标，工人参与空闲工人查询。召唤物分类参与驱散伤害、控制魔法、反馈、法球和击杀经验。实例分类在幻象创建时复制，变形保留实例修改；未改变时继续消费原对象和已有召唤生命周期。

只读 REA/Rizin 对原安装 1.27 的 `Game.dll`（SHA-256 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`）显示 `UnitAddType` 入口 `0x6f1fa8f0` 和 `UnitRemoveType` 入口 `0x6f1fb210` 的跳转表支持枚举 9、10、14–20；其余类型返回 false，实际位掩码映射位于 `0x6f966448`。英雄、魔免和抗性类型不能通过以上两个原生函数修改。

待功能阶段验证：原有／自定义单位的九类增加、移除、重复调用与空句柄；治疗、净化、技能免疫、修理、运输、尸体、光环、AI 与击杀经验；脚本修改后变形、幻象、死亡复活、易主和触发器重入；单位原有分类、召唤与定时生命的细节及目标过滤和原版时序。当前 gamecache 尚不保存运行时分类修改，完整原版一致性和性能尚未验收。
