# 灵魂宝石

原始 `gsou` 物品使用 `AIso`，目标为敌对英雄，施法范围 500；来源说明为捕获敌方英雄的灵魂，携带者受到目标所属玩家视野，携带者死亡时释放。`Asou` 的原资料注释指出移除该能力可释放灵魂，`soul` 是捕获后的物品。

当前实现走普通物品目标选择、靠近、施法事件、次数与消耗；捕获时保留目标单位、将其隐藏并暂停，在目标身上设置 `Asou`，目标玩家获得携带者附近视野。脚本从目标移除 `Asou`、携带者死亡或移除时释放英雄，恢复此前暂停状态并移动到携带者位置；被捕获英雄被脚本杀死或移除也解除关联。地图脚本负责创建和移除任务物品 `soul`。

兽族第八章原脚本在使用 `gsou` 后创建 `soul`，结尾移除该物品并从格罗姆身上移除 `Asou`。隔离会话中实际使用原图宝石后只产生一件脚本物品，进入结尾后捕获关联解除、格罗姆转换为 `Ogrh` 并产生胜利结果。测试调整双方位置、暂停其他单位并将萨尔移入目标区域；完整战斗、正常路径及窗口尚未验证。隐藏与恢复、视野半径和物品创建职责仍需与原版运行时及无脚本地图对照；目标生命、事件顺序、坐标、易主、暂停覆盖、魔免与视野范围同样待核对。完整战役及存档恢复仍未实现。

实验联机摘要包含持有者／英雄关联、视野和暂停状态，用于同版本失步诊断，不代表完整同步。Win32 Release 客户端、control 测试和原图战役测试已编译；`item-soul` 与 `war3_orc_soul_campaign_tests` 各 1 通过、0 失败、未加载 Game.dll，分别覆盖目标能力移除、脚本物品独立生命周期和携带者死亡，以及原图捕获、结尾释放和胜利。
