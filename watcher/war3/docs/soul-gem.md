# 灵魂宝石

原始 `gsou` 物品使用 `AIso`，目标为敌对英雄，施法范围 500；来源说明为捕获敌方英雄的灵魂，携带者受到目标所属玩家视野，携带者死亡时释放。`Asou` 的原资料注释指出移除该能力可释放灵魂，`soul` 是捕获后的物品。

当前实现走普通物品目标选择、靠近、施法事件、次数与消耗；捕获时保留目标单位、将其隐藏并暂停，创建 `soul` 并赋予携带者 `Asou`，目标玩家获得携带者附近视野。携带者死亡／移除、脚本移除 `Asou` 移除持有的灵魂物品，或脚本强制掉落／转交时释放英雄并移除灵魂物品；释放恢复此前暂停状态并移动到携带者位置。被捕获英雄被脚本杀死或移除也解除关联。

上述隐藏与恢复、生成物品及视野半径属于当前实现，原版对目标生命、事件顺序、坐标、物品销毁、易主、转交、暂停覆盖、魔免和视野范围的规则尚待对照。场景／双端与实际战役尚未验证；使用事件发生于宝石扣费和移除前，释放效果发生在之后；若回调占满库存，捕获立即解除。拾取事件后复核被捕获者和物品持有关系；死亡、脚本移除或强制掉落会解除关联。完整战役及存档恢复仍未实现。

实验联机摘要包含持有者／英雄／物品关联和视野、暂停状态，用于同版本失步诊断，不代表完整同步。Win32 Release 客户端和 control 测试程序已编译；`item-soul` 最小检查 1 通过、0 失败、未加载 Game.dll，覆盖满库存替换、移除能力、拾取回调删除物品与携带者死亡。
