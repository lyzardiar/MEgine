# 经典回放记录

`ReplayWriter` 接收调用方提供的对局元数据、玩家和槽位信息，按顺序在内存中记录时间片、聊天原始载荷及玩家离开事件，输出带 CRC 和 zlib 分块的经典 W3G 字节。写入器设有记录、动作、时间和内存上限；不会自行创建或覆盖文件。

局域网对局可在首次 `pump` 前通过 `LanRuntime::observeSlots` 显式接入记录器。仅成功应用的时间片传给观察器；记录异常后观察器停用，`observerError()` 保留错误，调用方必须视记录为不完整并禁止保存为完整回放。记录器、观察器和保存入口的生命周期由调用方管理。

该接口尚未接入菜单保存操作、单机录制、聊天和离开事件采集；现有局域网对象编号与校验尚未完成原版对照，因此容器写入并不代表原版可播放或双方兼容。待集中验证：真实样本和写入结果的读取、分块 CRC 与尾块填充、时间片分片及溢出边界、错误停止录制、明确用户操作触发保存、与原版播放器互通。
