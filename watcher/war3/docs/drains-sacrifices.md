# 汲取、法力燃烧和牺牲

原版AHdr/ANdr生命汲取与魔法吸吮、AEmb法力燃烧、AUdr黑暗仪式和AUdp死亡契约已连接实际会话、原订单和源按钮。当前为实现接入、必要产品编译通过；新玩法、完整原版规则和界面仍待阶段运行验证。

| 能力 | 实际消费 |
| --- | --- |
| 生命汲取 | 源周期/普通与英雄持续时间、目标类别和断开距离；真实伤害、伤害事件、实际生命损失回流及DrainUsesEtheralBonus开关 |
| 魔法吸吮 | 从敌人实际扣蓝并向施法者回流，向友军输送时扣除施法者魔法并按目标缺口恢复；原转移开关、原版施法者/目标/奖励buff和三类闪电 |
| 超额资源 | Bonus字段与开关驱动有界临时生命/魔法容量，按源衰减字段回收；伤害、支付、恢复、查询、驱散、死亡和切图共享实际状态 |
| 法力燃烧 | 源开启费用/冷却/目标，独立延迟载荷；按命中时实际扣除的魔法生成伤害，使用源MBUR闪电和目标特效 |
| 黑暗仪式/死亡契约 | 本人亡灵单位、源目标类别与转换率、百分比/保留目标字段；真实死亡/尸体/人口/触发器/货舱生命周期，随后恢复施法者魔法或生命 |

死亡契约物品AIdp及AUdr派生物品也使用原目标流程，真实扣除次数/魔法、登记物品冷却、牺牲所选单位并产生物品事件。

ANdr与AHdr共用原版AHdr原型。ACdr/ACsm及AEmb派生别名复用各自等级、源参数和w3a覆盖；法力燃烧部分源记录的Area为闪电代码，使用LightningEffect绘制并保持单体目标。

汲取沿用Approach/Windup/Channel和真实施法事件。施法者/目标buff按来源和施法票据记录，多名施法者共用目标buff；中断或结束只移除本次来源。跟随两端单位的闪电及源附件归施法生命周期所有，停止、移动、眩晕、目标失效、驱散、断开距离、死亡及移除走统一清理。延迟法力燃烧在释放后独立结算，返回菜单/切图由会话统一释放，不产生解包目录。

## 阶段验证和剩余项

合并验证五种能力的全部等级/派生/w3a、支付/冷却/阶段事件、英雄持续时间、施法距离/断开距离、资源不足/被耗尽/部分吸收、友军输送/归属和联盟变化、控制/隐形/魔免/无敌/外壳/虚无、驱散、同时汲取、能力增删、死亡/移除/复活、回调重入与切图释放。法力燃烧验证0.25秒延迟、1秒闪电及实际烧蓝伤害；牺牲验证真实尸体/人口/死亡顺序和恢复结果。

超额资源当前使用临时容量与逐秒衰减；正Bonus字段限制为基础容量的附加比例，零Bonus且正衰减字段允许有界超额。牺牲默认按目标当前生命换算，百分比字段按施法者相应容量换算；这些基准、上限、衰减和保留目标语义须与原件核对修正，尚不证明原版一致性。完整目标例外、满资源/通道结束时机、所有标志组合、物品目标交互与次数/冷却/回调组合、AI技能策略、循环音效和完整UI/GPU/附件/光束方向继续实现或验证。三图长局、性能、内存和旧MEngine待测项保留各自阶段状态。
