# 主动物品事件与希瓦的守护

非拾取型的永久属性／经验／生命／攻击能力物品通过通用物品施法流程执行，支付魔法和冷却，发布技能事件后应用对应永久效果。拾取即使用的能量提升物品继续沿用原有拾取流程。地图脚本因此可以在物品能力的施法事件中创建实际效果，而能力原字段仍由游戏会话消费。

脚本可对 `ShowUnit(false)` 隐藏的单位下达目标施法，施法者处于运输等隐藏状态时仍受原有限制；玩家直接施法仍检查显示状态。DotA_v6.83d 希瓦的守护 `I00Z` 使用 `A0T9` 触发地图冰环脚本，隐藏施法单位对命中者施加 `A0T0` 减速。隔离会话直接创建英雄和物品后使用，目标生命约由 420 降至 220，移动倍率降至 0.6，约四秒后恢复；记录 `tmp/docs-artifacts/war3/dota-shiva/after-hidden.log`。

Win32 Release 客户端及 mobility 测试程序编译通过；隐藏单位目标脚本施法与玩家限制、力量之书拾取分别为 1 通过、0 失败，未加载 Game.dll。该检查未覆盖实际购买、操作和窗口；原版事件次序、隐藏／运输／死亡交互、零与非零永久属性、能量提升、多目标／法免／阻挡和联机仍待对照。
