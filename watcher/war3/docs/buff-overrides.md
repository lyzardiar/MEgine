# 地图 Buff 对象覆盖

加载地图时从归档内存读取 `war3map.w3h`，使用原版 AbilityBuffMetaData 和 AbilityBuffData 的映射解析原始 Buff 修改和自定义 Buff；自定义对象继承其基础对象及已覆盖字段。Profile 字段查询不区分大小写，图标、名称、描述和特效读取复用同一对象覆盖。地图专属对象随会话释放，不生成解包文件。

覆盖仅应用元数据中能够映射到已加载数据表或 Profile 的字段；未知或无可用表的字段计入对象覆盖未知字段计数。自定义 ID 冲突、找不到基础对象和无效输入会报错。完整原版行为、真实地图兼容性及运行时界面和特效仍待批次验证。

研究测试夹具包含原始 Buff 和继承该 Buff 的自定义对象，待验证图标、名称、描述、目标特效和不同大小写的字段读取。
