# 回放时间驱动

`ReplayRuntime` 持有已解析的回放，使用调用方提供的单调时钟推进录制时间片。暂停仅停止本地播放时钟，速度范围为 0.25 至 8 倍；每次最多处理 256 条记录，未处理的时间留待下一次调用。连续时间片片段在完整时间片出现时合并，动作和字节数量受限。结束、主动停止和错误分别报告；时钟倒退、损坏的片段或消费者异常会终止播放。

调用方必须提供时间片消费者和非时间片记录处理器。消费者需要按顺序把完整时间片交给已配置的 `LanSimulation` 或同等接口，并将实际错误原样返回；记录处理器必须明确处理收到的每个记录，不能忽略未知行为。对象 ID 和玩家映射、随机种子与会话初始化由调用方负责，驱动不推测原版映射。调用方在播放期间必须禁止观看者的选择、指令、对话和其他会修改模拟状态的输入，允许的本地镜头操作须与模拟状态隔离。回调不能重新调用当前驱动。

当前驱动尚未接入主菜单、`GameView` 或原版对象映射。聊天、玩家退出、校验和、回放视角和其余非时间片事件仍需各自消费者；已有 LAN 动作支持范围不能代表完整原版回放。播放流程、时钟、异常和用户输入隔离均待集中验证。
