# 武器攻击可破坏物

玩家在游戏界面使用攻击命令选择可破坏物，或地图脚本使用目标攻击订单时，单位读取自身已启用武器的目标类型，与地图可破坏物源 targType 匹配；具备 debris 目标武器的单位可攻击门和障碍，具备 tree 目标武器的单位可攻击树。单位接近目标后按武器射程、前摇、冷却、攻速与伤害骰子攻击；远程武器创建实际弹道，命中后通过物件伤害与死亡事件、地形占用更新消费。炮击／范围弹道按源三段半径及系数伤害范围中的单位和可破坏物；弹跳弹道按源目标类型、范围、数量和衰减，在单位与可破坏物间选取最近未命中目标。直线弹道按源扩散距离和宽度命中路径上的单位及可破坏物，先处理主目标，再按句柄处理其他目标；零扩散距离仍覆盖发射点到主目标的路径。新的订单或目标失效会中断攻击，目标死亡后复活不会受到旧攻击或旧弹道。

原 1.27 源数据中树为 tree、门和木桶为 debris；步兵、兽族步兵、食尸鬼及弓箭手的普通武器包含 debris，食尸鬼第二武器包含 tree。迫击炮及投石车的源范围目标包含 ground、structure、debris、tree、wall，月刃的弹跳目标包含 ground、structure、debris、enemy；刃车 ebal 为 aline，扩散距离为 0、宽度为 50。读取目标分类支持地图对象覆盖；单机界面攻击与 Shift 排队进入同一目标订单；实验联机沿现有可破坏物身份、位置及目标订单编码和时间片回放路径。链路尚未运行验证。

当前以目标对象源类型与武器类型取交集，武器数据沿用公共骰子校验。障碍护甲／攻击类型修正、弹道视觉高度、空白类型及特殊门桥判定尚需原版对照。直线攻击的逐目标伤害衰减、攻击被动／法球及对物品目标暂未接入该分支；范围／弹跳目标顺序、目标关系、边界、原版事件和表现均需对照；不能将其作为完整武器行为。范围和直线查询复用会话装饰物空间索引，直线查询按障碍最大半径扩大候选范围，按目标句柄稳定处理，命中前校验目标死亡轮次；伤害回调移除、杀死或转让攻击者时停止本次剩余命中。实际窗口、远近程、排队／取消、地图脚本死亡与重入、树恢复、所有权、路径、不同面积、零距离、穿透顺序和双端同步待阶段验证。未执行编译和运行验证。
