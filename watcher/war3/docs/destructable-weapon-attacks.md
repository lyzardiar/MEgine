# 武器攻击可破坏物

玩家在游戏界面使用攻击命令选择可破坏物，或地图脚本使用目标攻击订单时，单位读取自身已启用武器的目标类型，与地图可破坏物源 targType 匹配；具备 debris 目标武器的单位可攻击门和障碍，具备 tree 目标武器的单位可攻击树。单位接近目标后按武器射程、前摇、冷却、攻速与伤害骰子攻击；远程武器创建实际弹道，命中后通过物件伤害与死亡事件、地形占用更新消费。新的订单或目标失效会中断攻击，目标死亡后复活不会受到旧攻击或旧弹道。

原 1.27 源数据中树为 tree、门和木桶为 debris；步兵、兽族步兵、食尸鬼及弓箭手的普通武器包含 debris，食尸鬼第二武器包含 tree。读取目标分类支持地图对象覆盖；单机界面攻击与 Shift 排队进入同一目标订单；实验联机沿现有可破坏物身份、位置及目标订单编码和时间片回放路径。链路尚未运行验证。

当前以目标对象源类型与武器类型取交集；升级增加骰子而源骰面为零时按一面骰处理以避免除零，该边界尚未对照。障碍护甲／攻击类型修正、弹道视觉高度、空白类型及特殊门桥判定尚需原版对照。范围伤害、弹跳、直线扩散、攻击被动／法球和对物品目标暂未接入该分支；不能将其作为完整武器行为。实际窗口、远近程、排队／取消、地图脚本死亡与重入、树恢复、所有权、路径和双端同步待阶段验证。未执行编译和运行验证。
