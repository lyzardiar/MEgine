# 地雷与怪物诱饵

2026-10-28。实现接入，必要Win32 Release产品增量编译通过、无编译警告，差异检查通过；新增玩法、原版精度、窗口／GPU／音效／AI和性能仍待功能阶段验证。

| 原型 | 源参数与真实消费者 |
| --- | --- |
| AIpm | 库存选点、接近、次数／魔法／共享冷却／事件；UnitID生成实际地雷，不生成解包资产 |
| Amin | DataA激活延迟、DataB隐形转换时间、Rng触发范围；注册到活跃被动时钟与空间网格，暂停／禁用、科技／能力／类型／库存刷新和死亡轮次进入状态处理 |
| Adda及Amnx | DataA／DataB为全额范围／伤害，DataC／DataD为部分范围／伤害，Dur为死亡后延迟；共用实际死亡快照与延迟爆炸、敌我／地空／建筑／地形对象筛选和伤害消费者 |
| AImo | DataA为每次招引数量，DataB为激活延迟，DataC为招引周期；UnitID生成一个实际诱饵守卫，Dur为存续时间，Area为检索范围 |

地雷在Amin激活后检测敌方地面单位，触发自身死亡，再由真实Adda死亡能力结算范围爆炸；被击杀也进入相同死亡路径。隐形状态共用已有侦测、视野、目标与渲染消费者。地图预放／JASS创建的地雷和能力派生也使用同一被动注册。Self Destruct分类允许魔免目标进入拆毁伤害判定，后续仍由实际伤害规则处理。

诱饵共用守卫激活和空间检索，按距离与句柄稳定排序，向范围内中立敌对非英雄单位下发实际攻击命令。引诱状态允许朝尚不可见的诱饵寻路，暂时抑制守卫距离返航；诱饵到期、死亡、移除或隐藏后恢复普通目标与返航检查。新的玩家／脚本命令按现有取消流程清除引诱状态。命令回调后的单位、死亡和归属轮次再次检查。

源表来自只读原安装的AbilityData、Profile与AbilityMetaData／WorldEditStrings。原始参数、中文字段名、摘要及提取脚本在tmp/docs-artifacts/war3/item-summons/placed-source.json与read-placed-items.py。Win32 Release必要编译日志为同目录placed-build.log和placed-final-build.log；运行不加载Game.dll。

阶段集中验证：地雷的10秒激活／2秒隐形、暂停／禁用／复活／易主、真视／显隐与攻击目标；触发单位分类、原扫描精度／范围边界与碰撞、被击杀／触发后的0.3秒爆炸／原伤害及魔免建筑／地形对象、多个死亡能力／归因／事件重入；诱饵60秒存续、5秒激活／2秒招引、1个目标计数及多个诱饵、远处无视野寻路／攻击／取消／返航／出生与销毁；库存六槽和完整UI／声音、三图／DotA长局、内存／性能及切图释放。

原地雷的精确触发分类、时钟／显隐、爆炸伤害种类与多能力顺序，以及诱饵的选怪／睡眠／守卫与周期计数语义仍待原版对照。当前空间与命令实现有实际消费，不据此认定已经达到原版一致性。Amec机械小动物的原池选择及敌方伪装仍未实现。
