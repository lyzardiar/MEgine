# 任务窗口键盘导航

F9 任务窗口使用原版 `UI/FrameDef/UI/QuestDialog.fdf` 的任务列表和按钮。焦点处于任务行时，上／下选择相邻任务，左／右切换主线与可选任务，Home／End 跳至当前列表首尾，Page Up／Page Down 按当前列表的可见行数移动；新选择会同步原有详情、目标和高亮，并在目标行位于可见区外时调整列表滚动。任务列表为空或焦点位于确认按钮等其他控件时不拦截这些按键。鼠标选择、Tab／Enter、F9／Esc 关闭和任务脚本状态沿用现有流程。

菜单与行的资源来自原版 FDF；方向键及翻页规则为当前客户端的键盘交互实现，尚未核实原版 1.27 对相同按键的精确行为。未发现或禁用任务的列表筛选不在本项范围，仍需原版证据。
