# 零效率魔法盾

`ANms` 允许魔法效率为零，开关、技能状态、支付、冷却和事件继续走实际自身技能流程。零效率或零吸收比例不扣魔、不改变受到的伤害，避免除零；正效率的原魔法盾继续按现有吸收规则运行。

DotA_v6.83d 的守护精灵使用零效率、零吸收的 `A28Q` 作为过载开关；地图脚本通过订单事件授予或清理加成，并按周期改变生命与魔法。隔离原图会话在 `-sd` 选择守护精灵后学习并开关此技能，观察到脚本加成的添加／移除及启用期间资源下降。探针预设生命与魔法，不代表自然对局、真实窗口或原版精度验收。

Win32 Release 客户端及 `war3_spell_tests` 编译通过；`zero-mana-shield` 隔离检查 3/3，覆盖零效率的零／非零吸收比例、零魔法、开关与原始正效率吸收，未加载 Game.dll。零效率与非零吸收比例的行为是当前实现值，其原版语义、边界、资源／伤害事件顺序、同类状态组合和多人同步待阶段对照。
