# Effekseer Fire

Open this directory as an MEngine project, then enter Play mode. The
`Effekseer Fire` entity in `Assets/Scenes/Main.mscene` continuously plays a
real `.efkefc` effect through the shared editor/player RHI path.

From the repository root it can also be run with:

```powershell
npm.cmd run sample:effekseer
```

The effect and its required companion assets come from Effekseer's official
`EffectMaterials` repository at commit
`8bf8edfedb51ac09af3d4cf788cb81746ea75a82`:

- `Effects/ef_fire01.efkefc`
- `Effects/Materials/mt_dissolve02.efkmat`
- `Effects/Textures/tx_fire_flipbook01_1024.png`
- `Effects/Textures/tx_glow02_128.png`
- `Effects/Textures/tx_noise01_256.png`

Upstream declares all repository data CC0. The effect's upstream credit is
`KTK_kumamoto` and its authored Effekseer version is 1.7.

Source: <https://github.com/effekseer/EffectMaterials>
