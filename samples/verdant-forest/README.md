# Verdant Forest / 翠影幽林

导入自 **Poly Haven CC0** 真实照片扫描 3D 自然资产（冷杉、灌木、苔藓巨岩、倒木、蕨类、林地 1K PBR 贴图与 32-bit 森林 HDRI `epping_forest_01`），按原始 glTF 材质 1:1 拆分导入 MEngine，验证 4 级联 CSM 树影、Cubemap IBL、SSAO、Bloom、AgX 以及 PBR / 卡渲 Toon / 标准 3D 实时切换。

按键：`1` 物理 PBR · `2` 卡渲 Toon · `3` 标准 3D · `C` 切换运镜 · `WASD/QE` 自由漫游 · `Space` 暂停/恢复自动运镜。
