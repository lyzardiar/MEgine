# Pelican Island Ride / 鹈鹕环岛骑行

原创 3D 海岛环游骑行场景示例：一只戴着遮阳渔夫帽、系着海风围巾的鹈鹕，骑着带藤编鱼篮的复古沙滩单车，沿闭合环岛海滨骑行道绕热带海岛悠闲骑行。

## 运行

在 MEngine 编辑器中打开本目录的 `project.json` 进入 Play 即可直接欣赏自动环岛骑行；或从仓库根目录命令行启动：

```bash
npm run build:samples
cargo run -p mengine-runtime -- --sample pelican-island-ride
```

## 操作 / Controls

| 键位 | 作用 |
| --- | --- |
| （默认） | 自动沿环岛公路匀速巡游骑行 |
| `W` / `S` 或 `↑` / `↓` | 加速 / 减速（松开后平滑回归舒适巡航速度） |
| `A` / `D` 或 `←` / `→` | 在环岛骑行道内左右变道与压弯 |
| `C` | 切换 4 种镜头：侧后跟随 / 骑行近景特写 / 海岛俯瞰 / 环岛电影运镜 |
| `L` | 切换光线氛围：热带晴昼 ↔ 黄金日落 |
| `B` | 按响清脆车铃，鹈鹕开心拍打双翼 |
| `Space` | 暂停 / 继续骑行动画 |
| `V` | 显示 / 隐藏 HUD 覆层 |
| `M` | 静音 / 取消静音（海风浪声与车铃） |

## 场景与实现

- **鹈鹕与复古单车**：使用 Catmull-Rom 放样曲面（`loft`）构建连续流畅的鹈鹕身躯、S 形长颈、长喙与垂坠喉囊、遮阳帽、随风飘动的围巾与羽翼；自行车包含经典菱形车架、弧形车把、装有小鱼的藤编车篮、前后辐条车轮与独立驱动的牙盘曲柄，双脚随曲柄圆周实时踩踏。
- **闭合热带海岛**：程序化生成有机轮廓海岛与火山双峰，沿闭合环岛曲线精确平整滨海骑行道、路缘石、护栏与沙滩木栈段，并布置椰林、彩色海滨小屋、红白条纹灯塔、木码头、帆船、岸边礁石与空中盘旋海鸥。
- **自定义着色器**：
  - `Assets/Shaders/Ocean.mshader`：多重波浪高度场法线、环岛浅滩青绿渐变、拍岸浪花带、Fresnel 反射与阳光碎金。
  - `Assets/Shaders/Island.mshader`：屏幕导数切线空间法线贴图，按高度与坡度过渡湿沙、暖金沙滩、草坡与火山岩壁。
  - `Assets/Shaders/Sky.mshader`：支持晴昼与黄金日落平滑过渡的程序化晴空、太阳光晕与漂移积云。
- **确定性重建**：全部模型（GLB）、贴图、合成音效、场景与 `.meta` 文件均由 `scripts/create-pelican-island-ride.py` 一键生成。

```powershell
python scripts/create-pelican-island-ride.py
npm run build:samples
```
