# BoxCollider2D_Stacked

来源：Unity 官方 [PhysicsExamples2D archive/2019](https://github.com/Unity-Technologies/PhysicsExamples2D/tree/873d60529b7e4735bdc8821048e728e42d3a0fad/Assets/Scenes/Colliders/BoxCollider2D_Stacked.unity)，Unlicense；Platformer Art 为 Kenney CC0。

左键点击并拖动物体，释放鼠标移除 TargetJoint2D。R 重开，H 显示/隐藏文字。

保留源场景的 Sprite、位置、碰撞几何、摩擦/弹性与生成时序；使用本引擎 Rapier2D 求解，轨迹不宣称与 Box2D 逐帧相同。TextMesh 转为可读的 Roboto 叠加文字。来源和适配详见 SOURCE.json。
