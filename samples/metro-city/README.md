# Metro City / 现代都市

导入自 **Kenney CC0** 商业摩天楼、道路网、路灯与车辆套组 + **Poly Haven CC0** 32-bit 黄金日落天空 HDRI（`belfast_sunset_puresky`），构建 136m×136m 大型现代都市街区，含 36 盏真实动态路灯点光源、流动车流、4 级联 CSM 建筑阴影、Cubemap IBL、SSAO、Bloom 与 AgX 色调映射。

按键：`1` 物理 PBR · `2` 卡渲 Toon · `3` 标准 3D · `C` 切换航拍/街景/公园视角 · `WASD/QE` 自由飞行 · `Space` 暂停/恢复自动运镜。
