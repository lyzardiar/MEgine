Description

Based on Ujimasa Hojo's optimized Captain. Just like the base model, wraps are optimized, portrait is incorporated, animations are linearized. Credits to @Ujimasa Hojo for the base model.
If you use or edit this, I kindly ask that you credit Ujimasa Hojo.

The bundle contains:
1. A blood elf lieutenant, with the regular vanilla blue eyes (V1.00)
2. A blood elf lieutenant with green glowing eyes (V1.01)
3. A blood elf lieutenant whose face has been rewrapped to that of a blood elven priest, with glowing eyes (V1.02)
4. A high elf version of the captain, whose face has been rewrapped to that of a high elven priest, with glowing eyes (V1.03)

Additionally, a pack containing a different wrap of chest and legs, that more closely resembles the vanilla units, has been made at the request of a user and will be added to the first comment (V2.--r).
