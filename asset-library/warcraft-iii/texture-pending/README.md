# 等待原始贴图的模型

作者：MiYu

15 个模型的 44 个材质层网格、各层 UV、骨骼与 15 段动画已转为原生 GLB。`Assets/WarcraftIII/texture-pending-catalog.json` 保存源材质与纹理名称；`SourceAssets` 保存原始 MDX；`Validation` 保存姿态比较和缺失引用。

这些资源需要原始 `redstone_rock.blp`、`worldtreetrunk.blp`、`rockseemles a1.blp` 或 `carpet.blp`，暂未生成带替代材质的战场 prefab。详见 [补充转换](../../../docs/designs/frostbound-realms/supplemental-conversion.md)。

UTM 与对应素材作者的原有署名、使用条件继续有效；MIT 许可仅适用于转换工具。
