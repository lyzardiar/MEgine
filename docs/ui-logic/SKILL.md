# UI 业务逻辑代码指南

用于创建或修改 UI 业务逻辑代码。规范以 [project.md] 为准。

## 澄清规则
- 存在影响实现方向的不确定信息时，必须使用**提问工具**与用户澄清。
- 需求文档（md）中的变量名（如配表名 `DanRecipe` 等）仅为命名建议与含义标记，初版实现时大概率不存在，**禁止**据此搜索代码，直接使用**提问工具**与用户确认。
- 用户未明确提出时，**忽略红点功能**。
