# Play 共用脚本和渲染的实体快照缓存

Author: MiYu

`ScriptHost.capture_world_snapshot` 使用脚本发布时的实体缓存导出不可变渲染快照。Play 初始化、模拟完成和无 revision 渲染均复用这一缓存。未变化实体共享 Arc，变化实体产生新快照；脚本仍读取回调前的快照，渲染历史持有已完成帧的快照。导出不会替换 JavaScript 的 snapshot、revision 或用户持有的旧对象。

28 项脚本测试、20 项 Play 运行时测试通过，另外 3 项人工性能测试未包含在常规测试中。新增测试验证未变实体复用、变更隔离、JavaScript 旧快照隔离和删除后历史保留。原生模拟性能采样另行运行，每版预热 360 步、记录 60 步。前端和 Release 构建通过；Release 耗时约 6分17秒，保留已有 `world_from_snapshot` 未使用警告。

## 真实 Release 工程验收

使用同一 Frostbound 场景及 Main.js，按旧版、新版、旧版重复、新版重复的顺序运行。采样期间无构建或 CPU 测试。所有四轮均通过；首轮旧版存在较大停顿，完整保留数据。不得把首轮波动全部归因于本次改动。

| 指标 | 旧版 | 新版 | 旧版重复 | 新版重复 |
| --- | ---: | ---: | ---: | ---: |
| Scene 绘制（ms） | 9.089 | 6.890 | 7.023 | 6.849 |
| Scene 新原生帧（FPS） | 26.343 | 36.255 | 36.627 | 36.032 |
| Scene 模拟推进（次/秒） | 10.288 | 26.392 | 25.278 | 26.305 |
| Game 全区间新原生帧（FPS） | 27.360 | 35.928 | 35.943 | 35.684 |
| Game 固定10秒新原生帧（FPS） | 28.900 | 38.700 | 37.700 | 38.500 |
| Game 最大新帧间隔（ms） | 588.300 | 97.200 | 152.400 | 101.100 |
| Edit 移动空画面 | 0 | 0 | 0 | 0 |
| Play 移动空画面 | 0 | 0 | 0 | 0 |

固定10秒区间从第一个绘制时间加1秒开始，保留期间停顿；最大新帧间隔按所有 Game 绘制记录的 sequence 变化计算。原生阶段开销降低，但四轮数据不足以证明整体帧率稳定提升或稳定60 FPS。

四轮均通过等待相机请求时的拾取、真实 Footman GLB 点击、父子变换、模型姿态、层级隐藏、GPU Canvas、相机预览、暂停/单步/停止重启和资源刷新。四个自有编辑器均已退出；临时材质及 meta 已移除，隔离 Main.js 已恢复并核对 SHA256。其他机器与多窗口/DPR 未在本轮验收。
