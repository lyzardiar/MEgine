# Scene 共享修订的派生数据复用

Author: MiYu

原生视角变化生成新的画面包装对象时，浏览器按该画面持有的实体数组识别相同源数据，复用层级激活查询、世界变换和相机派生数据。新的实体数组会重新计算，Timeline 预览权重和显示器变化继续触发相机更新。派生数据不依赖画面的颜色、模拟时间或运行会话。

playRenderSnapshot 通过结构比较验证编辑副本，无需为布尔验证复制整份实体指针列表和颜色。可变组件、外部引用、getter、Proxy 和 toJSON 的比较及回退语义保持原样。共享实体记录来自原生工厂冻结数据；可变快照继续各自持有 JSON 副本。编辑态缓存、显隐和原生修订协议沿用现有行为。

## Release 验收

基线为 `8917010`，固定同一 Frostbound Main.js，按旧版、新版、新版重复、旧版重复运行；移动视角期间同时推进实际游戏模拟，采样时不运行构建或 CPU 测试。完整 JSON 仅在暂停后的像素校验阶段解析。

| 指标 | 第一组旧版 | 第一组新版 | 第二组旧版 | 第二组新版 |
| --- | ---: | ---: | ---: | ---: |
| Scene 绘制耗时（ms） | 11.60 | 9.55 | 11.23 | 9.94 |
| Scene 新原生帧（张/秒） | 36.81 | 38.15 | 39.08 | 38.29 |
| Scene 模拟推进（次/秒） | 10.65 | 16.02 | 11.71 | 15.45 |
| Game 新原生帧（张/秒） | 39.05 | 39.71 | 38.64 | 39.76 |
| Game 模拟推进（次/秒） | 39.80 | 40.85 | 40.15 | 40.87 |
| worldTransforms 调用栈采样耗时（秒） | 1.35 | 0.60 | 1.40 | 0.58 |
| render snapshot 调用栈采样耗时（秒） | 0.45 | 0.46 | 0.42 | 0.44 |
| 移动时空画面次数 | 0.00 | 0.00 | 0.00 | 0.00 |

表中的调用栈耗时包含子调用，为各次 12 秒移动采样中的 CPU 总时间；不代表物理显示 FPS，也不可与父调用再次相加。四次编辑态和运行态移动均无空画面；真实活动树木、城镇大厅与农民、GPU 像素、模型选择、层级展开滚动、选中相机预览、暂停、单步和停止重启通过，无控制台 error。两次候选原生显隐像素检查通过，包含隐藏父级、显式后代、浏览器快照、恢复与再次隐藏，像素容差 0.5%。

46 项前端回归通过，涵盖同实体数组的不同相机帧复用、新实体数组的层级及姿态更新、旧画面恢复、Timeline 权重变化、深层编辑和 toJSON 失效。独立只读审核已核查生产 frameWorld 来源及其所有权前提，无阻断；性能证据来自主代理实测。四次 QA 进程均退出，隔离 Main.js 已恢复且哈希一致。验收记录 (`scene-derived-reuse-performance.json`)包含请求计数、像素结果、CPU 采样、EXE 哈希和日志。

整体卡顿、稳定 60 FPS、其他机器以及多窗口物理显示仍需继续验收。完整 Warcraft III 单机、联机、地图编辑器和地图复刻仍有未完成项。
