# Play 实体列表按暴露记录验证

Author: MiYu

原生发布时，私有编辑副本与不可变世界已有一一对应关系。客户端记录当前暴露实体的索引，跳过仍为私有的记录，继续深度比较暴露记录。暴露版本必须保持不变；getter 或 Proxy 在比较中暴露新记录时，从当前位置恢复完整检查。原型或序列化钩子变化时，剩余记录也恢复完整比较。颜色继续独立比较，普通 capture、reset 和自定义 runtime 保留原有行为。

95 项播放、原生世界所有权、视口及 AgentBridge 回归通过。新增检查包括 10,000 个实体中仅比较两条暴露记录，直接修改暴露记录的深层数据，以及 getter 暴露其他实体、安装全局序列化钩子时立即恢复检查。既有测试覆盖颜色、元数据、层级、待完成 IPC、重启、Behaviour 生命周期及自定义驱动。

Node/Vite 独立对照使用 10,000 个实体，其中 6 个已暴露；每样本执行 128 次验证，20 组交替测量。中位耗时由 14.747 ms 降至 0.305 ms，逐项检查次数由 1,280,000 降至 768。该数据是列表比较基准，不代表编辑器帧率。TypeScript/Vite 及内嵌前端的原生 Release 构建通过；没有 Rust 或游戏脚本修改。

## 四轮真实 Release 对照

同一隔离工程、同一 Main.js，仅交换旧版与新版 EXE。每轮验证 Edit/Play 持续移动、延迟新相机帧时拾取显示中的模型、原始 Warcraft 模型、父级变换、显隐、相机预览、层级列表、播放控制及资产刷新。采样期间没有并行构建或 CPU 测试。

回调采样汇总 unchanged 和 comparisonIndices 的 self 时间，不能当作整个验证流程的精确计时。两组 Game 回调采样减少约 79%～81%，Scene 减少约 56%～57%；Scene 呈现速率两组分别略降约 0.9% 和 1.9%，Game 两组分别略升约 0.3% 和 3.4%。本次确认了重复验证开销下降，不能据此声称整体帧率稳定提升。

四轮所有验收通过，Edit/Play 移动空画面均为 0，控制台 error 为 0。QA 进程均退出、资源 fixture 和基准临时源文件已删除，隔离工程脚本恢复并核对原始哈希。

当前本机运行态 Scene 约 40 张/秒，仍未达到稳定 60 FPS；跨机器严重卡顿需更新构建后复验。原生最后一帧采样中 GPU 回读仍有数毫秒等待，后续分析这条路径。完整 Warcraft 单机、联机、地图编辑器、TD/Dota 目标继续推进。
