# Play 私有实体列表验证复用

Author: MiYu

原生发布已经建立不可变世界与私有编辑副本的一一对应关系。全部记录仍为私有且暴露版本未变化时，Scene/Game、面板快照和原生世界引用的验证复用这个关系，省去重复实体遍历。任一引用暴露后恢复逐项比较。改变原型或 JSON 序列化钩子、普通捕获和 reset 会取消复用；清屏颜色继续独立检查。可编辑引用、Behaviour 回调和自定义 runtime 仍保留原有直接修改检测。

## 验证

93 项相关测试通过，覆盖深层 Transform/UI 修改、元数据、层级、颜色、外部组件别名、待完成 IPC 请求、原生版本、重启、Behaviour 注册与生命周期、播放控件、Scene 帧和显隐快照。新增测试以 10,000 个实体验证私有列表的重复检查不再扫描记录，以及暴露、颜色修改、普通捕获、reset 和序列化钩子后的行为。

Node/Vite 独立对照采用 10,000 个私有实体，每个样本执行 128 次验证，20 组交替测量。中位耗时由 10.806 ms 降至 0.013 ms，逐项检查由每样本 1,280,000 次降至 0。该结果仅证明私有列表比较开销，不代表编辑器整体速度。

前端 TypeScript/Vite 和原生 Release 构建通过。Release 构建使用 `tauri/custom-protocol` 内嵌前端。本次没有 Rust 或游戏脚本修改。

## 真实 Release 对照

同一隔离工程、同一游戏脚本，交替执行旧版、新版、旧版重复、新版重复。测量期间没有并行构建或 CPU 测试。每轮验证 Edit/Play 持续移动、延迟新相机帧时拾取显示中的模型、原始 Warcraft 模型、父级变换、隐藏、相机预览、层级虚拟列表、播放控制及资产刷新。

两组 Scene 呈现速率分别提高约 5.2% 和 12.1%，Game 呈现速率分别提高约 1.8% 和 4.9%。Game 模拟推进第一组略降、第二组上升，不据此声称模拟整体稳定提速。浏览器采样中的逐实体 unchanged 回调耗时减少，但仍存在暴露记录的常规比较。

四轮 Edit/Play 移动空画面均为 0，所有验收检查通过，无控制台 error。拥有的 QA 编辑器均退出，fixture 已删除，隔离工程脚本恢复原始哈希。当前运行态 Scene 约 37～38 张/秒，尚未达到稳定 60 FPS；其他机器需更新、重新构建并复验。

构建哈希、基准每组数据、93 项回归日志和四轮原始报告路径见 [验收记录](private-world-validation.json)。完整 Warcraft 游戏目标仍在继续。
