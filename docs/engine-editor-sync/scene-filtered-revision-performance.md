# Scene 原生修订与显隐过滤

Author: MiYu

运行态主 Scene 视图隐藏节点时，使用发布的精确 Play 修订号请求原生画面。原生侧按源实体 ID 过滤隐藏节点、非激活节点及其后代，在保留的场景镜像上更新变化组件；无需为每次移动视角序列化并上传完整 JSON 场景。过滤同步耗时计入 worldSyncMs。

画面、浏览器拾取和覆盖层使用同一修订的可见记录。选中相机预览继续使用经过过滤的独立快照；外部组件深层编辑会使修订引用失效并上传独立快照。修订淘汰后的回退保留显隐参数和原修订的浏览器快照，过期运行会话继续报错。编辑态缓存与运行态过滤镜像独立，过滤镜像的更新和绘制由同一互斥锁保护。

## Release 验收

基线引擎为 `d0fbc0a`。同一 Frostbound Main.js，按旧版、新版、新版重复、旧版重复运行；移动视角期间同时推进真实游戏模拟，采样时不构建或运行 CPU 测试。通过实际 Tauri fetch 发送路径计数，完整 JSON 只在暂停后的像素检查阶段解析。

| 指标 | 第一组旧版 | 第一组新版 | 第二组旧版 | 第二组新版 |
| --- | ---: | ---: | ---: | ---: |
| Scene 绘制耗时（ms） | 12.23 | 11.80 | 12.16 | 11.70 |

| Scene 模拟推进（次/秒） | 11.86 | 10.15 | 11.69 | 10.52 |
| Game 新原生帧（张/秒） | 28.44 | 37.48 | 39.10 | 39.09 |
| Game 模拟推进（次/秒） | 41.11 | 39.01 | 39.98 | 40.27 |
| 移动时空画面次数 | 0.00 | 0.00 | 0.00 | 0.00 |

四次编辑态和运行态移动均无空画面，真实树木、城镇大厅和农民动画、模型点击选择、层级展开与滚动、相机预览、暂停、单步及停止重启通过，无控制台 error。两次候选运行实际观察到原生修订请求；选中相机仍走过滤快照。暂停后的像素检查分别对父节点隐藏、显式后代隐藏、浏览器过滤快照、恢复显隐和再次隐藏进行比对，容差为 0.5%。高代数实体 ID、动态增加隐藏后代、缺失和非激活祖先、换父级、旧修订及实体槽复用另有 Rust 回归覆盖。

41 项前端、3 项场景镜像、20 项运行态回归通过，3 项原有测试忽略。独立只读审核无阻断。四次 QA 所属进程均退出，隔离 Main.js 已恢复并核对哈希。验收记录 (`scene-filtered-revision-performance.json`)包含请求计数、像素结果、EXE 哈希、日志和原始报告路径。

移动时 Scene 模拟推进由基线约 11.7～11.9 次/秒降至约 10.2～10.5 次/秒；显示更新更快，并未提高模拟吞吐。候选采样仍存在浏览器逐帧计算、垃圾回收和 QuickJS 回调开销，需要继续定位与优化；本阶段不能视作整体性能问题已解决。

新原生帧计数来自 WebView 画布实际显示；不代表物理显示器 FPS。其他机器、多窗口实际显示和稳定 60 FPS 尚未验收。完整 Warcraft III 复刻仍有未完成项。
