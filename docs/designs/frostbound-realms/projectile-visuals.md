# 弹体视觉与平滑飞行

客户端区分十种弹体外观，实体弹使用已接入的箭模型和扫描岩石，魔法弹使用粒子拖尾。命中、伤害、存档和重连继续由 10 Hz 权威模拟决定。

| 类别 | 来源和表现 |
|---|---|
| 箭、短弩箭、长投射物、弩炮箭 | 0 A.D. RealArrow，共用原模型并调整长度与粗细 |
| 攻城石弹 | Poly Haven RealRock07 的低细节扫描网格，飞行中旋转，落地扬尘 |
| 火焰 | 橙色烟焰拖尾 |
| 冰霜 | 蓝白碎光拖尾 |
| 自然 | 绿色光粒拖尾 |
| 暗影 | 紫色烟雾拖尾 |
| 奥术 | 蓝紫光粒拖尾 |

箭与岩石的来源、许可和哈希沿用 `human-sources.json`、`realistic-sources.json`；粒子图片来自已保留的 Kenney CC0 Particle Pack。本阶段没有新增下载文件。长投射物和弩炮箭仍共用箭模型，尚未接入独立的标枪与弩炮弹模型。

弹体变换独立于界面刷新，按渲染帧在已收到的可见位置间过渡，过渡时间为 0.1 秒，不向未知位置外推。每枚弹体按唯一编号保留显示历史；命中或失去可见性时立即隐藏模型和拖尾。新出现弹体、存档读取、重连、倒退帧或较大的快照间隔会重置历史。暂停冻结本地插值时钟与魔法粒子。其他单位的位置和界面刷新频率没有改动。

魔法弹仅激活粒子实体，实体弹仅激活对应网格；拖尾使用世界空间与每弹独立种子，槽位复用不继承前一弹的粒子。命中特效按弹种选择颜色、尺寸与烟尘，结束后禁用实体。客户端渲染与网络下发均检查弹体当前位置的可见性。

协议版本为 9，旧客户端必须同步更新。协议 8 存档中的 `art=bolt` 按发射者类别迁移；网络仍只下发位置、速度、阵营、类别与弹体编号。

## 验证

```powershell
node scripts/test-frostbound.mjs
node scripts/qa-frostbound.mjs --projectile-art-only
node scripts/qa-frostbound.mjs --projectiles-only
node scripts/qa-frostbound.mjs --network-only
```

原生视觉验收使用十个固定发射者与固定靶，编辑器逐帧推进实际 QuickJS 和渲染器。检查全部十类弹体、实体与粒子启用状态、同一模拟帧内的位移和命中清理；该展示场景用于对照弹体，不代表正式地图摆放。保存回归另用真实 Agent 输入执行暂停、F5 与继续游戏。
