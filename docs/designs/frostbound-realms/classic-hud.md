# Classic RTS interface

The gameplay screen uses a bottom strip with a minimap, character portrait, unit information, six inventory slots and a four-column, three-row command card. Move, Stop, Hold, Attack and Patrol occupy fixed slots; hero abilities occupy the bottom row. Workers open a construction submenu and Escape returns to their normal commands. The left hero shortcut and twelve selectable group portraits retain real selection and control-group behavior.

The information panel shows live attack damage/range, armor category, hero level, experience and available skill points. Health and mana values remain over their bars. The F10 menu opens over the current battlefield, suspends single-player simulation and provides resume, quicksave, quickload and exit. Multiplayer simulation continues while the local menu is open. Main-menu labels and resources are localized; the game retains its Frostbound Realms identity.

Character close-ups are native renders of twelve existing game meshes, generated by `scripts/render-frost-head-portraits.mjs`. Each model and camera is checked through the live scene snapshot; twelve distinct outputs are required. `head-portraits.json` records the meshes, camera settings and atlas hash. Attribution and adaptation terms are packaged in `Assets/Licenses/Head-Portraits.txt` and the original character notices. The atlas is CC-BY-SA-4.0; original sources retain their stated licenses.

Validation is recorded in `classic-hud-validation.json` and `native-classic-hud-qa.json`. Run `node scripts/build-frostbound.mjs`, `node scripts/test-frostbound.mjs`, `cargo test -p mengine-editor-host --test frost_sample` and `node scripts/qa-frostbound.mjs --hud-only` with `MENGINE_QA_ROOT` set to the isolated native QA directory. Packaged startup is checked separately by `scripts/smoke-frostbound.ps1`.

This is an interface implementation stage, not a complete Warcraft III reproduction. Race-specific sculpted frames, animated portrait viewports, the original main-menu composition, full localization, alliance/chat panels and full save-file browsing remain unfinished. The current frame art, models and icons are adaptations or original assets, not Blizzard assets. Native Agent input does not establish physical mouse, audio-listening or cross-machine LAN acceptance.
