# 场景与界面多重采样

2026-09-29。原生 Player、编辑器和离屏截图使用同一套 4× MSAA 渲染链：天空和场景写入多采样 HDR，解析为单采样纹理供曝光、色调映射和 FXAA 使用；结果写入多采样显示色缓冲区，界面复用场景的深度和 Stencil，最后解析到窗口或截图目标。界面在 FXAA 之后绘制，世界空间界面保留逐样本遮挡。阴影贴图和素材纹理的采样方式保持原有约定。

细枝、针叶的 UV、位置和法线使用覆盖区域内插值（centroid），避免部分覆盖像素在三角形外插值贴图。硬件选择同时检查 HDR、显示色和深度格式的 4× 支持、颜色解析和附件用途，缺失时采用 1× 路径。尺寸变化会同步重建全部颜色、深度附件及 HDR 绑定；自定义和错误材质管线使用同一采样数。

## 验证

- RHI 48 通过、0 失败；编辑器视口设置测试 1 通过、0 失败。着色器后端检查覆盖 WebGPU、Vulkan、D3D12、Metal。
- 真实 GPU 整链测试确认采样数 4，验证 32→48→32 尺寸切换、世界空间界面遮挡、Stencil 裁剪、屏幕界面、自定义/错误材质，以及针叶宽度三角形的 UV 不越界。1× 能力回退条件与单采样 UI/后处理路径有测试，尚未在仅支持 1× 的设备上运行完整 Renderer。
- [原生美术验收](native-realistic-qa.json)确认采样数 4、近景资源树使用三维网格、远景切换树冠贴片、地图编辑器渲染正常，材质管线拒绝数 0。资源源文件及派生哈希检查通过。
- [双客户端检查](native-network-qa.json)通过选人、工人队列、路线、巡逻和断线重连。
- Release 构建与 [Player 包验收](player-smoke.json)通过。包含 362 文件、1899 实体，内容哈希 `9ecfed3c7c8763c0a99295a24ed45ae34a0e47ff386cbc40c8d8166107256d71`。逐文件哈希一致，启动 30 秒窗口响应、日志错误 0。物理输入、音频听感和跨机器 LAN 不在此次验收范围内。

## 画面与成本

同一 1280×720 标准视角，预热 5 秒后测量三次各 5 秒，FPS 为 12.13、11.99、12.56；中位数 12.13，上一阶段为 12.09。原生渲染耗时中位数 8.93→9.36 ms。小样本波动不足以证明整体帧率改善。最近视角另预热 3 秒并测量 5 秒，10.54 FPS，原生渲染平均 13.41 ms。完整样本与二进制哈希见 [阶段记录](multisampling-qa.json)。

视口显存统计包含解析 HDR、多采样 HDR/显示色和多采样深度。1280×720 下颜色与深度附件估算约 66.8 MiB，比单采样增加约 52.7 MiB；此数不含驱动对齐，深度格式占用依后端而异，也不包括素材纹理和网格。

边缘覆盖得到改善，近景树冠仍偏暗、稀疏，需要继续完善材质与光照匹配。当前仍不够流畅，5 ms 整体目标和完整游戏目标未完成；角色、其他阵营、自然地形轮廓仍待完善。
