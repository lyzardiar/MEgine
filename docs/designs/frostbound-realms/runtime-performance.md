# 写实场景运行性能阶段

2026-09-29。沿用 [写实素材与截图](realistic-art.md)，本阶段减少没有物理组件的场景扫描、视口共享内存传输的中间拷贝，以及客户端组件命令的重复序列化。

World 按类型维护活实体的组件数量，覆盖插入、替换、反序列化、移除和销毁；没有必要组件的查询立即结束。物理系统仅在没有现存物理对象、也没有相关组件时跳过，保留对象清理路径。视口传输直接将头、元数据和渲染器 RGBA 写入最终共享缓冲区，普通 IPC 回退保持相同协议字节。

## 实测

同一 1899 实体场景、1280×720 原生 Release 编辑器，预热 5 秒后测量三次，每次 5 秒。基线为 `e62fd4a13c59f2898f5cd459996e638a586009b1`；完整样本和二进制哈希见 [性能对照](runtime-performance-change.json)。

| 指标（三次中位数） | 基线 | 当前 |
| --- | ---: | ---: |
| 实际呈现 FPS | 11.68 | 13.50 |
| 模拟耗时 | 12.17 ms | 9.78 ms |
| 原生渲染耗时 | 8.47 ms | 8.32 ms |

当前三次 FPS 为 13.50、12.36、13.61。物理阶段单次快照约从 2.2 ms 降为 0.004 ms，此值不是阶段平均值。编辑器请求调度与传输仍有显著开销，5 ms 整体目标未达到，当前表现尚不流畅。
