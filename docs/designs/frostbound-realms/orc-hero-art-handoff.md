# 兽族四英雄原版身体与肖像

Author: MiYu

剑圣、先知、牛头人酋长和暗影猎手的八个原版身体/肖像模型已从已安装游戏按 MPQ 覆盖优先级提取，包含 25 个原始来源、17 个贴图来源、39 个 geoset、44 个渲染部件和 68 段动画。来源档案、路径、字节数、SHA-256、工具与二进制指纹见 `orc-hero-art-sources.json`。353 个输出采用独立来源清单，原有兽族规则与图标清单不变。

`scripts/import-frost-orc-hero-art.py` 复用现有 MDX 导出器、节点读取器和姿态探针，无需重新下载或构建。导入支持 `--source-root samples/frostbound-realms --output <目录>`，可从随包的原始来源离线重建。材质依赖、两种队伍颜色、geoset 颜色与透明度、材质透明度和贴图切换均保留；动画 GLB 包含原始节点轨道和 billboard 信息。移动后的资产使用基于最终路径的稳定 GUID。牛头人身体和肖像的同名贴图分别按完整来源路径保存。

四个肖像保留原始透视相机及其轨道，固定取各轨道的第一个键用于取景。记录实际首键时间：先知目标轨道为 47,300 ms，暗影猎手目标轨道为 39,000 ms。动态相机未接入，固定取景不表示原始相机在时间零点的姿态。

`python scripts/test-frost-orc-hero-art.py` 通过：全部来源/输出/工具指纹、所有材质依赖、全部帧状态、节点标注重建、稳定 GUID、两队颜色、身体/肖像纹理区分、四个原版相机、1,173 个原生姿态、离线逐字节重建，以及损坏来源和修改输出的保护。原生首次可见帧包围盒使用一次批量请求读取 38 个部件；转换器的 MDX/序列化姿态比较最大位置误差为 0.0000020344 个引擎单位，低于 0.00390625 的容差。

本阶段最终转换命令用时 8.051 秒，验证与 diff 检查命令用时 9.589 秒。这是工具记录的本次命令时长，不包含代码分析、编写、提交或推送，也不是原生编辑器启动/渲染耗时。

游戏主脚本、场景和共享资产库未修改。`runtimeIntegrated=false`、`originalRuntimeVerified=false`；兽族英雄仍使用通用游戏行为。下一阶段接入原版英雄属性、招募/指令图标、身体/肖像、技能效果与具体技能，再验证保存和联机。原版粒子、丝带及动态肖像相机仍需独立接入；此次姿态加载验证不证明编辑器渲染和技能交互。完整战役、地图编辑器、经典 TD/Dota 行为、音频和跨机器 LAN 的完整复刻尚未完成。
