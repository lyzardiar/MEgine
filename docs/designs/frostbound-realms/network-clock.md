# 联机连接计时

作者：MiYu

客户端的 TCP 心跳、初次连接期限、断线重试和重连期限使用实际时间。战斗、动画、提示文字与菜单效果继续使用游戏帧时间。服务器空闲连接期限为 12 秒，断线玩家的重连令牌保留 15 秒；客户端每三个实际秒数区间发送心跳，并在八秒没有收到消息后关闭静默连接。

原生诊断确认，处理大型场景时游戏帧时间会落后于实际时间：主机发送创建消息的记录为 140.79 秒，服务器在 152.80 秒触发空闲超时；143.13 秒至 155.93 秒期间，客户端游戏时间只从 9.3 秒增加到 10.7 秒。连接期限需要与服务器使用相同的时间口径。更换时钟后，心跳区间不会因为跳过某个整秒而漏发。

`node scripts/test-frost-network-clock.mjs` 加载生产客户端、生成脚本和真实场景，在独立的实际时间与游戏帧时间下验证心跳、静默超时、半秒重试、重连令牌和两种连接期限。源码 `63d2f96` 在“极小游戏步长下按实际时间发送心跳”的断言失败；当前源码通过。测试不替代实际 TCP 和原生客户端验收。

`node scripts/qa-frost-menu-network.mjs` 使用两个独立原生客户端、实际菜单点击和真实 TCP 服务，验证创建、浏览、加入、16 秒大厅空闲、准备／开局、双方权威状态流、种族控制台与客机断线重连。脚本记录服务器连接、请求、心跳、空闲超时及关闭事件；报告为 `native-menu-network-qa.json`。物理鼠标和音频需要另行验收。

原生验收通过，服务器记录 79 次心跳、一次创建、一次浏览、一次加入、两次准备、一次开局和一次重连恢复；未发生服务器空闲超时。大厅闲置 16 秒后仍保留同一对 TCP 连接。双方材质管线拒绝数为 0。画面见 [兽族主机](menu-network-host.png) 和 [暗夜精灵客机](menu-network-guest.png)。
