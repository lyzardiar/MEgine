# Original Death Knight rules and spell rendering

Author: MiYu

Death Knight Udea source rules, original spell assets and the standalone hero profile are prepared for authoritative gameplay integration. The playable simulation, generated Main script and published game scene are unchanged in this stage. Death Coil, Death Pact, Unholy Aura and Animate Dead are not yet playable source abilities.

`death-knight-rules.json` retains source attributes/growth, distinct model/selection scales, melee weapon timing, altar costs, C/E/U/D command cards, buffs, AI learning order and translated original editor field metadata. Animate Dead revives six units for forty seconds with invulnerability; DataC is explicitly false for inheriting upgrades. The source targets do not restrict corpses to allies. The rules include 318 original nonbuilding unit profiles with usable corpses: original identity/model path, scale, movement, base health/mana/armor/regeneration, baseline abilities and both enabled weapons. These profiles contain no player research bonuses. The UnitBalance type classification is preserved independently of race; neutral Dark Ranger Nbrn is classified undead despite its creeps race.

Death Coil uses 200/400/600 healing, half damage and the original homing missile speed of eleven world units per second. Death Pact retains every conversion/ratio/survival field, including life conversion 1/2/3 and target survival false; static data does not establish whether the healing basis is current or maximum health. Unholy Aura uses ten/twenty/thirty percent speed and fixed 0.5/1/1.5 health per second, with percentage regeneration false. These field interpretations were independently checked against installed archive metadata; original-runtime targeting, aura stacking/linger, Pact sacrifice rewards and resurrection selection/mana still require validation.

`death-knight-effects.json` includes the Coil missile and impact, Pact caster and target, Unholy Aura, general aura target, Animate Dead target, Undead death explosion and original hero embedded emitters. Seven original geometry models and nine sampled effects preserve source fingerprints, textures, node/billboard annotations, material tracks, particles, ribbons and lights. Only DeathPactCaster is particle-only, verified against the original MDX without geosets. Ownership notices and the converter's separate MIT license are retained.

Native visual inspection exposed white cloud rectangles from multiply blending. The Clouds8x8Mod texture has transparent white edge pixels (255,255,255,0). The existing Dst/OneMinusSrcAlpha blend factors require premultiplied RGB; sampled effects now multiply texture/vertex RGB by their combined alpha before this blend. Transparent edges preserve the background, while opaque pixels multiply its color. Alpha, additive, alpha cutoff and depth behavior retain their existing paths. The change covers ordinary particles, quads and model particles through the shared polygon function. Sampled effects do not currently use soft clipping; adding soft clipping would require consistent RGB/alpha attenuation.

Validation: signed imports reproduced byte-for-byte with installed archives unavailable, modified generated outputs and damaged signed sources were rejected, and native parsing checked nine effects and thirty-six geometry pose samples. The profile check covers original stats/growth, ranked abilities, source classifications, 318 base resurrection profiles, AI builds and browser/CommonJS parity. Four runtime sampled-effect tests passed. Release editor build with tauri/custom-protocol passed. The native source preview and same-scene image comparison passed: white pixels in the Animate cloud region fell from 4,002 to zero and in the Coil cloud region from 1,183 to twenty; the original hero region was byte-identical. No console errors or mesh material rejects were observed. The image comparison is a targeted opacity regression, not original Warcraft solver equivalence.

The baseline report retains its passing structural checks and explicitly rejects its visual result. The first rebuilt preview exited normally after an incorrect assertion about the mesh custom-pipeline counter; sampled effects use the UI pipeline, which that counter does not cover. Its diagnostic report and fixture are retained. Final preview uses native image comparison for the repaired path; its owned editor exited normally and disposable fixture/storage/runtime/discovery were removed.
