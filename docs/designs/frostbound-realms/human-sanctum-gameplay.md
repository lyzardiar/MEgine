# 神秘圣地生产与训练

Author: MiYu

神秘圣地接入实际建造、生产和研究队列。建筑需要完成的 Keep；破法者还需要完成的 Arcane Vault。三兵种使用原始费用、人口、28/30/28 秒生产时间、攻击骰子、攻击点和投射物轨迹，共享三个生产／研究槽位，取消返还实际费用。

牧师和女巫两级训练各增加 40 生命、100 魔法上限和 0.325 每秒回魔，攻击力不变；第二级需要 Castle。已有单位和新生产单位均应用等级。破法者保留魔法免疫，Blacksmith 的 Rhar/Rhme 每级增加 2 护甲和平均 2 攻击力，投射物保存发射时的装备等级。

客户端使用原版图标、禁用图标、按钮位置及快捷键；三兵种和建筑使用原始模型与比例。主场景仍为 8,973 个实体，新模型复用按地图内容延迟创建的节点池。网络协议为 82，旧客户端需要更新；旧存档缺少新 feature version 时保留版本 0。存档严格校验等级、单位数值、生产者、队列顺序、等待时间、重复研究和投射物装备快照。

三兵种尸体带原版 source ID，能进入圣骑士 Resurrection 和死亡骑士 Animate Dead。操纵死尸使用原版基础数值和回魔速度，不继承操纵者的训练或装备研究。

验证：24 个相关测试入口通过，包括独立规则、生成客户端、实际 TCP／重连、装备、尸体、原有人族生产及原生骨骼查询。最终生成脚本通过原生编辑器 60 步建造卡片／训练／研究／存档操作；三兵种模型与训练数值恢复正确，控制台和材质错误为零。完整生产时钟在共享模拟、生成客户端和 TCP 测试验证；原生编辑器验证指令起始、支付、队列存档和完成状态恢复。报告与图片见本目录 `human-sanctum-gameplay-validation.json`、`native-human-sanctum-game-qa.json`、`human-sanctum-native-training.png`、`human-sanctum-native-army.png`。

本阶段完成生产和训练基础。医疗、驱逐魔法、心灵之火、减速、隐形、变形、反馈、魔法盗取、控制魔法及魔法岗哨检测仍待接入；Rhse/Rhss 已能排队并保存研究等级，尚未产生对应技能行为。物理鼠标／键盘、独立 Player 和跨机器局域网尚未验收。完整 Warcraft III 目标继续进行。
