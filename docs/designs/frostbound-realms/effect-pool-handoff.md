# On-demand classic effect pools

Author: MiYu.

Generic spell, status and construction attachment pools keep the complete slot-zero templates and all existing identity folders. Other slots are created inactive when requested, confirmed through native snapshots, parented to their slot folder/root, and reused. Mesh transforms start at local identity. Attachments grow as needed and disable excess old parts when an asset changes. World spells can use indices beyond the unit limit. Missing hidden slots cause no name query.

Native Spawn accepts optional `active` (default true) and `parent` (default null). Existing Rust construction sites keep their prior active-root defaults. The parent handle carries its entity generation; invalid or stale parents leave the spawned entity unparented without changing command result cardinality.

Pending names and unconfirmed active/component writes share batched name queries. Failed script ticks discard native commands, so creation, parenting, activation, component writes and one-off hides retry until a later snapshot confirms them. Component confirmation compares requested fields semantically, allows native defaults/key order, and uses f32 equality for the pooled typed component numbers.
