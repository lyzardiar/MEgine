# 恐惧魔王玩法阶段交接

Author: MiYu

本阶段接入原版 Udre 恐惧魔王与 ninf 地狱火的权威玩法、单机客户端、F5 存档和 TCP 联机。协议为 73；新游戏默认 dreadlordVersion=1，旧存档缺失版本时维持旧英雄规则。

## 已实现

- 腐臭蜂群：按原版等级数据沿扩张范围扫掠地面和空中有机敌人，逐个命中并消耗总伤害预算；释放后独立于施法者移动和死亡。
- 睡眠：普通单位与英雄使用各自持续时间，初始保护 2 秒，之后受到有效伤害唤醒；友军可攻击唤醒或驱散。睡眠阻断即时施法和道具，移动命令可排队。
- 吸血光环：使用范围内最强等级，仅合格近战普通攻击按实际扣除生命恢复；排除远程命中与幻象攻击。
- 地狱火：释放后延迟 1 秒落地，落地伤害及眩晕独立于施法者后续命令；提前预留单位名额。原版 1500 HP、重甲、混乱近战、魔法免疫、抗性皮肤时长处理、永久献祭、180 秒召唤寿命与生命恢复。
- 原版模型、身体粒子、施法动画、技能图标/位置/快捷键、选择圈比例和独立头像摄像机；地狱火显示三个原版被动卡。
- 蜂群和落地效果使用持久世界投影，支持断线恢复、隐藏施法者与离开视野清理。公共蜂群不传来源、起点、路程、释放帧、命中表或预算。
- 存档严格验证身份、属性、效果时钟、伤害预算、召唤寿命和预留容量；牛头人死亡重生及时清理地狱火眩晕。

## 验证入口

- `node scripts/test-frost-dreadlord-suite.mjs`：16 个脚本、80 组检查，最多 3 个独立进程。
- `node scripts/test-frostbound.mjs`：完整游戏回归入口，包含本阶段技能、头像、存档与真实 TCP 验证。本次分段完成 402 条 PASS 记录，详情见 `dreadlord-full-validation.json`，原始日志保留夹具问题诊断。
- `node scripts/qa-frost-dreadlord.mjs`：完整原生客户端模型、技能特效与 F5 验证，使用已缓存 Editor。
- `node scripts/qa-frost-dreadlord-runtime.mjs`：最终生成代码中的权威模拟在原生脚本运行时的独立验证，仅 1 个场景实体。
- `dreadlord-reproduction-validation.json`：最终 Main.js / Main.mscene 在独立输出路径生成后逐字节一致。

完整画面报告 `native-dreadlord-qa.json` 与截图记录报告中的产品哈希。最终产品增加睡眠即时动作保护、召唤容量预留、地狱火被动卡，并移除地狱火粒子实体的重复身体子网格；最终生成客户端检查、完整回归和独立原生模拟报告分别覆盖这些收尾内容。最终产品哈希见复现报告和 `native-dreadlord-runtime-qa.json`。
