# 破法者魔法盗取

Author: MiYu

破法者的魔法盗取已接入单机和权威 TCP 对战。命令面板第 8 槽使用原版开关图标，T 选择目标，右键或 Shift+T 切换自动施放。技能消耗 75 魔法，冷却 3 秒，施法与接收范围均为 7，采用原单位 0.3 秒施法前摇和 0.51 秒后摇。

敌方正面单位法术转给附近友军，友军负面单位法术转给附近敌军。现有可转移状态包括心灵之火、嗜血、咆哮、回春、隐形、闪电护盾、邪恶狂热、减速、残废、净化减速、精灵之火、变形和飓风。邪恶狂热和飓风需要手动选择；英雄法术、物品和攻击被动不进入盗取列表。反魔法外壳的单位法术尚未实现，因此其转移也尚未接入。

每次只转移一个状态。接收者按与原目标的距离、单位 ID 排序，已有同种状态的接收者会被跳过。正面状态可转给魔法免疫的破法者自身；负面状态继续受魔法免疫限制。变形术保留原施法的英雄、召唤物和中立单位等级限制，闪电护盾与飓风保留地面限制。自动施放仅在空闲、驻守、攻击、攻击移动或巡逻时选择范围内可转移的状态。

在释放帧完成转移，保留当时的剩余时间，并按新接收者的英雄时长上限截断。对象状态保存真实释放帧、原始施法来源和转移记录，校验剩余时间与帧数一致；不通过重置完整持续时间来转移。阵营改为破法者所属方，邪恶狂热和闪电护盾保留原始施法单位身份与类型，并将伤害归属改为盗取方。目标失效、没有接收者、移出范围或施法被中断时不扣魔法、不进入冷却。

新对战使用 `humanSpellbreakerVersion=2`，版本 1 继续只启用反馈；缺少版本字段的旧存档恢复为 0。TD、MOBA、RPG 的既有规则仍为 0。联机协议为 88。敌方快照隐藏盗取自动开关、冷却与目标订单，只提供可见施法动画；飞行特效的起点不可见时也隐藏该特效记录。重连与单机存档保留转移状态。

原版飞行特效保留五个动画几何部件与采样粒子，目标使用原版 overhead 粒子。飞行轨迹使用源速度 10、弧度 0.15，跟随接收者并播放 Birth、Stand、Death；转移机制在释放帧生效，飞行是视觉呈现。场景新增七个 inactive 模板，初始总数为 9,014；原有 9,007 个节点的身份、层级、组件与资源引用保持一致。

`human-spellsteal-validation.json` 记录 50 个通过的测试入口，包含实际牧师施放心灵之火、13 种单位状态、剩余时间、英雄时长截断、正负方向、伤害来源、魔法免疫、自身接收、手动例外、中断、恶意存档、生成客户端、真实 TCP、视野过滤及重连。`native-human-spellsteal-qa.json` 记录原生输入回放、正负转移、右键和自动施放、五个动画部件、目标粒子、存档续播与到期验收。截图为 `human-spellsteal-native-transfer.png`。

[官方技能说明](https://classic.battle.net/war3/human/units/spellbreaker.shtml)与工程中的原版 `Asps` 数据是实现依据。原版接收者优先级、英雄剩余时长的处理和转移/飞行动画时序尚未通过原版运行时实测。原生桥接验收也不代表物理输入、独立 Player 或跨机器 LAN 已完成。完整破法者还需实现魔法控制，完整游戏复刻目标保持进行中。
