# 守望者交接

Author: MiYu

守望者已接入源模型、比例、选择圈、头像、B/F/D/V 快捷键和原版技能/学习位置。四个技能分别使用 Blink、Fan of Knives、Shadow Strike 和 Vengeance 的源数据。复仇化身支持右键自动施法，消费友方尸体并维持最多六个子单位；子单位在化身死亡或到期时清理。公开快照携带可见化身的实际光球数量，隐藏子单位的位置仍受战争迷雾约束。

587 个签名文件、79 条源记录和 11 个生成器哈希由独立重建逐字节核对。模型、材质和采样特效的资源引用必须匹配保存的目录大小写，所有 `.mfx` 纹理必须存在于签名集合中。生成场景有 48,127 个实体和 321 个模型绑定；独立生成的场景、脚本和工程文件一致。生成前的本机场景和脚本保存在 `tmp/warden-before-generation`。

13 组规则测试、生成客户端测试、真实 TCP 和完整 `scripts/test-frostbound.mjs` 回归通过。原生玩法报告验证模型、四技能、学习位置、召唤、自动施法及 F5 恢复；特效纹理报告单独验证当前生成脚本和完整贴图资源。二者的实际指纹和范围保留在报告中，不能把不同脚本指纹当作同一次验收。

原生玩法验收四阶段耗时约 731 秒，其中 57 次输入命令中位数 9.129 秒、累计 333.089 秒。这些数据包含渲染、队列与 IPC，说明大场景还有明显的原生往返开销。下一步需要分别记录请求进入、前端处理、原生调用及渲染完成时间，不能从暂停桥接基准推断整个流程已经提速。

当前生成脚本和修复后的特效纹理原生验收通过：D/F/B/V、召唤及 F5 恢复均通过，着色器拒绝数为零；实例正常退出，隔离工程及存档已清理。两阶段累计 326.830 秒，其中工程就绪为 80.106 秒。逐项耗时和优化顺序见 `execution-timing.md`。

完整 Warcraft III 复刻仍未完成。原版技能与粒子求解器的运行时对照、战役、跨机器联机、原版地图编辑器和经典地图的完整行为仍需继续验证和完善。现有材质与 UI 的真实画面以原生 PNG 为准。
