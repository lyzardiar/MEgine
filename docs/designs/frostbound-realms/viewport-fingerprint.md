# 编辑器视口按需校验场景同步

Game View 每次绘制读取实时场景时，原先会序列化全部 1,899 个实体以判断能否复用原生世界；原生请求受 inFlight 限制，其中许多校验没有对应渲染请求。现在只在构造原生请求参数时读取会话 ID 并计算指纹，每个请求读取一次。模拟步进同步和 Inspector 直接修改后的快照回退保持有效。

回归测试验证 60 次展示快照读取产生 0 次序列化，读取原生会话 ID 时产生 1 次。编辑器全套测试 948 通过、0 失败；同时补齐 InputField 默认组件缺失的 font 字段，使其与 IDL 和 Inspector 字段定义一致。前端构建、带 tauri/custom-protocol 的 Release 编辑器构建、原生地形编辑及近远景渲染检查通过。

相同样例、1280×720、预热 5 秒后各采样三个 5 秒窗口：基线中位数 13.25 FPS，修改后 14.35 FPS，反向重跑基线 13.47 FPS。已确认减少重复序列化；短窗口和未隔离的机器负载限制了帧率结论，不能视为稳定提速保证。完整数值和可执行文件 SHA-256 见 [阶段验收](viewport-fingerprint-qa.json)，当前修改后详细采样保存在 [性能报告](native-performance-qa.json)。

这是编辑器 Game View 数据，未测独立 Player 帧率。原生渲染及模拟仍串行执行，5 ms 目标尚未达到。本阶段没有重新打包 Player；物理输入、音频听感、跨机器联机未验收。
