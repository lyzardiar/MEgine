# Original Undead hero source assets and rules

Author: MiYu

Original Udea Death Knight, Ulic Lich, Udre Dreadlord and Ucrl Crypt Lord source rules, bodies and portraits are prepared for gameplay integration. The installed original archives contain these models and full unit/ability records; the shared asset-library was inspected read-only. Original Warcraft III ownership notices and the converter MIT license are retained. Extraction does not establish free redistribution rights.

`undead-hero-rules.json` preserves the four heroes' source attributes/growth, recruitment costs/times, collision/sight/regeneration, distinct body and selection scales, source weapon rows, sixteen skill bindings, forty ranked parameter records, command/research positions, seventy-two original normal/disabled/research icons, buff definitions and original AI scripts. The altar training order is Udea/Ulic/Udre/Ucrl. Dreadlord's source hero ability list starts with Vampiric Aura; command ordering uses source Researchbuttonpos and is Carrion Swarm/Sleep/Vampiric Aura/Inferno. Sleep references `Bust`, while the unique matching source buff definition is `BUst`; the requested identifier remains unchanged and `sourceAlias` records the resolved definition. Runtime alias behavior has not been established.

`undead-hero-models.json` contains eight original body/portrait models, fifty-five clips and fifty-four render parts. Original bone/node/billboard tracks, material visibility/texture/color changes, red/blue replaceable textures and source cameras are preserved. Portrait framing uses the first source camera keys; dynamic portrait camera tracks are retained but not played. `undead-hero-portraits.json` contains the original perspective camera settings. Model particles/ribbons remain in original MDX source data and require separate effect conversion.

Validation: both rules and art packs independently reproduced byte-for-byte with the original archives unavailable; damaged sources and modified outputs were rejected. Native GLB sampling checked 1,380 poses and fifty-one billboard annotations. Native editor body and four portrait camera previews passed with zero console errors and zero material rejects; the successful owned editor exited normally and fixture/storage/runtime/discovery data were removed. The first preview attempt failed its camera-reference assertion and exited normally; its isolated fixture is retained for diagnosis in the QA cache. Final screenshots are undead-native-original-heroes.png and undead-native-original-portraits.png.

The shared rule/art importers accept race-specific source bindings while preserving the existing default Orc outputs. All ten affected prior receipt packs' signed outputs were verified unchanged; the Orc rule and art packs reproduced 138 and 353 outputs byte-for-byte. Existing Orc rule/art acceptance also passed. Prior source receipts keep their original byte format and change only shared generator hashes. Other dependent packs were not independently regenerated in this check.

No generated playable Main script or game simulation was changed in this asset stage. The four Undead heroes are not yet original playable heroes. Next: implement Death Knight attributes/recruitment/versioned saves, Death Coil, Death Pact, Unholy Aura and Animate Dead, with original source effects, generated client/F5, actual TCP and full native gameplay acceptance; then Lich, Dreadlord and Crypt Lord. Campaign, complete map editor, cross-machine LAN, classic TD/Dota parity and original-runtime solver equivalence remain incomplete. Keep the full Warcraft III goal active.

Evidence: undead-hero-assets-validation.json, undead-hero-art-validation.json, undead-import-compatibility.json, native-undead-hero-assets-qa.json and native-undead-hero-assets-qa-attempt1.json. Importers and test scripts are under scripts/import-frost-undead-hero*.py and scripts/test-frost-undead-hero*.py.
