# 单位特效槽更新开销

Author: MiYu

客户端按单位呈现槽记录上一次活动的状态与法术槽名称。首次呈现清理所有未使用的 authored 槽；之后只隐藏刚结束的效果，活动效果每帧持续更新。重复空列表直接返回。重复槽使用第一个效果，未知槽忽略，活动效果保持原有绑定顺序。缓存只持有槽名称，不持有效果或地图对象；不可见、死亡、复活和菜单切换均使相关记录失效。对象池在每帧开始时独立重试未完成的生成、显隐和组件命令。

## Release 对照

同一 EXE、同一隔离工程，按旧版、新版、新版重复、旧版重复执行；采样期间不运行构建或 CPU 测试。每次采样 12 秒；只交换生成 Main.js，结束后恢复原始脚本并验证 SHA-256。

第 1 组模拟推进 +4.4%，不同世界版本绘制 +3.9%；第 2 组模拟推进 +8.3%，不同世界版本绘制 +5.8%。这些是本机模拟和画布绘制数据，不代表物理显示器 FPS；稳定 60 FPS 与其他机器上的流畅性仍需继续验证。

四次连续右键移动 Scene 视角均无完全空白画面。实际 WebView GPU 像素、模型选择、层级展开滚动、暂停时钟、精确单步及停止重启检查通过；无 console error，QA 进程均已退出。Scene 持续显示的引擎和编辑器代码已同步到 master，本阶段仅修改游戏脚本。
