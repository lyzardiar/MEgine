# 血法师特效阶段交接

Author: MiYu

凤凰自动火焰使用原始 `Phoenix_Missile_mini.mfx` 采样粒子，按来源速度 900（世界速度 9）追踪目标，到达时才产生伤害与持续灼烧。飞行中的目标预留、凤凰变蛋或移除后的延续、完整存档恢复和 TCP 重连均已验证。协议版本为 65。

吸魔使用原始 DRAM 纹理与来源参数，通过现有 MaterialPropertyBlock 驱动自定义材质的 UV 动画。相位跟随模拟时钟，暂停时冻结。无需引擎修改；实体总数仍为 63,877。

来源、玩法、微型飞弹、相关英雄、渲染与弹道的 8 个回归模块通过；生成客户端、TCP 重连和主验收主体通过。默认生成与隔离生成的场景、Main 脚本、光带模型及材质字节一致。两次原生验收退出码为 0，控制台错误和材质拒绝均为 0，正常退出并清理临时工程。最新四张草地截图已人工检查：吸魔光带可见、两个采样时刻纹理变化、微型火球与凤凰分离、命中后出现伤害显示。

验证指纹见 `blood-mage-effects-validation.json`，原生断言和画面计时分别见 `native-blood-mage-effects-qa.json`、`native-blood-mage-effects-visible-qa.json`，耗时分析见 `blood-mage-effects-timings.md`。

原版 UV/noise 与粒子执行算法、目标选择/失效/叠加行为尚未运行对照；微型火球命中仍使用现有通用命中特效，下一步可接原始 Death 片段。音频、物理输入、跨机器 LAN 未验收。完整战役、地图编辑器及经典地图复刻仍未完成。
