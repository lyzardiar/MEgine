# Crypt Lord Locust Swarm handoff

Author: MiYu

## Delivered scope

`cryptLordVersion: 1` now supports authoritative AUls alongside Impale, Spiked Carapace and Carrion Beetles. Default remains 0 and protocol remains 73 until source hero presentation and product acceptance are complete.

- A 0.4-second source cast point precedes payment of 150 mana and the 180-second cooldown. Twenty independent actors release every 0.2 seconds, first at 0.2 seconds and twentieth at 4 seconds. They share a 30-second swarm duration, follow the moving caster, and survive ordinary orders or stun.
- Actors use imported uloc speed, height, contact range, 13–14 damage dice, one-second attack cooldown, missile speed and arc. Each flies to contacts, launches a delayed shot, wanders while cooling down and retargets within the caster's eight-unit radius. Allocation permits seven actors per target per swarm. Air, ground, buildings and magic-immune targets use physical weapon handling with imported spell-category armor ratios and numerical armor.
- Actors collect actual applied life loss multiplied by 0.75. Twenty accumulated life triggers return without truncating excess collection; healing occurs only upon arrival at the moving caster. Shared damage returns effective loss before Phoenix egg transformation or Tauren reincarnation, and credits no absorbed damage or overkill.
- Expiry recalls actors; outstanding emitted shots can finish before arrival delivers healing and retires the actor. Recasting removes the previous swarm without death events. Caster death removes all owned actors and pending shots, including when another swarm kills the caster during actor iteration.
- Actors occupy a separate bounded array, with no ordinary unit selection, collision, food or sight contribution. Strict saves validate release slots, lifecycle, return threshold, target allocation and missile clocks/coordinates. Public state exposes only visible presentation positions and phase, plus the hero's remaining duration, hiding actor ownership, targeting, collection, timers and serial state.

## Validation

- `node scripts/test-frost-locust-swarm-suite.mjs`: 24 scripts, 159 PASS groups, three bounded workers, 10781 ms. Includes actual two-client TCP, shared damage heroes, Phoenix egg conversion, Tauren reincarnation, opposing caster death and strict in-flight forgery rejection.
- TCP acceptance exercises server command ownership, private actor and emitted-missile projection, moving caster, enemy visibility, reconnect and final return using an explicit opt-in fixture. Expiry is advanced through authoritative ticks to keep the check short; this is not a wall-clock thirty-second session or full product scene acceptance.
- `node scripts/qa-frost-locust-swarm-runtime.mjs`: four checks in the native generated script runtime, one scene entity, readiness 1286 ms, elapsed 4835 ms, zero console errors. The owned editor exited normally and the successful fixture/storage were removed. This validates authoritative logic, not rendered Locust models or animations.
- `node scripts/verify-frost-locust-swarm-build.mjs`: isolated byte-identical Main.js and Main.mscene generation, 1699 ms; temporary output removed.
- Earlier independent read-only review found missing-actor/threshold validation gaps and iterator reinsertion after caster death; repaired behavior was independently reproduced. The final missile-arc extension is covered by simulation and native checks.

## Source references and limits

- Imported `crypt-lord-rules.json` pins AUls and uloc rows. Its existing `damageReturnLimit` field is interpreted as a return threshold; importer receipts remain unchanged.
- [Blizzard Crypt Lord](https://classic.battle.net/war3/undead/units/cryptlord.shtml) specifies duration, mana, cooldown, staggered twenty actors, seven per target, conversion and return threshold, moving caster and building targets.
- [Editor experiments, version 1.28.5.7680](https://github.com/Cokemonkey11/wc3-ability-doc/blob/master/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md#L3804) document threshold-dependent activity, radius, alternate caster state and recast removal without unit death. They do not establish the exact numeric accumulation formula or geometry.
- [Community examination with demonstration](https://www.reddit.com/r/WC3/comments/q8ao62/a_closer_look_at_locust_swarm/) reports four-second release, after-armor collection and roughly 26.6 damage for twenty returned HP. Community testing supports the current formula; this project has not run an original Blizzard runtime comparison. Imported uloc's spell attack category remains authoritative for this source version.

Exact original flight, wandering, target solver, expiry/death behavior and threshold overshoot remain fidelity limits. Existing Impale DataD-based sine animation likewise is an implementation reference, not an original measured curve.
