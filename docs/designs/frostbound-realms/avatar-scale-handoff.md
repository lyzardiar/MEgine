# 天神下凡体型表现阶段

Author: MiYu

天神下凡持续时，以已导入 Area1=0.5 作为视觉体型增量，模型和选中圈使用正常大小的 1.5 倍，血条高度按放大后的模型顶部计算。头像仍使用独立头像模型和原始相机取景。碰撞与移动半径保持原始单位规则，变身到期后恢复正常显示。倍率由现有 mountainAvatarLeft 状态推导，存档和联网协议没有新增字段。

生成客户端验证了实际施放、模型与选中圈倍率、血条升高、头像取景、碰撞半径、F5 加载和到期恢复。原生 native-avatar-scale-qa.json 记录正常模型缩放 [2,2,2]、变身缩放 [3,3,3]，同样验证 F5 和到期恢复；shaderRejections=0、consoleErrors=0，自有实例正常退出，测试夹具和存储已删除。四张 avatar-scale-* 截图对应正常、变身、恢复和到期状态。

单位尺寸回归使用完整的当前英雄与召唤物素材目录，并通过 unitType 获取有效源单位。50 条源尺寸记录、184 个单位/阵营映射、城镇大厅相对步兵高度、选中圈、与动画包围盒无关的尺寸及枪口位置均通过。该检查已加入完整回归入口；本阶段运行的是相关检查，不声称重新运行了整个入口。

独立生成与当前 Main.js、Main.mscene 和 project.json 逐字节一致。场景数量仍为 61,253，场景字节未改变。avatar-scale-validation.json 记录产物、脚本和原生验收指纹；固定预检指纹由 mountain-king-client-validation.json 更新至本阶段生成客户端结果。

原版 Warcraft 运行时是否使用相同的 Area1 体型增量、选中圈变化和变化时序仍未逐项对照。本阶段证明 MEngine 的放大、恢复和到期表现，不宣称该行为已经与原版完全一致。原版伤害与免疫边界、完整阵营、战役、编辑器、经典 TD/Dota、物理输入、音频与跨机器 LAN 仍需继续完成。
