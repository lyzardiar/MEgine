# 场景静态物体地形高度缓存

Author: MiYu

树木装饰和资源点按地图几何版本、槽位及 x/z 复用地形高度。高度、坡道、雕刻、地表数组原地修改会刷新缓存；位置变化重新采样。迷雾、阻挡、LOD、材质和动画下沉量仍实时更新。地图缓存使用 WeakMap。

## 原生回调对照

同一接受的 Release 原生代码，交替运行旧版/新版各两次，每次预热 360 步、测量 60 步。QuickJS 回调平均耗时为旧版 6.149/6.142 ms，新版 5.503/5.513 ms，下降约 10.4%。这是脚本回调测量。

## 真实 Release 编辑器

同一 EXE、同一隔离工程，仅替换 Main.js，采样期间没有并行构建或 CPU 测试。每轮在 Edit/Play 各持续移动 Scene 12 秒，并验证 GPU 像素、原始 Warcraft 模型拾取、显隐、父级变换、层级滚动、播放控制及资源刷新。

Game 模拟推进两组分别改善约 3.6% 和 1.4%，完成画面约改善 3.4% 和 2.1%。Play Scene 画面速率第一组上升、第二组下降，不能据此声称 Scene FPS 稳定提升。当前运行态约 35～37 张/秒，尚未达到稳定 60 FPS。

Scene 持续显示最近完成且兼容的画面，新相机帧完成后替换。画面、相机与拾取保持一致；四轮新相机请求被延迟时，点击仍命中显示中的模型。此通用实现已同步 master，本次提交仅修改游戏脚本及验证资料。

## 验证与边界

26 组静态节点精确对照通过，重复帧累计省去 1,342 次高度采样。对照覆盖原地地图修改、资源移动重排、迷雾、LOD、阻挡、延迟创建和模式切换。完整世界显示对照通过 90 组；阻挡对照通过 36 组；路径与 AI 状态对照通过 144 条路径和 315 帧。scenery-visual、environment、minimap、tree-felling、ground-bindings、ground-detail、terrain 回归通过。源码、工作树 Main、隔离生成 Main 与 QA 候选按 LF 规范化后一致。

旧基线测试失败和一次 QA 打开请求失败保留在 JSON 中；验收采用修改前 8eca82d 对照。四轮控制台 error 为 0，拥有的编辑器进程均退出、资源 fixture 已删除、QA 原脚本已恢复并核对哈希。恢复校验区分原始字节哈希和 LF 规范化哈希。

测试入口：`node scripts/test-frost-environment-elevation-client.mjs`、`node scripts/test-frost-ground-display.mjs 8eca82d`。原始报告、具体测试限制及构建哈希见 [验收记录](environment-elevation-performance.json)。跨机器的严重卡顿仍需重建后复测；本机结果不代表其他机器已经解决。
