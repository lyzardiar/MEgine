# 权威弹道与延迟命中

远程普通攻击在箭矢或弹体抵达后结算伤害。模拟以 10 Hz 推进，客户端显示服务器给出的当前位置与朝向。弓箭使用 RealArrow 写实模型，来源与授权见 [弓箭美术](archer-art.md)。本阶段没有新增下载资产；Free3D 本次复查仍返回 HTTP 403。

普通远程弹速为每秒 20 世界单位，追踪存活且仍在场的敌方目标；目标死亡或进入建筑后取消该弹。攻城弹速为每秒 12 单位，落在发射时的目标位置，目标移动可避开直接伤害，落点仍有范围伤害。近战和火枪即时命中。弓箭、其他远程和攻城弹道的弧高分别为 0.6、0.2、2.5。单局最多 256 枚弹体，满额时保留攻击冷却等待发射；弹体最多存活 6 秒。

发射时保存攻击数值，抵达时应用目标护甲、护盾和减伤；射手死亡后仍保留击杀归属，吸血不能复活死亡射手。旧存档缺少弹道字段时迁移为空列表。暂停时可按 F5 保存，继续游戏后飞行和伤害接续。

当前网络协议为 9，客户端与服务端需一起更新。仅同步当前位置可见的弹体，网络数据仅含位置、速度、阵营、模型类别和弹体编号；隐藏目标、射手编号与伤害数据不下发。包含发射点坐标的事件要求起点和终点都可见。

## 验证入口

```powershell
node scripts/test-frostbound.mjs
node scripts/qa-frostbound.mjs --projectiles-only
node scripts/qa-frostbound.mjs --humans-only
node scripts/qa-frostbound.mjs --network-only
```

规则测试覆盖移动目标、射手死亡、目标消失、护盾、吸血、攻城落点与溅射、弹体上限、寿命、存档校验和战争迷雾。真实 TCP 测试检查飞行中断线重连、编号保持、隐私字段裁剪和单次命中。

原生弹道验收使用平地与固定靶，弓箭手在射程内等待初始冷却，首箭之后抑制连射。编辑器逐帧推进捕捉短暂飞行，再通过 Agent 输入执行 Escape 暂停、F5 保存与菜单继续；检查实际箭模型坐标、暂停冻结和一次护甲折算伤害。详情见 [原生弹道结果](native-projectiles-qa.json)、[阶段结果](projectile-combat-qa.json)。
