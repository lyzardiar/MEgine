# 凤凰自动火焰命中特效

Author: MiYu

凤凰自动火焰在命中点播放原始 `Phoenix_Missile_mini.mfx` 的 Death 片段，使用来源时长 2.333 秒、世界缩放 2 和飞行方向。现有 24 槽特效池支持没有几何部分的采样效果，隐藏通用命中粒子和旧几何子节点，暂停时冻结，片段结束后回收。场景仍为 63,877 个实体，无需扩展引擎或转换资产。

命中事件只增加有限数值的速度向量；公开事件仍不包含来源、召唤者或目标身份，迷雾中的事件仍被过滤。协议保持 65。TCP 测试验证真实重连后的命中事件和延迟伤害。

生成客户端验证原始 Death 片段、位置、缩放、方向、暂停、时长回收，以及池槽重新播放原始驱散几何效果。凤凰玩法/TCP、驱散玩法和全渲染槽回归通过。四项生成产物逐字节复现。原生验收通过，错误和材质拒绝均为 0，实例正常退出并清理工程及存档。截图已检查：目标上方显示短暂的原始黄色命中效果；该片段部分时段只有两个采样四边形。

证据见 `phoenix-fire-impact-validation.json`、`native-phoenix-fire-impact-qa.json` 和 `phoenix-fire-original-death.png`。文本源码指纹统一按 LF 校验，生成 Main 脚本及原始采样资产保持字节校验。原生 Transform 使用 float32，位置断言采用 1e-5 容差。

原版粒子随机、模型空间传输和执行算法尚未运行对照；音频、物理输入、跨机器 LAN 未验收。完整战役、地图编辑器和经典地图行为仍未完成。
