# 冰壁棱面与砌石崖面

Author: MiYu

`terrain4h:` 的原始高度与起伏数据后可附加一个 0/1/2 字符，分别生成岩石、冰壁或砌石崖面。无尾部类型的现有网格使用岩石。地图编辑器的悬崖选择同时决定网格和材质；保存和联机继续使用已有 `cliffStyle` 字段与协议 25。

冰壁采用具有不同脊线深度的棱面。砌石壁分为四层，邻层水平错缝，块面高于灰缝，倒角连接块面与凹槽。砌石面内部增加顶点，顶面边界和崖脚仍使用相同的分段。三种崖面在顶沿、崖脚和垂直接缝回到共享轮廓，坡道交点的高差趋于零时，新增凸起也归零；重合的轮廓点只生成一次内缩环，保持坡道尖端闭合。不同高度的垂直接缝共享四分之一世界单位的高度分段。

顶面三角形、轮廓收边、地表起伏和单位落地高度不随类型改变。现有脚底半径通行检查继续使用共享崖沿。崖壁中部凸起的完整三维人体碰撞尚未实现。

```powershell
cargo test -p mengine-assets terrain_mesh
node scripts/test-frostbound.mjs
node scripts/build-frostbound.mjs
node scripts/qa-frostbound.mjs --ground-only --cliff-styles --deterministic-input
```

原生网格测试覆盖三种类型、16 种邻格高低组合和四种坡道配置，共 192 组四区块接缝，检查内部闭合边与有限法线。三种类型的顶面均对照 JavaScript 的 64 组高度夹具，共 2304 个完整三角形；另检查造型区别、平台保持、旧格式和非法类型拒绝。原生编辑、保存和渲染另行验收，不以网格测试代替实际运行验证。

本阶段实现棱面冰壁和砌石崖面。完整原版地形套件与全部造型变体仍未完成。物理输入、听音和稳定游戏性能另待验收。
