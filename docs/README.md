# 文档与本地验证产物

本目录保存设计、使用说明和验证结论。截图、运行快照、测试结果、日志与性能采样仅保存在本地，不纳入 Git。

- 新验证产物写入 `tmp/docs-artifacts/<任务>/`。需要共享结论时，记录关键指标、复现命令和产物路径。
- 旧文档中的截图和报告路径表示本地验证证据；对应文件已停止跟踪，全新检出不会包含这些产物。运行相关验证脚本后查看其输出，部分旧脚本仍写入被忽略的原路径。
- 依赖历史报告的验证步骤应先运行报告生成脚本；历史快照不作为当前代码通过验证的依据。
- `docs/images/` 仅保存正式文档引用的必要配图。编译、测试和导入使用的固定参考 JSON 通过 `.gitignore` 中的精确例外继续跟踪。

清理使用 `git rm --cached` 保留本地文件。Git 历史仍包含旧快照，本次清理阻止后续版本继续携带或更新这些产物，不会立即缩减已有 `.git` 的历史对象体积。
